# Chaser - 裸身追鬼

## Implementation Status

- 素材状态：已实现并接入，当前对应 `assets/sprites/enemies/enemy_1.png`。
- 玩法状态：专属 `chaser` archetype、独立数值和行为尚未实现；当前仍与其他普通敌人共享同一套追踪 AI。

## Role

基础追击敌人，是玩家理解普通小怪的基准。它的形象应直接、凶狠、低复杂度，不暗示额外机制。

## Target Size

宽 `90-110px`，高 `95-115px`。当前基础追击体型。

## Visual Identity

- 远看是前倾奔跑的赤褐色鬼影。
- 乱发后飘，额角短小，嘴部张开，表情偏野性。
- 裸露上身，肩背和肋骨肌肉明显，保持瘦而有爆发力。
- 一前一后摆动的手爪强调追逐方向。
- 破损短裤或腰布颜色低调，不抢身体轮廓。

## Color And Materials

- 主色：赤褐皮肤、暗肉色高光、深灰裤布。
- 强调色：眼睛和嘴部可有少量暗红。
- 材质：粗糙皮肤、汗亮肌肉、破布。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 奔跑 | 保持重心前压，头发向后甩，手爪有清晰摆幅 |
| 受击 | 上半身向后折，爪子打开，读出硬直 |
| 死亡 | 向前扑倒或被斩开后化烟，动作短促 |

## Avoid

- 不要加武器或施法物件，它必须保持最纯粹的基础追击单位。
- 不要把体型画得过壮，避免和 `brute` 混淆。
