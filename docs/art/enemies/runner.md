# Runner - 角突鬼

## Implementation Status

- 素材状态：已实现并接入，当前对应 `assets/sprites/enemies/enemy_3.png`。
- 玩法状态：专属 `runner` archetype、前摇冲刺和恢复帧尚未实现；当前仍与其他普通敌人共享同一套追踪 AI。

## Role

快攻压力敌人。它应通过“可预判的突然靠近”迫使玩家跳跃、拉开或用远程技能提前处理。

## Target Size

宽 `95-120px`，高 `95-120px`。冲刺前后 silhouette 差异明显。

## Visual Identity

- 单角、抬臂、前冲姿态是主要辨识点。
- 一根明显前倾长角或断角，冲刺时角尖指向玩家。
- 上半身比 `chaser` 更扭转，肩膀一高一低。
- 一臂高举蓄力，一臂压低维持平衡。
- 跨步更大，脚后跟有扬尘或拖影空间。

## Color And Materials

- 主色：暗肉色、深褐裤布、黑发。
- 强调色：角尖和肩部可加浅骨色；冲刺前眼睛暗红发亮。
- 材质：骨角、紧绷肌肉、破布。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 移动 | 比 `chaser` 更低、更急，头角保持前指 |
| 冲刺前摇 | 身体压低，单角对准玩家，脚下扬尘 |
| 冲刺 | 身体拉成长斜线，手臂后摆，速度感明确 |
| 恢复 | 冲过后刹停，身体前倾过度，露出反击窗口 |

## Avoid

- 不要只把 `chaser` 加速；必须有独立蓄力姿态。
- 不要让角太大到像 Boss 或精英头冠。
