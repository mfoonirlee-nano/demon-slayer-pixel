# Runner - 角突夜妖

## Implementation Status

- 素材状态：已实现并接入，当前运行时移动图集对应 `assets/sprites/enemies/runner/runner_approach.png`。
- 动作序列帧：已新增 `runner_approach.png`、`runner_windup.png`、`runner_dash.png`、`runner_recover.png`，用于按行为状态接入。
- 玩法状态：已接入专属 `runner` archetype。当前实现为“接近玩家 -> 前摇停顿 -> 直线冲刺 -> 恢复硬直”的快攻循环。
- 代码入口：`src/entities/enemies/runner.ts`；基础敌人数值入口：`src/constants/combat.ts` 的 `ENEMY_CONFIG`。

## Role

快攻压力敌人。它不是更快的 `chaser`，而是通过“可预判的突然靠近”迫使玩家处理反应、站位和技能时机。

`runner` 的价值来自节奏变化：平时接近速度可控，进入触发距离后短暂停住，给出明显前摇，然后沿锁定方向高速冲刺。玩家应能在前摇期间判断方向，并用跳跃、拉开、潮龙·破阵或镜潮·护返处理。

## Gameplay Loop

| 状态 | 当前规则 | 设计目的 |
| --- | --- | --- |
| `approach` | 低中速朝玩家移动，速度低于冲刺态 | 建立压迫但不直接贴脸秒杀 |
| `windup` | 进入触发距离后停住 `14-18` 帧，朝向玩家 | 给玩家读招时间 |
| `dash` | 沿前摇结束时的朝向冲刺 `42-52` 帧 | 制造更长的直线快攻窗口 |
| `recover` | 冲刺后停住 `24` 帧 | 给玩家反打或重新站位 |

## Current Tuning

| 参数 | 当前值 | 说明 |
| --- | ---: | --- |
| 触发距离 | `250px` | 距离玩家足够近时进入前摇 |
| 接近速度 | `1.1 + rand(0.35) + elapsed*0.006` | 比基础追踪更稳定，避免贴身乱转 |
| 冲刺速度 | `4.1 + elapsed*0.008`，上限 `5.2` | 冲刺需要明显快于普通移动 |
| 前摇 | `14-18` 帧 | 必须可读，不应低于玩家反应阈值 |
| 冲刺 | `42-52` 帧 | 形成更长的直线威胁 |
| 恢复 | `24` 帧 | 冲刺后不能无缝粘人 |
| 生命 | 基础敌人生命的 `75%` | 鼓励玩家用技能或抓恢复快速处理 |

## Combat Readability

- 前摇期间必须保持静止或近似静止，不能边蓄力边滑向玩家。
- 冲刺方向在前摇结束时锁定；冲刺中不应持续追踪玩家，否则会和 `chaser` 重合。
- 恢复帧要足够明显，玩家需要能判断“现在可以反打”。
- 同屏多个 `runner` 时，前摇时间应有轻微错位，避免同时冲刺造成不可读伤害。
- 当前实现用红色前摇线和冲刺尘迹增强可读性；后续如果有专门动画，这些提示可以减弱但不应完全消失。

## Player Counterplay

| 玩家行为 | 有效原因 |
| --- | --- |
| 提前跳跃 | 冲刺是水平直线压力，跳跃能避开接触窗口 |
| 潮龙·破阵 | 远距离直线清理，适合在前摇期打断 |
| 镜潮·护返 | 适合处理冲刺进入身边后的防守反击 |
| 抓恢复普攻 | 冲刺结束后 `runner` 停顿，给近战窗口 |
| 横向拉开 | 诱导它进入前摇，再离开冲刺路径 |

## Spawn And Mixing

- `runner` 可以和 `chaser` 同池出现，但两者压力必须分工：`chaser` 负责持续贴身追踪，`runner` 负责短前摇爆发。
- 不建议在早期同屏堆太多 `runner`；多个冲刺单位会快速压缩玩家反应空间。
- Boss 召唤 `runner` 时应避免和 Boss 自身高速冲刺技能完全同步。
- 后期可降低常规刷怪权重，把 `runner` 作为轮换快攻单位，而不是每波固定出现。

## Target Size

宽 `95-120px`，高 `95-120px`。冲刺前后 silhouette 差异明显。

## Visual Identity

- 单角、抬臂、前冲姿态是主要辨识点。
- 一根明显前倾长角或断角，冲刺时角尖指向玩家。
- 上半身比 `chaser` 更扭转，肩膀一高一低。
- 一臂高举蓄力，一臂压低维持平衡。
- 跨步更大，脚后跟有扬尘或拖影空间。

## Color And Materials

- 主色：暗肉色、深褐裤布、黑发。
- 强调色：角尖和肩部可加浅骨色；冲刺前眼睛暗红发亮。
- 材质：骨角、紧绷肌肉、破布。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 移动 | 比 `chaser` 更低、更急，头角保持前指 |
| 冲刺前摇 | 身体压低，单角对准玩家，脚下扬尘 |
| 冲刺 | 身体拉成长斜线，手臂后摆，速度感明确 |
| 恢复 | 冲过后刹停，身体前倾过度，露出反击窗口 |

## Design Boundaries

- 可以快，但不能没有前摇。
- 可以突然靠近，但不能在冲刺中无限修正方向。
- 可以造成站位压力，但不能比 `duelist` 更像近战精英。
- 可以用红光、尘土、残影提示速度，但不能遮住真实碰撞体。
- 伤害以接触伤害为主；如果未来增加角突命中盒，需要独立前摇关键帧和恢复帧。

## Avoid

- 不要只把 `chaser` 加速；必须有独立蓄力姿态。
- 不要让角太大到像 Boss 或精英头冠。
- 不要让多个 `runner` 同时前摇、同时冲刺，除非这是明确的高难波次。
