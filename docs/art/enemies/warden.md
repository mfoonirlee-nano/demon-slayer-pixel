# Warden - 御阵鬼

## Implementation Status

- 素材状态：未实现。
- 玩法状态：未实现。

## Role

支援核心敌人，用低直接威胁换取高目标优先级。

## Target Size

宽 `110-140px`，高 `125-155px`。高但不应 Boss 化。

## Visual Identity

- 支援核心、后排优先级、光环来源。
- 它不靠直接攻击威胁玩家，视觉上必须让玩家知道先杀它会削弱整波敌人。

## Shape Details

| 部位 | 描述 |
| --- | --- |
| 头部 | 戴破损祭祀面具或木质鬼面，表情冷静，不要狂暴 |
| 身体 | 比普通敌人更直立，像移动祭坛或阵眼 |
| 背部 | 背负小型破旗、灯架、鼓架或骨制阵牌，形成高轮廓 |
| 手臂 | 一手扶阵牌，一手持铃或短杖，用于维持光环 |
| 底部 | 行走慢，脚边可有小型阵纹残影 |

## Color And Materials

- 主色：深墨绿、黑木、暗金旧饰。
- 强调色：光环用低饱和金绿或暗青绿，与 `binder` 的暗红咒圈区分。
- 材质：木牌、破旗、旧金属铃、骨片。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 待机/移动 | 背部阵牌轻微摇晃，身体稳重缓慢 |
| 光环维持 | 双手抬起，背部阵牌亮起，脚下出现环形纹 |
| 受击 | 阵牌闪烁或裂开，光环短暂抖动 |
| 死亡 | 背部阵牌断裂，光环向内收缩后熄灭 |

## Effects

- 光环范围：低透明环形边界，不遮挡战斗。
- 被强化敌人：可以给脚下小符点或边缘描边，不要全身大面积变色。

## Avoid

- 不要做成 Boss 级体量。
- 光环不影响 Boss，视觉上也不要把光环连到 Boss 身上。
- 不要让它的直接攻击动画太强，否则会和 `caster` / `binder` 职责重叠。
