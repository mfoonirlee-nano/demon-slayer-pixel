# Crawler - 伏地蛛鬼

## Implementation Status

- 素材状态：已实现并接入，包含 `move` / `windup` / `lunge` / `recover` 四组动作图集。
- 玩法状态：已接入专属 `crawler` archetype。它会低伏接近、短暂停顿读招、短距离贴地前扑，然后进入恢复硬直。

## Role

低矮、快速、贴地穿插。它应打破只看站立敌人的节奏，但必须保持玩家普攻可命中。

## Target Size

宽 `105-125px`，高 `45-65px`。必须保留可命中高度。

## Visual Identity

- 远看像地面上一团横向移动的危险轮廓，而不是缩小版普通敌人。
- 圆硬头甲，眼点集中在正面，玩家能看出朝向。
- 横向椭圆躯干，腹部贴地，背部有硬壳分节。
- 多条细长节肢向外伸展，前肢略大，作为攻击方向提示。
- 背部可有暗红小斑点，强化危险感。

## Color And Materials

- 主色：灰褐硬壳、黑紫阴影、暗红眼点。
- 强调色：前肢尖端可有浅骨色，帮助读出攻击宽度。
- 材质：硬壳、细腿、粗糙腹部。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 移动 | 多肢交替快速摆动，但主体位置稳定，避免闪烁 |
| 前摇 | 身体压低、前肢张开、眼点增强，读出即将前扑 |
| 前扑 | 短距离贴地前冲，头甲和前肢指向明确，少量尘迹/气弧烘进图内 |
| 恢复 | 扑击后停顿，腿部回收，姿态读出可反打窗口 |
| 受击 | 硬壳向上翻起，露出腹部，给玩家命中反馈 |
| 死亡 | 腿部收缩，身体塌下后化烟 |

## Gameplay Notes

- `move`: 低血、比基础追击怪更快，持续贴地靠近玩家中心。
- `windup`: 进入触发距离后停住约 `14` 帧，锁定朝向。
- `lunge`: 约 `14` 帧短前扑，不继续修正方向；前方攻击盒首次命中造成略高于接触的伤害。
- `recover`: 约 `22` 帧不移动，玩家可用普攻、下落攻击或技能反打。
- 同时前扑的 crawler 有数量限制，避免多个单位无读招叠扑。

## Avoid

- 碰撞视觉不能过低；普攻命中高度要和视觉身体一致。
- 不要让腿部太细太密，像素缩放后会糊成噪点。
- 不要做潜行、绕背或瞬移，避免和后续 `burrower` 定位混淆。
