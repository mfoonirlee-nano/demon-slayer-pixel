# Crawler - 伏地蛛鬼

## Implementation Status

- 素材状态：已实现并接入，当前对应 `assets/sprites/enemies/enemy_2.png`。
- 玩法状态：专属 `crawler` archetype、独立数值和低矮穿插行为尚未实现；当前仍与其他普通敌人共享同一套追踪 AI。

## Role

低矮、快速、贴地穿插。它应打破只看站立敌人的节奏，但必须保持玩家普攻可命中。

## Target Size

宽 `105-125px`，高 `45-65px`。必须保留可命中高度。

## Visual Identity

- 远看像地面上一团横向移动的危险轮廓，而不是缩小版普通敌人。
- 圆硬头甲，眼点集中在正面，玩家能看出朝向。
- 横向椭圆躯干，腹部贴地，背部有硬壳分节。
- 多条细长节肢向外伸展，前肢略大，作为攻击方向提示。
- 背部可有暗红小斑点，强化危险感。

## Color And Materials

- 主色：灰褐硬壳、黑紫阴影、暗红眼点。
- 强调色：前肢尖端可有浅骨色，帮助读出攻击宽度。
- 材质：硬壳、细腿、粗糙腹部。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 移动 | 多肢交替快速摆动，但主体位置稳定，避免闪烁 |
| 前扑 | 身体低压，前肢同时向前伸，读出威胁 |
| 受击 | 硬壳向上翻起，露出腹部，给玩家命中反馈 |
| 死亡 | 腿部收缩，身体塌下后化烟 |

## Avoid

- 碰撞视觉不能过低；普攻命中高度要和视觉身体一致。
- 不要让腿部太细太密，像素缩放后会糊成噪点。
