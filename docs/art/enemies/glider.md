## Role

低空飞行敌人，负责占用玩家头顶和平台边缘空间。它不应靠远程弹幕制造压力，而是通过可预判的俯冲迫使玩家移动、跳斩或提前处理空中目标。

## Target Size

宽 `115-145px`，高 `70-95px`。展开翼膜时横向更宽，收翼俯冲时轮廓变窄。

## Visual Identity

- 远看是一团横向展开的暗色翼膜，中心有清楚的鬼面和发光眼点。
- 身体瘦长、肋骨外露，腿部退化并向后收，避免被读成地面奔跑敌人。
- 双臂拉成长翼骨，破损膜翼连接手臂、肋侧和腰后，形成最主要 silhouette。
- 头部前伸，短角向后贴，张口露齿；俯冲时头和爪子成为箭头。
- 爪尖和翼骨末端要清楚，用于提示接触伤害范围。

## Shape Details

| 部位 | 描述 |
| --- | --- |
| 头部 | 窄脸鬼面，后掠短角，红褐眼点，张口尖牙；脸部始终在翼膜前缘可见 |
| 身体 | 枯瘦胸腔和外露肋骨，腹部收紧，背脊有少量骨刺但不做成重型单位 |
| 翼膜 | 黑紫或暗灰膜翼，边缘破裂，有几个大缺口；展开时形成宽扁轮廓 |
| 手爪 | 翼骨末端伸出长爪，俯冲时两爪向前并拢，读成主要攻击点 |
| 腿脚 | 腿部短而后缩，脚爪像挂钩，只辅助悬停，不承担奔跑 silhouette |

## Color And Materials

- 主色：黑紫翼膜、灰褐枯肉、深红阴影。
- 强调色：眼点和翼膜裂缝可有少量暗橙红，提示俯冲前摇。
- 材质：薄膜翼、骨质翼架、干枯皮肤；不要使用玩家水蓝技能色。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 悬停/移动 | 翼膜小幅上下拍动，身体保持低空，头部始终朝向玩家 |
| 俯冲前摇 | 翼膜向后收紧，身体短暂停住，眼点和翼膜裂缝变亮 |
| 俯冲 | 身体拉成斜向箭头，两爪前伸，翼膜贴近身体，速度感明确 |
| 掠过恢复 | 俯冲后翼膜重新打开，身体上抬，给玩家反击窗口 |
| 受击 | 翼膜破口抖动，身体侧翻，不能像地面敌人那样后仰 |
| 死亡 | 翼膜烧穿或撕裂，身体旋转下坠后化烟 |

## Effects

- 俯冲预警：敌人自身眼点和翼膜裂缝短暂变亮，不额外铺大面积地面标记。
- 俯冲轨迹：短促暗红或灰黑风痕，持续时间短，不能遮挡玩家。
- 死亡：少量黑灰碎膜和暗红火星，避免大片烟雾遮挡空中目标。

## Avoid

- 不要做成高空不可命中的敌人；它需要低到跳跃、技能或平台攻击能处理。
- 不要发射弹幕，否则会和 `caster` 混淆。
- 不要使用大而华丽的 Boss 翅膀，保持小怪级别。
- 不要加羽毛、长袍或灯具，核心识别必须来自翼膜和俯冲姿态。
