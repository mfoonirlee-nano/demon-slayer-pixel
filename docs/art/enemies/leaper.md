# Leaper - 裂足跳鬼

## Implementation Status

- 素材状态：已实现，运行时透明图集位于 `assets/sprites/enemies/leaper/`。
- 玩法状态：已实现，当前以 `elapsed >= 35s` 作为第 2 幕解锁近似。

## Role

跳跃突袭敌人，专门惩罚玩家长期站在平台边缘或只向一个方向风筝。

## Target Size

宽 `105-125px`，高 `95-120px`。起跳时轮廓可变高。

## Visual Identity

- 远看像一只压低身体、随时弹起的畸形跳跃鬼。
- 腿部极长，膝关节反折或过度弯曲，脚掌像分裂的钩爪。
- 上半身相对瘦小，双臂向后拖，形成“腿大于身体”的轮廓。

## Shape Details

| 部位 | 描述 |
| --- | --- |
| 头部 | 窄长鬼面，额头有短角或骨刺，嘴部横向裂开，表情像在憋力 |
| 身体 | 肋骨和背脊突出，胸腔收缩，背部可有一排短刺强化弹跳感 |
| 手臂 | 手臂细长但不是主要攻击点，手爪向后摆，突出冲刺方向 |
| 腿脚 | 大腿细长，小腿肌腱夸张，脚爪分叉，落地时能插入地面 |
| 服饰 | 破损短袴或腿部缠布，避免长袍遮住腿部 silhouette |

## Color And Materials

- 主色：暗红褐、枯肉色、深紫阴影。
- 强调色：脚爪和膝关节可有赤红裂纹，用于提示跳跃危险。
- 材质：肌腱拉伸、骨刺、粗糙皮肤；不要做成轻盈飞行单位。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 待机/移动 | 身体低伏，腿部弹簧感明显，头部左右寻找目标 |
| 前摇 | 双腿完全压低，背刺竖起，脚下出现尘土或红色裂纹 |
| 起跳 | 身体拉成斜线，脚爪离地，腿部成为最大视觉焦点 |
| 落地 | 膝盖深蹲，脚爪插地，周围出现冲击尘或碎石 |
| 恢复 | 拔出脚爪，身体重新压低 |

## Effects

- 落点预警：地面小型红褐裂纹圈，不要使用玩家水蓝色。
- 落地冲击：低矮尘土半环，持续时间短。

## Avoid

- 不要加翅膀，避免被读成飞行敌人。
- 不要让上半身过大，否则会和 `brute` 混淆。
