# Binder - 缚咒夜妖

## Implementation Status

- 素材状态：已实现，运行时透明 PNG 位于 `assets/sprites/enemies/binder/`。
- 玩法状态：已实现 v2。`elapsed >= 90s` 后进入普通刷怪池，同屏最多 `1` 个；施法在自身身前生成短时法阵，法阵释放符纸，符纸命中后贴附玩家并施加状态。

## Role

控场干扰敌人，不靠高伤害，而是用贴附符纸制造玩家短时间失控。

## Target Size

宽 `85-105px`，高 `115-145px`。施法姿态要明显。

## Visual Identity

- 施法、束缚、区域控制。
- 远看要像会画阵和抛出束缚物的夜妖，而不是普通远程投射手。

## Shape Details

| 部位 | 描述 |
| --- | --- |
| 头部 | 面部被符纸或布条半遮，眼睛从缝隙发暗光 |
| 身体 | 瘦高，背微驼，动作像在念咒或牵线 |
| 手臂 | 手指细长，缠绕红绳、咒线或破损念珠 |
| 腰背 | 挂有残破符札、绳结、小铃，动起来能产生节奏感 |
| 下摆 | 长袍下摆破碎，但不要遮住脚部移动方向 |

## Color And Materials

- 主色：灰黑长袍、暗红绳线、旧黄符纸。
- 强调色：束缚区域用暗红/紫色咒纹，边缘低亮度脉冲。
- 材质：纸、绳、布、木铃。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 待机/移动 | 双手在胸前收拢，符纸轻微飘动 |
| 施法前摇 | 一只手拉线，一只手指向地面，身体向后弯 |
| 施法 | 绳线向地面或玩家方向甩出，符纸展开成环 |
| 恢复 | 绳线回收，符纸重新垂下 |
| 受击 | 符纸散开，短暂打断感明显 |

## Effects

- 身前法阵：低矮侧视法阵，边缘清晰；横版运行时需要压成偏侧面视角，不使用俯视完整圆。法阵只负责发射符纸，不直接对站位造成伤害。
- 贴附符纸：命中后显示在玩家身上。普通状态施加减速和持续掉血；觉醒状态施加左右键位错乱和突发眩晕；终幕状态从四种效果中随机施加两种。
- 减速提示：玩家被符纸减速时身上需要有滤镜/束缚线等可见反馈，不要使用实心大色块遮挡角色。

## Avoid

- 不要把它画成高伤法师；它的卖点是控场。
- 不要让法阵过亮或过大，符纸贴附时也不要遮挡玩家动作读法。
