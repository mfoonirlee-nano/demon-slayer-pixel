# Binder - 缚咒鬼

## Implementation Status

- 素材状态：已实现，运行时透明 PNG 位于 `assets/sprites/enemies/binder/`。
- 玩法状态：已实现 v1。`elapsed >= 90s` 后进入普通刷怪池，同屏最多 `1` 个；施法生成短时地面咒圈，只降低玩家水平移动速度，并在玩家身上显示束缚减速特效。

## Role

控场干扰敌人，不靠高伤害，而是制造玩家不想站的位置。

## Target Size

宽 `85-105px`，高 `115-145px`。施法姿态要明显。

## Visual Identity

- 施法、束缚、区域控制。
- 远看要像会画阵和抛出束缚物的妖鬼，而不是普通远程投射手。

## Shape Details

| 部位 | 描述 |
| --- | --- |
| 头部 | 面部被符纸或布条半遮，眼睛从缝隙发暗光 |
| 身体 | 瘦高，背微驼，动作像在念咒或牵线 |
| 手臂 | 手指细长，缠绕红绳、咒线或破损念珠 |
| 腰背 | 挂有残破符札、绳结、小铃，动起来能产生节奏感 |
| 下摆 | 长袍下摆破碎，但不要遮住脚部移动方向 |

## Color And Materials

- 主色：灰黑长袍、暗红绳线、旧黄符纸。
- 强调色：束缚区域用暗红/紫色咒纹，边缘低亮度脉冲。
- 材质：纸、绳、布、木铃。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 待机/移动 | 双手在胸前收拢，符纸轻微飘动 |
| 施法前摇 | 一只手拉线，一只手指向地面，身体向后弯 |
| 施法 | 绳线向地面或玩家方向甩出，符纸展开成环 |
| 恢复 | 绳线回收，符纸重新垂下 |
| 受击 | 符纸散开，短暂打断感明显 |

## Effects

- 束缚区域：地面咒圈，半径比玩家宽 `2-3` 倍，边缘要清晰；横版运行时需要压成偏侧面视角，不使用俯视完整圆。
- 减速提示：区域内可有向中心收束的细线，不要使用实心大色块遮挡平台；玩家进入时身上需要有滤镜/束缚线等可见反馈。

## Avoid

- 不要把它画成高伤法师；它的卖点是控场。
- 不要让咒圈过亮或过大，避免遮挡玩家和平台。
