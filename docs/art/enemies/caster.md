# Caster - 提灯咒鬼

## Implementation Status

- 素材状态：已实现并接入，当前对应 `assets/sprites/enemies/enemy_4.png`。
- 玩法状态：专属 `caster` archetype、远程投射物和施法冷却尚未实现；当前仍与其他普通敌人共享同一套追踪 AI。

## Role

远程施压敌人。危险来源应被读成“灯和咒术”，不是接触追击。

## Target Size

宽 `85-105px`，高 `115-145px`。提灯和面具是核心识别。

## Visual Identity

- 白色或灰白鬼面，眼孔发暗红光，面具轮廓清楚。
- 破损黑袍或灰袍，姿态微驼，行动慢。
- 一手提灯，一手下垂或结印，提灯位置始终可见。
- 提灯发橙红光，施法前亮度增强。
- 长袍破洞和布条随步伐摆动，但不遮住脚底方向。

## Color And Materials

- 主色：黑灰长袍、灰白面具、暗红眼孔。
- 强调色：提灯暖橙光，与玩家水蓝技能区分。
- 材质：纸灯、破布、木柄、面具裂纹。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 移动 | 提灯轻晃，身体缓慢前进 |
| 施法前摇 | 提灯抬高或向前伸，灯芯骤亮 |
| 施法 | 灯光拉成短弧，释放投射物或召唤标记 |
| 恢复 | 提灯光变弱，手臂回落 |
| 受击 | 面具偏移，灯光闪烁，读出打断感 |

## Avoid

- 不要让提灯光覆盖大面积画面，它只是施法提示。
- 不要把它画得太快或太强壮，定位应是后排远程压力。
