# Caster - 提灯咒妖

## Implementation Status

- 素材状态：多状态素材已实现并接入预加载，移动图集对应 `assets/sprites/enemies/caster/caster_move.png`，额外状态在 `assets/sprites/enemies/caster/`，独立幽火为 `caster_wisp.png`。
- 玩法状态：已接入专属 `caster` archetype，状态机为 `seekRange -> windup -> cast -> recover -> seekRange`。普通、觉醒、终幕三档幽火节奏、颜色、连发数、速度、伤害和序列帧速度均已接入。

## Role

远程施压敌人。危险来源应被读成“灯和咒术”，不是接触追击。

## Target Size

宽 `85-105px`，高 `115-145px`。提灯和面具是核心识别。

## Visual Identity

- 白色或灰白妖面，眼孔发暗红光，面具轮廓清楚。
- 破损黑袍或灰袍，姿态微驼，行动慢。
- 一手提灯，一手下垂或结印，提灯位置始终可见。
- 提灯发橙红光，施法前亮度增强。
- 长袍破洞和布条随步伐摆动，但不遮住脚底方向。

## Color And Materials

- 主色：黑灰长袍、灰白面具、暗红眼孔。
- 强调色：提灯暖橙光，与玩家水蓝技能区分。
- 阶段色：普通幽火保持暖橙；觉醒幽火叠紫红滤镜；终幕幽火压暗为暗红并提高饱和度和对比度。
- 材质：纸灯、破布、木柄、面具裂纹。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 移动 | 4 帧慢速前行，提灯低位前摆、抬高、内收、再前摆，身体和袍摆保持同一底部锚点 |
| 施法前摇 | 4 帧提灯从低位抬到高位，灯芯逐渐增强，另一手结印准备释放 |
| 施法 | 4 帧提灯前伸，短弧和小符点只围绕灯笼局部出现，避免变成全身光效 |
| 恢复 | 3 帧施法后手臂回落，灯光变弱，身体重新下沉 |
| 受击 | 3 帧面具后仰、袍摆侧甩、提灯闪烁，读出打断和脆弱窗口 |

## Projectile Notes

- `caster_cast` 只表现提灯近处的起火和释放，不承载飞行中的幽火。
- `caster_wisp.png` 是独立 4 帧投射物图集，单帧 `96x96`。
- 普通状态：每 `5s` 发射 `1` 个暖橙幽火；速度为普通基准的 `110%`，单体可同时保有最多 `3` 个幽火。
- 觉醒状态：每 `3s` 发射 `3` 个紫红幽火，从不同垂直偏移和角度飞出；速度为普通状态的 `130%`，伤害为普通状态的 `120%`，单体可同时保有最多 `15` 个幽火。
- 终幕状态：每 `3s` 发射 `6` 个暗红幽火，从更宽的多角度扇形飞出；速度为普通状态的 `150%`，伤害为普通状态的 `150%`，幽火序列帧播放速度翻倍，单体可同时保有最多 `30` 个幽火。
- 幽火会朝玩家方向飞行并在前 `5s` 轻微追踪。终幕可以形成明显弹幕压力，但单个幽火轮廓仍要可读，不能遮住玩家动作。

## Avoid

- 不要让提灯光覆盖大面积画面，它只是施法提示。
- 不要把它画得太快或太强壮，定位应是后排远程压力。
- 不要把飞离灯笼的幽火画进 caster 动作帧；飞行形态只存在于 `caster_wisp.png`。
- 不要只靠换色表达终幕；终幕还需要通过更密集的 6 发扇形、暗红色和更快闪动读出强度变化。
