# Splitter - 裂影夜妖

## Implementation Status

- 素材状态：已实现，运行时透明 PNG 位于 `assets/sprites/enemies/splitter/`。
- 玩法状态：已实现。本体约 `90s` 后进入随机刷怪池；死亡后短暂分裂并生成两个 splitling，splitling 不再分裂。

## Role

分裂压迫敌人，用来让玩家判断先清小怪还是先打本体。

## Target Size

宽 `90-115px`，高 `105-135px`。死亡分裂是核心卖点。

## Visual Identity

- 看起来像身体内部已经裂开，死亡后会分裂。
- 本体必须在活着时就暗示会裂成两个。

## Shape Details

| 部位 | 描述 |
| --- | --- |
| 头部 | 左右不对称的面具或双面半脸，中间有明显裂缝 |
| 身体 | 躯干从胸口到腹部有发光裂线，像两具影子缝在一起 |
| 手臂 | 左右手形状不同，一侧爪、一侧骨刃，强化不稳定感 |
| 腿部 | 步态不协调，一条腿拖行，一条腿正常行走 |
| 服饰 | 破烂长布从身体裂缝向两侧飘，死亡时可撕裂成分裂体披片 |

## Color And Materials

- 主色：暗紫、灰白皮肤、深黑裂影。
- 强调色：裂缝中使用暗红或紫红，不要太亮。
- 材质：破裂面具、阴影烟雾、撕裂布条。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 待机/移动 | 身体左右半边不同步，裂缝微微张合 |
| 攻击 | 贴近玩家时短暂停步，影爪和骨刃做紧凑前探，特效保持贴身暗紫红 |
| 受击 | 裂缝短暂变亮，暗示分裂临界 |
| 死亡 | 身体从中线撕开，左右半身化成两个低矮影子 |
| 分裂体移动 | 比本体更小、更快，轮廓像残缺半身 |
| 分裂体死亡 | 快速化烟，不要再分裂 |

## Effects

- 分裂瞬间：中线撕裂闪光和两团黑紫烟。
- 分裂体出生：短暂半透明 `6-10` 帧，随后实体化。

## Avoid

- 不要把分裂做成两个完整本体，否则奖励和威胁感会误导。
- 不要让裂缝颜色过亮，以免像玩家技能效果。
