# Brute - 甲壳重鬼

## Implementation Status

- 素材状态：已实现并接入，当前对应 `assets/sprites/enemies/enemy_6.png`。
- 玩法状态：专属 `brute` archetype、高血重型数值、霸体窗和重踏尚未实现；当前仍与其他普通敌人共享同一套追踪 AI。

## Role

高血重型敌人。目标是制造空间阻塞和目标优先级，而不是靠速度追杀玩家。

## Target Size

宽 `115-145px`，高 `55-80px`。重型低矮，不要像普通爬行怪。

## Visual Identity

- 远看是一团低矮厚重的甲壳。
- 低垂骨质头甲，眼点小而凶，头部埋在前壳下。
- 宽厚甲壳覆盖背部，背壳有绿色囊泡或发光腐蚀点。
- 短粗节肢支撑重量，移动时有压地感。
- 前颚或骨刺可作为接触伤害来源。

## Color And Materials

- 主色：黑灰甲壳、骨白头甲、暗绿囊泡。
- 强调色：绿色囊泡低亮度脉动，提示重型危险。
- 材质：硬甲、骨质、腐蚀液体。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 移动 | 身体上下起伏很小，脚步慢但有重量 |
| 霸体前摇 | 背壳收紧，囊泡变亮，身体压低 |
| 重踏/撞击 | 前端猛压地面或短距离顶撞 |
| 受击 | 甲壳震动，囊泡闪烁，不要大幅后仰 |
| 死亡 | 背壳裂开，绿色光熄灭后塌陷 |

## Avoid

- 不要让它移动姿态太灵活，否则会和 `crawler` 混淆。
- 不要让绿色特效太亮，避免抢过奖励和玩家技能可读性。
