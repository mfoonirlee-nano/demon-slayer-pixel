# Brute - 甲壳重鬼

## Implementation Status

- 素材状态：已重做并接入，当前 `assets/sprites/enemies/brute/brute_advance.png` 是 `advance`，另有 `brute_brace.png`、`brute_stomp.png`、`brute_recover.png`；攻击读招已烘进动作图集。
- 玩法状态：已接入专属 `brute` archetype，当前实现为 `advance -> brace -> stomp -> recover` 的慢速重型循环。
- 代码入口：`src/entities/enemies/brute.ts`；资源入口：`src/constants/assets.ts` 的 `BRUTE_SHEET_INDEX` / `BRUTE_SHEETS`。

## Role

高血重型敌人。目标是制造空间阻塞和目标优先级，而不是靠速度追杀玩家。

## Gameplay Loop

| 状态 | 当前规则 | 设计目的 |
| --- | --- | --- |
| `advance` | 慢速面向玩家推进 | 制造阻挡压力，但不高速贴脸 |
| `brace` | 进入距离后停顿 `26-34` 帧，素材内逐帧压低并让头部/前甲开始发绿光 | 给玩家读招和拉开时间 |
| `stomp` | 短距离前顶 `14-18` 帧，素材内烘入头部高亮和前方气浪，并在冲击窗口只触发一次矩形打击 | 明确高伤威胁，避免多次判定 |
| `recover` | 停住 `24-34` 帧，使用同尺度低姿态恢复帧，头部/前甲从亮绿色逐帧恢复原色 | 露出反打窗口 |

## Current Tuning

| 参数 | 当前值 | 说明 |
| --- | ---: | --- |
| 触发距离 | `150px` | 进入距离后尝试前摇 |
| 推进速度 | `0.42 + elapsed*0.006 + rand(0.22)` | 慢速重型推进 |
| 生命 | 基础敌人生命的 `4.25x` | 高血目标，明显区别普通敌人 |
| 绘制缩放 | `1.12x` | 保持低矮但更有体量 |
| 同屏上限 | `2` | 避免高血单位堆场 |
| 同时前摇/重踏 | `1` | 避免多个重踏叠加不可读 |
| 霸体减伤 | `50%` 非大招伤害 | `brace/stomp` 期间减伤但不免疫，大招全额 |

## Target Size

宽 `115-145px`，高 `55-80px`。重型低矮，不要像普通爬行怪。

## Visual Identity

- 远看是一团低矮厚重的甲壳。
- 低垂骨质头甲，眼点小而凶，头部埋在前壳下。
- 宽厚甲壳覆盖背部，背壳有绿色囊泡或发光腐蚀点。
- 短粗节肢支撑重量，移动时有压地感。
- 前颚或骨刺可作为接触伤害来源。

## Color And Materials

- 主色：黑灰甲壳、骨白头甲、暗绿囊泡。
- 强调色：绿色囊泡低亮度脉动，提示重型危险。
- 材质：硬甲、骨质、腐蚀液体。

运行时只负责切换 `brace` / `stomp` / `recover` 图集和结算既有命中盒，不再额外绘制头光、地面预警、地裂、尘土或气浪覆盖层。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 移动 | 身体上下起伏很小，脚步慢但有重量 |
| 霸体前摇 | 背壳收紧，囊泡变亮，身体压低 |
| 重踏/撞击 | 前端猛压地面或短距离顶撞 |
| 受击 | 甲壳震动，囊泡闪烁，不要大幅后仰 |
| 死亡 | 背壳裂开，绿色光熄灭后塌陷 |

## Avoid

- 不要让它移动姿态太灵活，否则会和 `crawler` 混淆。
- 不要让绿色特效太亮，避免抢过奖励和玩家技能可读性。
