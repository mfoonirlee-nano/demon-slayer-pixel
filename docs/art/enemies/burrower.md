# Burrower - 土潜鬼

## Implementation Status

- 素材状态：未实现。
- 玩法状态：未实现。

## Role

潜行包抄敌人，用来打破玩家贴边站位和单方向清线。

## Target Size

宽 `100-130px`，高 `45-75px`。潜行时只露地面痕迹。

## Visual Identity

- 贴地、挖掘、从土里突袭。
- 轮廓要像低矮钻地怪，而不是普通四足爬行敌人。

## Shape Details

| 部位 | 描述 |
| --- | --- |
| 头部 | 额头有铲形骨板或硬壳，眼睛靠两侧，钻出时先露出头甲 |
| 身体 | 低矮长条，背部覆土、碎石和硬壳片，腹部贴地 |
| 前肢 | 两只巨大铲爪是主要识别点，边缘像骨铲或铁锹 |
| 后肢 | 短小，用来支撑，不抢前爪视觉 |
| 服饰 | 不建议做人形衣物，避免和 `crawler` 混淆 |

## Color And Materials

- 主色：湿土棕、灰黑硬壳、暗绿霉斑。
- 强调色：钻出前的地面裂痕可用暗橙或红褐。
- 材质：泥土、甲壳、磨损骨质。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 地面移动 | 身体左右摆动，铲爪交替刮地 |
| 潜入前摇 | 前爪高举，头甲压低，身体开始被土遮住 |
| 潜行 | 不显示完整身体，只显示移动土包、裂缝或短暂露出的背刺 |
| 钻出 | 铲爪先破土，头甲随后顶出，形成明确攻击帧 |
| 恢复 | 抖落泥土，短暂停顿，给玩家普攻窗口 |

## Effects

- 潜行轨迹：地面隆起线，移动速度可读。
- 钻出预警：目标点先出现 `24-32` 帧裂纹和土尘。

## Avoid

- 不要完全隐形，玩家必须能追踪威胁。
- 不要让钻出点直接覆盖玩家中心，视觉上要留半个身位反应空间。
