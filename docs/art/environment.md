# 环境与气候美术设定

环境与气候素材服务于月夜赶路的氛围和景深，不承担伤害判定或攻击预警。它们应延续暗靛天空、蓝黑树线、冷灰石地与低饱和旧木的色彩语法，让亮白与高纯月潮蓝继续属于玩家，让鲜红和高亮黄继续优先表达危险。

## 树线

- 基础树线保持松、杉、柳、枯木和低矮灌木的轮廓轮换；源素材至少保留 `2x` 运行时像素密度，运行时缩小绘制，不用最近邻放大旧图伪造高清细节。
- 稀疏高树位于基础树线后方，每个近景循环只出现少量直杉、分叉古杉、偏冠松或风折杉。高树之间保持不等距，树冠高度和枝间负空间明显不同，用单个清晰的高点打破连续平顶，不能拼成不透光的整面树墙。
- 高树只承担景深和剪影，不作为敌人出生遮挡物；它们不得携带蛛网、血痕、铃铛、纸垂、注连绳等逐幕身份符号，以免与 Boss 主题环境物件混淆。
- 树木继续使用深靛、蓝黑、冷灰、低饱和旧木和少量暗苔；月蓝只作为弱边光，不使用玩家专属的高纯亮蓝、亮白或危险提示的鲜红与高亮黄。
- 每棵树必须完整保留树冠、根部、透明边缘和底部锚点。像素簇应清晰、边缘透明级数受控，大屏背板放大后不能出现绿边、软雾边或被裁断的枝叶。

## 落叶

- 参考 `assets/sprites/background/foreground_sprites.png`、`assets/sprites/tree/tree_sprites.png`、`assets/sprites/ground/moon_forest_ground_base.png` 与 `assets/sprites/scenery/act-occluders/fang-gale-windbent-pine.png` 的月夜森林明度和像素密度。
- 落叶按树冠轮廓分为松针枝束、柳叶、阔椭圆叶和竹叶四类；叶型必须由实际释放它的树变体决定，枯树不释放叶片。远层绑定高杉，近层绑定基础树线，叶片先从可见树冠内脱离，再独立随重力、摆动与阵风下落。
- 叶片使用低饱和铜褐、冷赭、暗酒红和暗靛轮廓，只允许极弱的月蓝边光；禁止鲜红攻击色、大面积高亮黄、青绿残边和自发光光晕。
- 每类翻滚序列中的八帧必须保持同一枚叶片或针束的轮廓、叶柄、尺度和中心锚。薄边帧可以收窄，但不能消失；首尾姿态必须能连续循环。
- 素材只承载叶片本体和翻转，不烘入树枝、风线、阴影、地面或整屏粒子。四边保留透明 gutter，运行时再用远近两层的移动速度、密度和透明度建立景深。
