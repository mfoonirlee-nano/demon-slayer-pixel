# Mist Bone - 下弦之鬼 · 雾骨

## Implementation Status

- 素材状态：未实现。
- 玩法状态：未实现；目标定位为区域封锁型 Boss。

## Role

区域封锁型 Boss，依靠雾障、骨刺和延迟爆发压缩站位。

## Setting Copy

| 项 | 文案 |
| --- | --- |
| 一句话设定 | 藏在白雾里的瘦长恶鬼，将被吞噬者的骨片磨成钉，从看不清的角落刺穿猎物。 |
| 登场提示 | 山雾贴地滚来，碎骨在雾中轻响。 |
| 血条标题 | `下弦之鬼 · 雾骨 · 阶段 {phase}` |

## Character Brief

雾骨不喜欢正面迎击。它会先铺开低矮的白雾，遮断炭治郎的移动判断，再用骨钉逼迫玩家离开安全位置。进入末段后，雾气不再只是掩护，而会变成连续爆开的骨林。

## Visual Identity

- 瘦长骨形身体，肩、肘、背部有外露骨刺。
- 主色偏灰白、雾蓝和枯骨色，避免大面积接近玩家水蓝技能色。
- 下半身可被白雾半遮，但脚下威胁点必须清晰。
- 远看应读成“白雾中站起的骨刺鬼”。

## Phase Copy

| 阶段 | 名称 | 设定表现 | 玩法标签 |
| --- | --- | --- | --- |
| 1 | 起雾 | 用薄雾和少量骨刺试探玩家移动路线。 | 慢速区域、单发投射物 |
| 2 | 埋骨 | 雾中开始出现延迟骨钉，玩家需要提前离开落点。 | 延迟预警、地面陷阱 |
| 3 | 白葬 | 骨刺成排爆发，Boss 趁玩家换位时追击。 | 区域封锁、追踪冲撞 |

## Skill Copy

| 技能 | 文案 | 玩法标签 |
| --- | --- | --- |
| 雾骨钉 | 雾骨抬手碾碎骨片，向前射出一串白色骨钉。 | 多段投射物 |
| 白雾埋身 | 它把雾气压到地面，短暂标记数个危险点，随后骨刺破土。 | 延迟区域封锁 |
| 骨林合围 | 雾骨退入白雾，左右两侧依次升起骨刺，逼迫玩家跳跃或反向移动。 | 组合技能 |

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 待机 | 白雾贴地流动，骨刺轻微开合 |
| 施法 | 身体后仰，骨片从手臂或背部剥落 |
| 骨刺预警 | 地面先出现白雾旋涡或骨尖阴影 |
| 死亡 | 骨架散落，雾气被水流或风吹开 |

## Avoid

- 不要让雾完全遮住地面预警。
- 不要把骨刺做成纯白细线，低分辨率下需要暗边。
- 不要同时强调太多骨刺方向，核心威胁必须可读。
