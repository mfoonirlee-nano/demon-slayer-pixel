# Mist Bone - 血月眷属 · 雾骨

## Role

区域封锁型 Boss，依靠雾障、骨刺和延迟爆发压缩站位。

## Character Brief

雾骨不喜欢正面迎击。它会先铺开低矮的白雾，遮断潮刃者的移动判断，再用骨钉逼迫玩家离开安全位置。进入末段后，雾气不再只是掩护，而会变成连续爆开的骨林。

## Visual Identity

- 瘦长骨形身体，肩、肘、背部有外露骨刺。
- 主色偏灰白、雾蓝和枯骨色，避免大面积接近玩家水蓝技能色。
- 下半身可被白雾半遮，但脚下威胁点必须清晰。
- 远看应读成“白雾中站起的骨刺妖”。

## Phase Copy

| 阶段 | 名称 | 设定表现 | 玩法标签 |

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 待机 | 白雾贴地流动，骨刺轻微开合 |
| 施法 | 身体后仰，骨片从手臂或背部剥落 |
| 骨刺预警 | 地面先出现白雾旋涡或骨尖阴影 |
| 死亡 | 骨架散落，雾气被水流或风吹开 |

## Avoid

- 不要让雾完全遮住地面预警。
- 不要把骨刺做成纯白细线，低分辨率下需要暗边。
- 不要同时强调太多骨刺方向，核心威胁必须可读。

## 蚀醒形态（第 8 幕）

蚀醒形态 = 基础雾骨 + 一招蚀醒妖术 + 多一阶段（阈值 `[0.75, 0.5, 0.25]`）+ 强化召唤池，**复用基础精灵**。数值与机制见 [../../numeric-system/boss-archetypes.md](../../numeric-system/boss-archetypes.md)。

| 项 | 设定 |
| --- | --- |
| 血条标题 | `血月眷属 · 雾骨·蚀醒 · 阶段 {phase}` |
| 登场提示 | 浓雾涌起，多处骨影同时浮现。 |
| 蚀醒视觉态 | 基础精灵叠加更浓雾气环绕 + 骨架泛冷光；不重画身体 |
| 蚀醒妖术 | **浓雾葬**：短时遮蔽视野（屏幕局部起雾，不全黑）+ 多点延迟骨刺连爆；玩家靠预警点与落点记忆躲避 |
| 强化召唤 | 在基础召唤池上加入 `warden`，雾中支援其余敌人 |

新增美术需求（仅特效）：可控范围的视野遮蔽层（保留地面预警可见）、多点骨爆预警标记、连爆先后的节奏提示。遮蔽必须始终留出预警点的可读度，不能让玩家"盲打"。
