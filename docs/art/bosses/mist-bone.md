- 素材状态：已接入 `assets/sprites/boss/mist-bone/`，包含普攻、三种施法读招、地刺、飞行骨钉，以及三套可循环雾序列帧。
- 玩法状态：已完整接入；定位为区域封锁型 Boss，基础形态包含薄雾减速、斜落雾骨钉、延迟骨刺、骨刺线与 P3 锁向追击，蚀醒形态包含浓雾葬、冷骨光、环身浓雾和支援召唤。

## Role

区域封锁型 Boss，依靠雾障、骨刺和延迟爆发压缩站位。

## Character Brief

雾骨不喜欢正面迎击。它会先铺开低矮的白雾，遮断潮刃者的移动判断，再用骨钉逼迫玩家离开安全位置。进入末段后，雾气不再只是掩护，而会变成连续爆开的骨林。

## Visual Identity

- 瘦长骨形身体，肩、肘、背部有外露骨刺。
- 主色偏灰白、雾蓝和枯骨色，避免大面积接近玩家水蓝技能色。
- 下半身可被白雾半遮，但脚下威胁点必须清晰。
- 远看应读成“白雾中站起的骨刺妖”。

三套图集都是不含角色的透明效果序列。运行时在同一雾区重复布置多组实例，并为三套序列使用不同帧节拍、起始帧和位置相位，避免整片雾同步翻动或显出单张贴图的重复边界。薄雾、浓雾葬、蚀醒环身雾和死亡散雾都必须从这些图集裁帧绘制，不再用 Canvas 椭圆或路径制造雾的可见轮廓。

## Runtime Cadence

- 普攻总长 `48` 帧，第 `24` 帧开始释放；阶段 1/2/3 依次发射 1/2/3 枚斜落骨钉，间隔 `6` 帧，起手后锁定方向。
- 普攻只在中距离、特殊技未就绪且自身攻击间隔结束时触发；完整收招后才恢复移动。
- 基础形态从阶段 2 起确定性交替单点与成列地刺；蚀醒形态按合围、单点、成列循环，避免连续随机到同一读招。
- 单点与成列地刺会在锁定区域铺开低矮薄雾；玩家脚底进入椭圆玩法区域时降低常态横向移动速度，离开或雾散后立即恢复。椭圆只保留为减速判定足迹，可见雾由三套图集错速、错相堆叠，且不会覆盖地刺预警。
- 薄雾或地刺在移动、悬浮平台上锁定时，雾区、减速足迹和骨刺命中框都保存相对平台锚点并随平台移动；雾的初始图片相位保持固定，不会因平台位移逐帧跳帧。
- P3 成列地刺施法结束后，雾骨沿施法时锁定的朝向直线追击；冲撞只判定一次，随后进入明确恢复窗口。
- 蚀醒合围会在玩家附近生成短时局部浓雾遮蔽，并让七根骨刺按两侧向中心的延迟顺序爆发；浓雾本身不叠加薄雾减速，既有遮蔽强度和寿命不变，地面预警始终绘制在图片雾层之上。
- 蚀醒本体复用基础精灵；环身浓雾使用三套雾图集错相叠放，骨架冷光继续使用既有 Canvas `filter`。P4 合围同时召来一名蚀醒 `warden` 和一名普通同伴，由守望者在雾中提供支援。
- 击败时保留统一的 `60` 帧结算冻结，先以三套雾图集表现雾团吹散，再绘制本体骨架碎片散落；不需要新增死亡本体图集。
- 施法、骨钉发射、地刺预警、地刺破土、锁向追击和击败分别使用一条雾骨专属 SFX，共 `6` 条采样。

## Avoid

- 不要让雾完全遮住地面预警。
- 不要把骨刺做成纯白细线，低分辨率下需要暗边。
- 不要同时强调太多骨刺方向，核心威胁必须可读。

## 蚀醒形态（第 8 幕）

蚀醒形态 = 基础雾骨 + 一招蚀醒妖术 + 多一阶段（阈值 `[0.75, 0.5, 0.25]`）+ 强化召唤池，**复用基础精灵**。数值与机制见 [../../numeric-system/boss-archetypes.md](../../numeric-system/boss-archetypes.md)。

| 项 | 设定 |
| --- | --- |
| 血条标题 | `血月眷属 · 雾骨·蚀醒 · 阶段 {phase}` |
| 登场提示 | 浓雾涌起，多处骨影同时浮现。 |
| 蚀醒视觉态 | 已接入：基础精灵叠加三套错速、错相的图片雾 + 既有 Canvas 冷骨光 `filter`；不重画身体 |
| 蚀醒妖术 | 已接入：**浓雾葬**短时局部遮蔽视野 + 七点由外向内延迟骨刺连爆；玩家靠预警点与落点记忆躲避 |
| 强化召唤 | 已接入：P4 合围召来一名蚀醒 `warden` 和一名普通同伴，守望者在雾中支援其余敌人 |

所有可见雾层都由三套 RGBA 序列帧重复堆叠，程序只编排裁帧、位置、相位、透明度与寿命，不再用 Canvas 椭圆或路径造雾。薄雾减速足迹、浓雾葬遮蔽、本体冷骨光 `filter`、骨架碎片以及伤害时序保持原有逻辑；局部遮蔽始终留出地面预警的可读度，死亡收尾保持先雾后骨片，不能让玩家“盲打”。
