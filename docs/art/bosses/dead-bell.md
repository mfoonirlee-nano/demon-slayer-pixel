# Dead Bell - 血月眷属 · 枯铃

## Implementation Status

- 素材状态：已完整接入 `assets/sprites/boss/dead_bell/`；基础本体、摇铃、恢复、声波、音刃和蚀醒第二裂铃均为透明运行时 PNG。
- 玩法状态：已完整接入第 6/12 幕；基础形态使用确定性累计节拍、P3 支援和无接触伤害恢复，蚀醒形态追加双频强制停拍、第二裂铃、预算内 `binder` / `warden` 和专属死亡收尾。
- 音效状态：施法、低/高钟音、音刃、止响、违律反震、安全破响和击败共 `8` 条专属采样已接入，加载失败时保留 tone 回退。

## Role

节奏压迫型 Boss。玩家先通过不同钟音和可见边界躲开声波/音刃，再在铃声停止时主动停手，换取一段明确、安全的反击窗口。

## Character Brief

枯铃不是单纯增加弹幕密度。它用稳定循环让玩家学会“低钟—高钟—静默”的因果：声波和音刃逼迫换位，停拍警告要求收刀，成功克制后则以断铃声和垂首恢复姿态明确交出反击权。

## Visual Identity

- 裂开的枯铃是核心物件；蚀醒时第二只裂铃始终可见，不靠短暂全屏变色代替形态差异。
- 身体瘦长、僵直，动作像被铃声牵动；恢复时突然垂首停住，与摇铃形成轮廓反差。
- 低频声波使用旧金/骨白，高频声波使用血红深描边；两者还以不同扩散速度和启动音区分。
- 声波图按每帧可见边界补偿绘制，使视觉外缘与圆形碰撞半径一致；危险边界不能藏在透明 gutter 中。
- 音刃只在可见飞行帧中保持伤害判定，离场前先进入无伤消散帧。

## Runtime Cadence

- 单次施法 `64` 帧，第 `30` 帧生成；组合/双调施法 `86` 帧，第 `34` 帧生成。声波有 `24` 帧内圈警告，再由半径 `54` 扩到目标半径；低频扩散 `76` 帧，高频约快 `12%`。
- 普通声波、双圈和组合按阶段分别构成 `1`、`2`、`3` 项确定性循环；进入 P2/P3 时先出该阶段的新考题，再轮换已学节拍。所有延迟波与音刃在自身真正启动的帧播放专属音效，不在创建延迟实例时提前发声。
- 音刃始终保留独立 `20` 帧可见警告，较晚的节拍只延后警告开始，不会把蓄势拉长成 `52` 帧。前 `2` 个素材帧只做蓄势；飞行中循环可见核心帧，消散帧不再造成伤害。
- 基础 P3 的每次组合招拥有一个 director 召唤池支援槽；预算或 debug 自动生成开关阻止时只消费当前槽，等完整三招循环回到下一次组合再尝试，不逐帧重试。
- 蚀醒每个新阶段的第一次安全施法强制使用双调；随后从该阶段标志招开始常规循环，P4 循环中再加入双调，因此不会只在低血阶段偶然出现。非双调施法还会比基础形态少 `12` 帧冷却，但不低于 `148` 帧。
- 双调 P1 先出一低一高两圈；P2 加入一枚锁定玩家高度的音刃；P3/P4 再加入第三个低频大圈和另一高度音刃，逐阶段累积复杂度。
- 双调结束后依次进入 `30` 帧停拍警告、最多 `42` 帧反震激活和完整 `54` 帧安全反击。警告期间持续刷新玩家动作序号，所以只惩罚激活后新开始的普攻、落击、技能或终式，不追罚已经承诺的动作。
- 反震若命中会立即结束激活判定，并把剩余恢复压到标准 `54` 帧反击窗；若违规起手暂带启动无敌，则冻结当前节拍与恢复计时直到伤害可结算，不能靠无敌覆盖掉违规。玩家若完整停手，也会在激活期结束后进入同样完整的 `54` 帧窗口并播放安全破响。两条路径都没有额外激活空档，整个恢复阶段 Boss 不造成身体接触伤害。
- 蚀醒组合槽在强化专员与基础 director 池之间确定性交替：P3 先尝试蚀醒 `binder`、下一轮回到基础池；P4 先尝试蚀醒 `warden`、下一轮回到基础池。所有尝试都使用 Boss 召唤成本、数量和同类 cap。
- 击败枯铃时立即清空全部声波、音刃和 Boss 召唤物，并在统一 `60` 帧结算冻结中把独立裂铃裁成两块分离、让最多三圈悬停声波消散，同时播放专属死亡音效。

## Avoid

- 不要把难度做成随机连招或单纯提高弹幕数量；玩家必须能预测下一个节拍。
- 不要让声波外观小于碰撞环，或让不可见音刃继续伤人。
- 不要让停拍警告追罚警告前已经起手的动作，也不要在违律反震后省略或缩短标准 `54` 帧安全反击窗。
- 不要让召唤绕过 director 预算或在同一阶段失败后逐帧重试。
- 不要把尚未绘制的登场/击败短句写成已接入功能；当前对应形态提示是持续绘制的第二裂铃。

## 蚀醒形态（第 12 幕）

枯铃·蚀醒 = 基础确定性节拍 + 四阶段阈值 `[0.75, 0.5, 0.25]` + 双调枯铃 + 第二裂铃 + 强化支援。数值与统一形态规则见 [../../numeric-system/boss-archetypes.md](../../numeric-system/boss-archetypes.md)。

| 项 | 已接入实现 |
| --- | --- |
| 血条标题 | `血月眷属 · 枯铃·蚀醒 · 阶段 {phase}` |
| 登场提示 | 设定文案为“双铃错响，节拍裂成两条。”；当前未接入短句 UI |
| 蚀醒视觉态 | 基础本体后方持续叠加 `dead_bell_awakened_echo_bell.png`，第二裂铃与主铃错相摆动 |
| 蚀醒妖术 | 每阶段强制首发双调，P4 循环重现；双频错相后执行 `30 / 42 / 54` 帧停拍协议 |
| 强化召唤 | P3 一次蚀醒 `binder` 尝试、P4 一次蚀醒 `warden` 尝试，严格服从 Boss 召唤预算 |

双频的辨识由素材着色、扩散速度和专属低/高钟音共同承担；任一通道加载失败时，另两种提示仍应足以判断。第二裂铃是持续形态标识，不改变本体碰撞或阶段生命公式。
