# Dead Bell - 血月眷属 · 枯铃

## Implementation Status

- 素材状态：未实现。
- 玩法状态：未实现；目标定位为节奏压迫和组合弹幕 Boss。

## Role

节奏压迫型 Boss，通过铃声波纹和组合弹幕制造固定节拍压力。

## Setting Copy

| 项 | 文案 |
| --- | --- |
| 一句话设定 | 它摇响挂满裂纹的枯铃，让声音变成刀刃，逼迫猎物按它的节奏行动。 |
| 登场提示 | 铃声从远处响起，下一声已经贴近耳边。 |
| 血条标题 | `血月眷属 · 枯铃 · 阶段 {phase}` |
| 击败提示 | 最后一声铃响断在半空。 |

## Character Brief

枯铃适合后期登场。它的攻击有清晰节奏，但组合后会形成连续判断：先躲环形声波，再处理横向音刃，最后抓住铃声停止的短暂间隔反击。它强调读节奏，而不是纯粹反应速度。

## Visual Identity

- 裂开的枯铃是核心物件，可挂在手杖、背架或胸前。
- 身体可瘦长、僵直，动作像被铃声牵动。
- 声波环使用暗金、灰白或血红描边，必须可读出扩散范围。
- 停拍时角色姿态突然静止，形成明显反差。

## Phase Copy

| 阶段 | 名称 | 设定表现 | 玩法标签 |
| --- | --- | --- | --- |
| 1 | 初响 | 铃声形成单圈波纹，节奏稳定。 | 环形预警 |
| 2 | 复响 | 第二道铃声延迟出现，玩家需要连续躲避。 | 延迟二段 |
| 3 | 丧钟 | 铃声、音刃和召唤物交替出现，反击窗口集中在一小段停拍。 | 组合弹幕、召唤 |

| --- | --- | --- |
| 枯铃震 | 枯铃摇出扩散声波，靠近中心越危险。 | 环形区域 |
| 裂音刃 | 它把铃声压成横向刀刃，沿地面或半空切过战场。 | 多层投射物 |

## Avoid

- 不要让声波环完全透明，低分辨率下会读不出危险边界。
- 不要把每次铃声都画成全屏闪光。
- 不要让停拍阶段没有视觉提示，玩家需要知道反击窗口到了。

## 蚀醒形态（第 12 幕）

蚀醒形态 = 基础枯铃 + 一招蚀醒妖术 + 多一阶段（阈值 `[0.75, 0.5, 0.25]`）+ 强化召唤池，**复用基础精灵**。枯铃·蚀醒是蚀醒段最后一关，强度最高。数值与机制见 [../../numeric-system/boss-archetypes.md](../../numeric-system/boss-archetypes.md)。

| 项 | 设定 |
| --- | --- |
| 血条标题 | `血月眷属 · 枯铃·蚀醒 · 阶段 {phase}` |
| 登场提示 | 双铃错响，节拍裂成两条。 |
| 蚀醒视觉态 | 基础精灵叠加第二只裂铃 + 声波描边加深；不重画身体 |
| 蚀醒妖术 | **双调枯铃**：双频错相声波环 + 强制停拍反震；玩家须在停拍窗口内停手，否则被反震 |
| 强化召唤 | 在基础召唤池上加入 `binder`/`warden`，停拍间隙仍有控场压力 |

新增美术需求（仅特效）：两组不同频率的声波环（颜色/扩散速度区分）、强制停拍的全局节拍提示、反震判定的可读窗口。两频声波必须能分辨先后，停拍窗口与反震时机要有明确视觉信号，避免变成"听不懂的节奏"。
