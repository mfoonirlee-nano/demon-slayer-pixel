- 素材状态：未实现。
- 玩法状态：未实现；目标定位为高速冲刺和近身压迫 Boss。

## Role

近身压迫型 Boss，以高速冲刺和连续撕咬逼迫反应。

## Character Brief

牙岚几乎不使用复杂术式。它的强度来自速度、转身和假冲刺：先用短距离逼近打乱节奏，再突然拉远蓄力，沿直线撕穿战场。它适合成为检验走位和下落攻击时机的 Boss。

## Visual Identity

- 身体低伏前倾，长臂、尖牙和后扬鬃毛形成速度感。
- 牙和爪是最亮识别点，身体主色保持暗红、深灰或风蚀棕。
- 冲刺前身体要压低，像蓄满力的兽影。
- 风刃特效可用浅灰白，边缘带暗色描边。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 待机 | 重心压低，脚爪抓地，尾迹或鬃毛轻摆 |
| 蓄力 | 肩背拱起，尖牙前探，方向明确 |
| 冲刺 | 身体拉成长形残影，但头部和牙仍可读 |
| 死亡 | 断牙飞出，身体滑行后倒地 |

## Avoid

- 不要把身体画得过高，否则会失去贴地冲刺感。
- 不要让冲刺残影盖住真身方向。
- 不要加入复杂施法道具，它应保持肉搏压迫。

## 蚀醒形态（第 10 幕）

蚀醒形态 = 基础牙岚 + 一招蚀醒妖术 + 多一阶段（阈值 `[0.75, 0.5, 0.25]`）+ 强化召唤池，**复用基础精灵**。数值与机制见 [../../numeric-system/boss-archetypes.md](../../numeric-system/boss-archetypes.md)。

| 项 | 设定 |
| --- | --- |
| 血条标题 | `血月眷属 · 牙岚·蚀醒 · 阶段 {phase}` |
| 登场提示 | 狂风成壁，兽影一闪即跨过半场。 |
| 蚀醒视觉态 | 基础精灵叠加风刃尾迹加密 + 尖牙泛血光；不重画身体 |
| 蚀醒妖术 | **岚牙连闪**：三段跨场冲刺连段，每段起手方向不同；玩家须连续读三次起手方向，找跳 / 反击窗口 |
| 强化召唤 | 在基础召唤池上加入 `burrower`，逼迫玩家在连闪间隙也要管身后 |

新增美术需求（仅特效）：三段连闪各自的起手方向预警（残影/风线指向）、段与段之间的短硬直提示。每段起手必须可读，最后一段硬直最长以保留反击窗口，不能做成无解连段。
