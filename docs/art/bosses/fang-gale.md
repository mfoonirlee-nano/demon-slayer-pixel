# Fang Gale - 下弦之鬼 · 牙岚

## Implementation Status

- 素材状态：未实现。
- 玩法状态：未实现；目标定位为高速冲刺和近身压迫 Boss。

## Role

近身压迫型 Boss，以高速冲刺和连续撕咬逼迫反应。

## Setting Copy

| 项 | 文案 |
| --- | --- |
| 一句话设定 | 它像风暴中的兽影一样贴地奔行，用不断加速的牙击撕开防线。 |

| 血条标题 | `下弦之鬼 · 牙岚 · 阶段 {phase}` |

## Character Brief

牙岚几乎不使用复杂术式。它的强度来自速度、转身和假冲刺：先用短距离逼近打乱节奏，再突然拉远蓄力，沿直线撕穿战场。它适合成为检验走位和下落攻击时机的 Boss。

## Visual Identity

- 身体低伏前倾，长臂、尖牙和后扬鬃毛形成速度感。
- 牙和爪是最亮识别点，身体主色保持暗红、深灰或风蚀棕。
- 冲刺前身体要压低，像蓄满力的兽影。
- 风刃特效可用浅灰白，边缘带暗色描边。

## Phase Copy

| 阶段 | 名称 | 设定表现 | 玩法标签 |
| --- | --- | --- | --- |
| 1 | 试咬 | 用短冲刺接触玩家，攻击前摇清晰。 | 近身追击 |
| 2 | 狂奔 | 冲刺距离变长，并穿插后撤蓄力。 | 直线冲锋、假动作 |
| 3 | 牙岚 | 连续冲刺后追加撕咬波，留给玩家的反击窗口更短。 | 连击、单向斩波 |

## Skill Copy

| 技能 | 文案 | 玩法标签 |
| --- | --- | --- |
| 断牙突 | 牙岚压低身体向前猛冲，路径上的目标都会被撞开。 | 直线冲锋 |
| 风牙裂 | 它在冲刺末端挥出爪牙风刃，补击试图追身反打的玩家。 | 单向斩波 |
| 三段兽影 | 牙岚连续三次变向突进，最后一次速度最快但硬直最长。 | 组合突进 |

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 待机 | 重心压低，脚爪抓地，尾迹或鬃毛轻摆 |
| 蓄力 | 肩背拱起，尖牙前探，方向明确 |
| 冲刺 | 身体拉成长形残影，但头部和牙仍可读 |
| 死亡 | 断牙飞出，身体滑行后倒地 |

## Avoid

- 不要把身体画得过高，否则会失去贴地冲刺感。
- 不要让冲刺残影盖住真身方向。
- 不要加入复杂施法道具，它应保持肉搏压迫。
