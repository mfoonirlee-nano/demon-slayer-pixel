## Character Brief

牙岚几乎不使用复杂术式。它的强度来自速度、转身和假冲刺：先用短距离逼近打乱节奏，再突然拉远蓄力，沿直线撕穿战场。它适合成为检验走位和下落攻击时机的 Boss。

## Visual Identity

- 身体低伏前倾，长臂、尖牙和后扬鬃毛形成速度感。
- 牙和爪是最亮识别点，身体主色保持暗红、深灰或风蚀棕。
- 冲刺前身体要压低，像蓄满力的兽影。
- 风刃特效可用浅灰白，边缘带暗色描边。

## Skill Copy

| 技能 | 文案 | 玩法标签 |
| --- | --- | --- |
| 断牙突 | 牙岚压低身体向前猛冲，路径上的目标都会被撞开。 | 直线冲锋 |
| 风牙裂 | 它在冲刺末端挥出爪牙风刃，补击试图追身反打的玩家。 | 单向斩波 |
| 岚牙连闪 | 牙岚连续三次变向突进，最后一次速度提升 20%，但硬直最长。 | 组合突进 |

`cast`、段间转向和恢复都是安全读招/反击窗口，不造成身体接触伤害。普通移动仍有接触伤害；冲刺只按脚底对齐的身体核心攻击框结算。风牙裂只在最后一段冲刺结束后生成一枚，并按玩家当时所在方向飞行。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 待机 | 重心压低，脚爪抓地，尾迹或鬃毛轻摆 |
| 蓄力 | 肩背拱起，尖牙前探，方向明确 |
| 后撤 | 面向玩家抓地倒跃，始终保持低伏轮廓 |
| 转向 | 段间刹停、回首并明确下一段冲刺方向 |
| 扑咬 | 低身向前扑出，张口和前爪形成普攻读法 |
| 终段扑咬 | 身体拉伸更充分，牙光和受控风线更强，但真身方向仍可读 |
| 恢复 | 刹停、短暂失衡后重新撑地，形成清晰反击窗口 |
| 死亡 | 断牙飞出，身体滑行后倒地 |

## Avoid

- 不要把身体画得过高，否则会失去贴地冲刺感。
- 不要让冲刺残影盖住真身方向。
- 不要加入复杂施法道具，它应保持肉搏压迫。

## 蚀醒形态（第 10 幕）

蚀醒形态 = 基础牙岚 + 一招蚀醒妖术 + 多一阶段（阈值 `[0.75, 0.5, 0.25]`）+ 强化召唤池。基础身份与配色保持不变，岚牙连闪第三段使用专用终段扑咬序列。数值与机制见 [../../numeric-system/boss-archetypes.md](../../numeric-system/boss-archetypes.md)。

| 项 | 设定 |
| --- | --- |
| 血条标题 | `血月眷属 · 牙岚·蚀醒 · 阶段 {phase}` |
| 登场提示 | 狂风成壁，兽影一闪即跨过半场。 |
| 蚀醒视觉态 | 基础精灵叠加风刃尾迹加密 + 尖牙泛血光；不重画身体 |
| 蚀醒妖术 | **岚牙连闪**：三段跨场冲刺连段，段间交替方向；第三段提速 20%，结束后进入 66 帧安全恢复。玩家须连续读三次起手方向，再抓反击窗口 |
| 强化召唤 | 在基础召唤池上加入 `burrower`，逼迫玩家在连闪间隙也要管身后 |

三段连闪使用 `turn` 序列表现每次段间变向，以 `final_bite` 强调第三段提速，并用 `recover` 明确最终长硬直。每段起手必须可读，最后一段硬直最长以保留反击窗口，不能做成无解连段。

## Runtime Contract

- 普通阶段权重：P1 `断牙突 100%`；P2 `断牙突 56% / 风牙裂 44%`；P3 `断牙突 34% / 风牙裂 66%`。
- 蚀醒阶段权重：P1 `88/0/12`、P2 `56/22/22`、P3 `34/32/34`、P4 `20/20/60`，顺序均为 `断牙突 / 风牙裂 / 岚牙连闪`。
- P2 以上的风牙裂与岚牙连闪先后撤 `18` 帧，每帧 `3.2px`；P3 风牙裂两段，岚牙连闪固定三段。
- 每套动作在恢复结束后才进入追逐冷却，P1-P4 分别为 `72 / 64 / 56 / 48` 帧。
- 冲刺攻击框为脚底对齐的 `160x120`；风刃核心攻击框为 `64x48`。鬃毛、爪尖与风线拖尾不参与命中。
