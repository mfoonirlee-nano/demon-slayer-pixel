## Role

干扰型 Boss，通过镜影分身和反射弹制造误判。

## Character Brief

镜魇的威胁不在单次伤害，而在不断制造错误目标。它会留下短暂镜影吸引攻击，并让飞出的镜片在边界折返。玩家需要根据实体动作和弹道节奏判断真正的攻击窗口。

## Visual Identity

- 身体像被镜片切割过，外轮廓有不连续的反光碎边。
- 真身轮廓更实，镜影更透明、更冷色。
- 关键识别物是悬浮碎镜或镜面面具。
- 反射弹要有清楚的亮边和运动方向，不能和普通粒子混淆。

## Runtime Cadence

- P3 的「镜中噩梦」在施法释放帧锁定镜阵位置与真身突进端点，以四个镜位中的一个承载
  不透明真身，其余三个保留为冷色假身；镜阵锁定后不再追踪玩家。
- 镜阵出现后保留 `32` 帧读招，真身再用 `18` 帧横穿到另一侧镜位。贴地命中盒每次突进
  只结算一次，随后按滑停、低身暴露、起身三帧进入 `40` 帧无接触伤害恢复，给玩家明确
  反击窗口。
- P3 的镜影从突进开始后依次转为原地镜面，各自用 `mirror_nightmare.png` 完整播放
  `6` 帧聚能破碎序列；每面镜在末帧结束后瞄准玩家当前位置，再散射 `3` 枚小镜片。
  首轮弹幕落在真身恢复阶段，避免抢走突进方向的视觉焦点。
- 蚀醒形态在 P1 开场及后续新阶段的首个安全窗口执行一次 `真影错位`；旧真身位置留下
  假身，新真身落点不叠放假身。阶段换位完成后继续轮换基础三招，不会在 P4 连续占用施法；
  首次进入 P3 时额外召来一名蚀醒 `splitter`，整场只尝试一次。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 待机 | 身边镜片缓慢漂浮，真身不要过透明 |
| 位移 | 原地残留镜影；突进后依次播放滑停、低身暴露和起身，清楚标记反击窗口 |
| 反射 | 镜片撞边时闪一次，提示路径改变 |
| 死亡 | 镜面从脸部或胸口开始碎裂 |

## Avoid

- 不要让镜影和真身完全一样，玩家必须能在短时间内读出差异。
- 不要让反射弹无预警改变方向。
- 不要使用过多纯白闪光，避免遮挡玩家攻击特效。

## 蚀醒形态（第 9 幕）

蚀醒形态 = 基础镜魇 + 一招蚀醒妖术 + 多一阶段（阈值 `[0.75, 0.5, 0.25]`）+ 强化召唤池，**复用基础精灵**。数值与机制见 [../../numeric-system/boss-archetypes.md](../../numeric-system/boss-archetypes.md)。

| 项 | 设定 |
| --- | --- |
| 血条标题 | `血月眷属 · 镜魇·蚀醒 · 阶段 {phase}` |
| 登场提示 | 镜面尽数翻转，真假身影同时上前。 |
| 蚀醒视觉态 | 已接入：移动、施法和恢复各使用与基础姿态逐帧对齐的透明裂纹覆盖图，为不透明真身新增银蓝分叉镜裂，并叠加窄冷蓝描边；假身继续保持更低透明度，不重画身体 |
| 蚀醒妖术 | 已接入：**真影错位**在 P1 开场及每个后续阶段的首个安全窗口互换真假身；镜魇仅在空闲移动时，对玩家刚释放的普通技能进行一次 `30%` 反射判定。施法、收招或同帧准备起手自身招式时直接放弃本次机会，不会延迟补发。判定成功后先显示 `24` 帧镜影预警，再原地完整播放镜中噩梦发射序列，最后朝发射时的玩家位置射出一枚继承原技能主色、范围与伤害强弱的镜像弹；预警期间若被阶段换相打断则取消。 |
| 强化召唤 | 已接入：首次进入 P3 的真影错位固定尝试召来一名蚀醒 `splitter`，并沿用 Boss 召唤数量、成本和同类上限 |

当前反射物复用 `镜中噩梦` 的原地发射序列、镜片弹与镜影预警，并按被反射技能的主色、判定半径和对 Boss 伤害基准调整亮边、尺寸、速度与伤害；不复刻位移、控制、防反或派生被动。后续若制作逐技能专属外观，应继续保留方向亮边；互换后真身仍须可在短时间内读出，反射物的来源镜影要有清晰指向。
