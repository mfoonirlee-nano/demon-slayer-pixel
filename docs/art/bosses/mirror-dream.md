# Mirror Dream - 血月眷属 · 镜魇

- 素材状态：基础形态已实现，位于 `assets/sprites/boss/mirror-dream/`；不提交 `*_source.png` 制作源图。

## Role

干扰型 Boss，通过镜影分身和反射弹制造误判。

## Setting Copy

| 项 | 文案 |
| --- | --- |
| 一句话设定 | 它把月光磨成碎镜，让猎物在真假身影之间挥空，最后被自己的倒影吞没。 |
| 登场提示 | 月光裂成数片，镜中的夜妖同时抬头。 |
| 血条标题 | `血月眷属 · 镜魇 · 阶段 {phase}` |
| 击败提示 | 镜面碎裂，倒影全部熄灭。 |

## Character Brief

镜魇的威胁不在单次伤害，而在不断制造错误目标。它会留下短暂镜影吸引攻击，并让飞出的镜片在边界折返。玩家需要根据实体动作和弹道节奏判断真正的攻击窗口。

## Visual Identity

- 身体像被镜片切割过，外轮廓有不连续的反光碎边。
- 真身轮廓更实，镜影更透明、更冷色。
- 关键识别物是悬浮碎镜或镜面面具。
- 反射弹要有清楚的亮边和运动方向，不能和普通粒子混淆。

## Phase Copy

| 阶段 | 名称 | 设定表现 | 玩法标签 |
| --- | --- | --- | --- |
| 1 | 映身 | 留下短暂镜影，真身保持中距离牵制。 | 假目标、位移 |
| 2 | 折光 | 镜片开始折返，攻击路径变得不直观。 | 反射投射物 |
| 3 | 破梦 | 多个镜影接连出现，真身从镜影之间突进。 | 分身干扰、突进 |

## Skill Copy

| 技能 | 文案 | 玩法标签 |
| --- | --- | --- |
| 月镜碎片 | 镜魇甩出锋利镜片，镜片撞到边界后折返一次。 | 反射投射物 |
| 假身留影 | 它在原地留下镜影，本体短距离闪到另一侧。 | 位移、假目标 |

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 待机 | 身边镜片缓慢漂浮，真身不要过透明 |
| 位移 | 原地残留镜影，本体有清楚落点姿态 |
| 反射 | 镜片撞边时闪一次，提示路径改变 |
| 死亡 | 镜面从脸部或胸口开始碎裂 |

## Avoid

- 不要让镜影和真身完全一样，玩家必须能在短时间内读出差异。
- 不要让反射弹无预警改变方向。
- 不要使用过多纯白闪光，避免遮挡玩家攻击特效。

## 蚀醒形态（第 9 幕）

蚀醒形态 = 基础镜魇 + 一招蚀醒妖术 + 多一阶段（阈值 `[0.75, 0.5, 0.25]`）+ 强化召唤池，**复用基础精灵**。数值与机制见 [../../numeric-system/boss-archetypes.md](../../numeric-system/boss-archetypes.md)。

| 项 | 设定 |
| --- | --- |
| 血条标题 | `血月眷属 · 镜魇·蚀醒 · 阶段 {phase}` |
| 登场提示 | 镜面尽数翻转，真假身影同时上前。 |
| 蚀醒视觉态 | 基础精灵叠加镜裂纹增多 + 真身冷光描边强化（仍保持真假可读差异）；不重画身体 |
| 蚀醒妖术 | **真影错位**：每阶段开始真假身互换；镜魇仅在空闲移动时，对玩家刚释放的普通技能进行一次 `30%` 反射判定。施法、收招或同帧准备起手自身招式时直接放弃本次机会，不会延迟补发。判定成功后先显示 `24` 帧镜影预警，再朝玩家发射一枚继承原技能主色、范围与伤害强弱的镜像弹；预警期间若被阶段换相打断则取消。 |
| 强化召唤 | 在基础召唤池上加入 `splitter`，制造清场顺序与真假双重误判 |

当前反射物复用 `镜中噩梦` 的镜光弹与镜影预警，并按被反射技能的主色、判定半径和对 Boss 伤害基准调整亮边、尺寸、速度与伤害；不复刻位移、控制、防反或派生被动。后续若制作逐技能专属外观，应继续保留方向亮边；互换后真身仍须可在短时间内读出，反射物的来源镜影要有清晰指向。
