# Mirror Dream - 下弦之鬼 · 镜魇

## Implementation Status

- 素材状态：未实现。
- 玩法状态：未实现；目标定位为分身干扰和反射投射物 Boss。

## Role

干扰型 Boss，通过镜影分身和反射弹制造误判。

## Setting Copy

| 项 | 文案 |
| --- | --- |
| 一句话设定 | 它把月光磨成碎镜，让猎物在真假身影之间挥空，最后被自己的倒影吞没。 |
| 登场提示 | 月光裂成数片，镜中的恶鬼同时抬头。 |
| 血条标题 | `下弦之鬼 · 镜魇 · 阶段 {phase}` |
| 击败提示 | 镜面碎裂，倒影全部熄灭。 |

## Character Brief

镜魇的威胁不在单次伤害，而在不断制造错误目标。它会留下短暂镜影吸引攻击，并让飞出的镜片在边界折返。玩家需要根据实体动作和弹道节奏判断真正的攻击窗口。

## Visual Identity

- 身体像被镜片切割过，外轮廓有不连续的反光碎边。
- 真身轮廓更实，镜影更透明、更冷色。
- 关键识别物是悬浮碎镜或镜面面具。
- 反射弹要有清楚的亮边和运动方向，不能和普通粒子混淆。

## Phase Copy

| 阶段 | 名称 | 设定表现 | 玩法标签 |
| --- | --- | --- | --- |
| 1 | 映身 | 留下短暂镜影，真身保持中距离牵制。 | 假目标、位移 |
| 2 | 折光 | 镜片开始折返，攻击路径变得不直观。 | 反射投射物 |
| 3 | 破梦 | 多个镜影接连出现，真身从镜影之间突进。 | 分身干扰、突进 |

## Skill Copy

| 技能 | 文案 | 玩法标签 |
| --- | --- | --- |
| 月镜碎片 | 镜魇甩出锋利镜片，镜片撞到边界后折返一次。 | 反射投射物 |
| 假身留影 | 它在原地留下镜影，本体短距离闪到另一侧。 | 位移、假目标 |
| 镜中噩梦 | 镜影依次破碎，每次破碎都向玩家方向射出碎光。 | 组合弹幕 |

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 待机 | 身边镜片缓慢漂浮，真身不要过透明 |
| 位移 | 原地残留镜影，本体有清楚落点姿态 |
| 反射 | 镜片撞边时闪一次，提示路径改变 |
| 死亡 | 镜面从脸部或胸口开始碎裂 |

## Avoid

- 不要让镜影和真身完全一样，玩家必须能在短时间内读出差异。
- 不要让反射弹无预警改变方向。
- 不要使用过多纯白闪光，避免遮挡玩家攻击特效。
