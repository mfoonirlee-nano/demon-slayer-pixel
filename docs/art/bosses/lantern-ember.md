# Lantern Ember - 血月眷属 · 灯烬

- 素材状态：已实现，运行时透明 PNG 位于 `assets/sprites/boss/lantern-ember/`；`lantern_ember_death.png` 为当前全局即时击败流程的后续死亡状态机预留素材。
- 玩法状态：已接入当前 Boss 轮换；基础形态包含召唤、贴地火线和召唤强化，蚀醒形态包含燎原灯阵和灰烬减速区。

## Role

召唤强化型 Boss，通过灯火、灰烬和小怪形成持续压力。

| 项 | 文案 |

## Character Brief

灯烬本体移动不快，但会持续改变战场压力。它召来的夜妖更适合牵制和堵路，火线则会把玩家从舒服的位置赶走。战斗重点是判断先清召唤物，还是抓住 Boss 施法后的空档输出。

## Visual Identity

- 血月灯是最亮识别点，始终挂在手边或胸前。
- 主体可以瘦削、披破旧长衣，衣摆带灰烬孔洞。
- 火线颜色以暗红、橙红和灰烟为主，避免大面积明黄。
- 召唤强化时，灯火和小怪之间可以有短暂细线或火星牵引。

## Animation Notes

| 状态 | 原画要点 |
| --- | --- |
| 待机 | 血月灯轻晃，灰烬从袖口或衣摆落下 |

| 火线 | 地面先出现火星预警，再形成短时火线 |
| 死亡 | 血月灯熄灭，身体化成灰烬 |

## Avoid

- 不要让火线特效遮住平台边缘。
- 不要把召唤物画得和 Boss 一样亮，血月灯必须是主视觉。
- 不要让本体动作过快，避免和 `牙岚` 定位混淆。

## 蚀醒形态（第 11 幕）

蚀醒形态 = 基础灯烬 + 一招蚀醒妖术 + 多一阶段（阈值 `[0.75, 0.5, 0.25]`）+ 强化召唤池，**复用基础精灵**。数值与机制见 [../../numeric-system/boss-archetypes.md](../../numeric-system/boss-archetypes.md)。

| 项 | 设定 |
| --- | --- |
| 血条标题 | `血月眷属 · 灯烬·蚀醒 · 阶段 {phase}` |
| 登场提示 | 血月灯齐燃，火线在地面织成网。 |
| 蚀醒视觉态 | 基础精灵叠加血月灯火焰加大 + 灰烬粒子加密；不重画身体 |
| 蚀醒妖术 | **燎原灯阵**：多条火线连成移动网格 + 灰烬减速区叠加；玩家须走网格缝隙，避免被灰烬粘住 |
| 强化召唤 | 在基础召唤池上加入 `warden`，给火阵中的小怪加成 |

新增美术需求（仅特效）：移动火线网格（缝隙始终可走）、灰烬减速区的叠加可视化、网格移动方向预警。网格必须始终留出可通行缝隙，灰烬区的减速强度要从视觉浓度读出，不能做成全屏死区。
