# 玩家原画设定

## Attack Style

角色使用“水之呼吸”，攻击会产生水流效果，具体体现在层叠浪纹、白色浪尖、蓝色卷线和泡沫碎点。

## Visual Notes

- 水流特效需要保持清亮，但不要长期遮挡敌人和 Boss 前摇。
- 普攻、技能和大招可以共享水蓝主色，但轮廓强度应随技能等级递增。
- 白色浪尖用于强调命中方向，泡沫碎点用于表现收招和命中后的散逸。

## Ultimate Art Brief

目标大招为 `终式·月潮无间`，表现重点是限时强化状态，而不是一次性全屏爆发。

开启表现：

- 角色脚下扩散半月形月蓝水纹，起手瞬间有清晰但短促的外扩浪环。
- 身体外轮廓出现青蓝高光，持续期间周身环绕细密水波。
- 移动时在身后留下短水线，水线必须快速淡出，不能遮住地面预警。
- 普攻时生成 `1-2` 道半透明残影斩，像上一刀轨迹延迟回潮。

等级递进：

| 等级 | 视觉重点 |
| --- | --- |
| Lv1 | 脚下半月水纹 + 轻量青蓝轮廓，普攻偶发残影水刃 |
| Lv2 | 周身水波更稳定，移动水线更连续，普攻残影更容易读出 |
| Lv3 | 轮廓高光和残影斩更亮，命中反馈更强，但不扩大成长期遮挡层 |

可读性边界：

- 残影和水线只保留短寿命、低透明度层级，不盖住 Boss 前摇、敌人身体和平台边缘。
- 大招状态不使用大面积雾、满屏浪墙或常驻强闪白。
- 等级差异主要靠密度、亮度和命中反馈，不靠把特效面积无限放大。
