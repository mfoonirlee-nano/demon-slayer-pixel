# 月潮灵匣原画设定

## 定位

月潮灵匣是高台秘藏玩法的唯一场景宝藏。它需要在高速横向卷轴中一眼区别于敌人掉落物和普通平台装饰，同时延续玩家“月潮流”的深靛、银白、潮蓝视觉语言。整体是小型神龛与便携灵匣的结合，不采用西式金币宝箱造型。

## 轮廓与材质

- 主体为低重心的深靛漆木 / 暗石匣体，正面略宽，便于在 `84x84` 运行时尺寸下保持清楚轮廓。
- 顶部使用银白新月形檐冠，左右檐角轻微上挑；关闭状态也能凭月冠认出宝藏身份。
- 正面嵌入青蓝潮纹月印，核心使用克制的暖金光，与冷色匣体形成奖励焦点。
- 边角只保留少量暗银包边、红绳结和神社构件，不堆叠细碎纹样，不出现现成作品的家纹或角色标志。

## 色彩层级

1. 深靛与蓝黑：主体体积和阴影。
2. 暗银与冷白：月冠、包边和最高亮边。
3. 青蓝与月潮蓝：潮纹、缝隙能量和灵火。
4. 暖金：锁芯与开启核心，只占小面积。
5. 暗红：绳结点缀，用于连接神社场景语法。

## 四帧状态

运行时图集固定为四个横排状态，每帧都保持同一底部锚点与主体尺度：

1. **休眠闭匣**：盖体闭合，月印微暗，只有少量青蓝缝隙光。
2. **月印点亮**：月冠与正面月印增亮，能量从底部潮纹向上汇聚。
3. **半启匣**：盖体上抬，暖金核心可见，青蓝光从缝隙溢出。
4. **完全开启**：盖体完全展开，核心达到峰值，三团错位月潮灵火升起。

状态之间依靠盖体角度、核心亮度和灵火数量形成明确进展，不能只对同一张图做整体提亮。

## 像素与运行时边界

- 采用与当前角色、敌人和场景一致的高清像素插画：硬边像素块、有限层次高光、无平滑矢量轮廓。
- 本体图集只绘制灵匣和紧贴主体的小型能量；外围月潮光效由 Canvas 运行时叠加。
  待开启时使用多层柔光、渐亮断弧、细扇形光芒、带尾迹的上浮像素光尘及贴台反光；
  解封前亮度较低，驻留时断弧与光尘向锁心收束，暖金驻留环仍单独表示领取进度。
  开匣时释放三道错时扩散潮环，随定格计时散去，奖励选择停在完整开启的本体帧。
  右缘入场提示复用月潮光效，但仍只出现一次，不使用箭头或文字。
  以青蓝为主、银白作细亮芯，暖金只保留为锁心和少量光尘点缀。
- 实现参考社区的 [加色粒子叠加](https://gamedev.stackexchange.com/questions/18594/how-can-i-make-this-style-of-2d-glowing-graphics/18595)
  与 [Bloom 的柔和衰减及亮部控制](https://catlikecoding.com/unity/tutorials/advanced-rendering/bloom/)。
  在 Canvas 2D 中用 `screen` 合成广域柔光，`lighter` 合成局部亮芯与光尘，
  分段衰减断弧，保留未模糊的灵匣轮廓；这是局部光效，不对整个场景做 Bloom 后处理。
  动画只消费宝藏的游戏计时，暂停与奖励时不会继续漂移；绘制后恢复 Canvas 状态。
- 原图不得烘入大范围地面阴影、文字、卡面或完整背景。
- 精确文件尺寸、帧切片、透明 gutter、基线和绘制尺寸以 [素材处理指南](../SPRITES.md) 为准。
