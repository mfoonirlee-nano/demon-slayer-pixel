# 月潮灵匣原画设定

## 定位

月潮灵匣是高台秘藏玩法的唯一场景宝藏。它需要在高速横向卷轴中一眼区别于敌人掉落物和普通平台装饰，同时延续玩家“月潮流”的深靛、银白、潮蓝视觉语言。整体是小型神龛与便携灵匣的结合，不采用西式金币宝箱造型。

## 轮廓与材质

- 主体为低重心的深靛漆木 / 暗石匣体，正面略宽，便于在 `84x84` 运行时尺寸下保持清楚轮廓。
- 顶部使用银白新月形檐冠，左右檐角轻微上挑；关闭状态也能凭月冠认出宝藏身份。
- 正面嵌入青蓝潮纹月印，核心使用克制的暖金光，与冷色匣体形成奖励焦点。
- 边角只保留少量暗银包边、红绳结和神社构件，不堆叠细碎纹样，不出现现成作品的家纹或角色标志。

## 色彩层级

1. 深靛与蓝黑：主体体积和阴影。
2. 暗银与冷白：月冠、包边和最高亮边。
3. 青蓝与月潮蓝：潮纹、缝隙能量和灵火。
4. 暖金：锁芯与开启核心，只占小面积。
5. 暗红：绳结点缀，用于连接神社场景语法。

## 四帧状态

运行时图集固定为四个横排状态，每帧都保持同一底部锚点与主体尺度：

1. **休眠闭匣**：盖体闭合，月印微暗，只有少量青蓝缝隙光。
2. **月印点亮**：月冠与正面月印增亮，能量从底部潮纹向上汇聚。
3. **半启匣**：盖体上抬，暖金核心可见，青蓝光从缝隙溢出。
4. **完全开启**：盖体完全展开，核心达到峰值，三团错位月潮灵火升起。

状态之间依靠盖体角度、核心亮度和灵火数量形成明确进展，不能只对同一张图做整体提亮。

## 像素与运行时边界

- 采用与当前角色、敌人和场景一致的高清像素插画：硬边像素块、有限层次高光、无平滑矢量轮廓。
- 本体图集只绘制灵匣和紧贴主体的小型能量；一次性右缘月潮光晕、光柱、平台辉光、驻留环、飞散光点和开匣闪光由 Canvas 运行时叠加。右缘光晕不使用箭头或文字，以青蓝为主、银白过渡，暖金只保留为峰值核心。
- 原图不得烘入大范围地面阴影、文字、卡面或完整背景。
- 精确文件尺寸、帧切片、透明 gutter、基线和绘制尺寸以 [素材处理指南](../SPRITES.md) 为准。
