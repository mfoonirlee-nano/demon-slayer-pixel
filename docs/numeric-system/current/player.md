# 当前玩家数值

## Purpose

记录玩家基础属性、普通攻击、下落攻击、技能、大招、受伤与无敌的当前生效数值。

## Current State

玩家当前只有局内即时成长：攻击水晶和宝箱可以提高 `attackBonus`，治疗奖励可以恢复生命。最大生命、技能上限和大招上限没有局内提升玩法。

技能释放：

- 技能释放消耗 `30` 技能能量。
- 技能格数同步公式为 `floor(skillEnergy / 30)`，最高 `3` 格。
- 释放瞬间会对玩家前方半径范围内目标结算一次范围伤害。

释放瞬间范围伤害：

| 技能 | 小怪基础伤害 | 小怪距离缩放 | Boss 基础伤害 | 半径 |
| --- | ---: | ---: | ---: | ---: |
| 壹之型 | `34` | `42` | `56` | `30` |
| 贰之型 | `37` | `45` | `62` | `30` |
| 叁之型 | `40` | `48` | `68` | `30` |

小怪伤害：

```ts
(enemyBase + ratio * enemyScale) * (1 + attackBonus * 0.025)
```

Boss 伤害：

```ts
bossBase * ratio
```

Boss 判定半径额外增加 `40`，最低伤害比例为 `0.2`。当前释放瞬间的 Boss 伤害不读取攻击加成。
