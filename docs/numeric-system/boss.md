# Boss 数值

> 实现状态：已实现。本文记录当前源码中已经生效的 Boss 数值和行为。

## Purpose

记录当前 Boss 出场、阶段、AI 行为、召唤、投射物、专属技能和血量曲线。完整目标设计见 [boss-archetypes.md](boss-archetypes.md)。

## Current State

当前运行时使用固定 13 幕 Boss 注册表：第 1-6 幕为六名基础 Boss，第 7-12 幕按同序复现蚀醒形态，第 13 幕为万相血月。枯铃固定出现在第 6 幕，并于第 12 幕以蚀醒形态复现；Boss 死亡奖励、幕推进和清理统一由 `defeatBoss()` 处理。

美术与设定文案见 [../art/bosses/spider-string.md](../art/bosses/spider-string.md) 和 [../art/bosses/dead-bell.md](../art/bosses/dead-bell.md)。本文只把源码已生效行为写作当前实现；仍需试玩的数据校准明确标为后续 telemetry 工作。

## Encounter And HP

所有注册表 Boss（含基础、蚀醒与终幕）统一计算有效生命：

```ts
bossHp = (hpBase + bossKills * hpPerKill + elapsedSeconds * 0.35) * 2
```

末尾的 `* 2` 来自 `BOSS_CONFIG.healthMultiplier`，不能在文档或调参时遗漏。枯铃注册表使用 `hpBase = 520`、`hpPerKill = 60`：

| 遭遇 | `bossKills` | 有效生命 |
| --- | ---: | --- |
| 第 6 幕枯铃 | `5` | `1640 + elapsedSeconds * 0.7` |
| 第 12 幕枯铃·蚀醒 | `11` | `2360 + elapsedSeconds * 0.7` |

蚀醒形态不另乘生命倍率；额外难度来自第四阶段、蚀醒妖术和支援。Boss 入场仍使用 `WIDTH + 140`、目标 `WIDTH - 170`、速度 `-2.6` 与入场后 `32` 帧 AI 延迟；具体出场时点由当前幕的 enemy director 波次、幕内时间与前奏门槛共同决定，不再是固定 `28s / 45s` 计时器。

蛛弦阶段技能累计解锁，进入新阶段后仍保留此前招式：

| 阶段 | 条件 | 实际接触伤害 | 累计技能 |

## Dead Bell Runtime Contract

基础枯铃使用 `[0.66, 0.33]` 三阶段，蚀醒枯铃使用 `[0.75, 0.5, 0.25]` 四阶段。下列伤害已经包含全局 `1.5` 倍 Boss 伤害倍率：

| 来源 | 公式 | P1 / P2 / P3 / P4 |
| --- | --- | --- |
| 身体接触 | `(10 + phase * 2) * 1.5` | `18 / 21 / 24 / 27` |
| 声波 | `(11 + phase * 3) * 1.5` | `21 / 25.5 / 30 / 34.5` |
| 音刃 | `(13 + phase * 3) * 1.5` | `24 / 28.5 / 33 / 37.5` |
| 违律反震 | `(16 + phase * 3) * 1.5` | `28.5 / 33 / 37.5 / 42` |

### Deterministic Cadence

每阶段都从序列首项重新开始并累计此前招式，不随机抽取：

| 阶段 | 常规循环 |
| --- | --- |
| P1 | 单圈 |
| P2 | 双圈 + 玩家高度音刃 → 单圈 |
| P3 | 双波双刃组合 → 双圈 → 单圈 |
| 蚀醒 P4 | 组合 → 双圈 → 单圈 → 双调 |

蚀醒形态每个新阶段的第一招强制为双调，之后从该阶段标志招开始常规循环；P4 因而会再次循环到双调。单次/双次施法为 `64` 帧并在第 `30` 帧生成，组合/双调为 `86` 帧并在第 `34` 帧生成；短恢复 `26` 帧、组合恢复 `46` 帧。基础单次/双次后续冷却为 `max(160, 238 - phase * 18)`，组合 `288` 帧；蚀醒的非双调冷却再减 `12` 帧且下限为 `148`，双调固定 `330` 帧。

### Wave, Blade And Activation Cues

| 项 | 当前值 |
| --- | ---: |
| 声波预警 | `24` 帧 |
| 低频 / 高频扩散 | `76 / floor(76 * 0.88) = 66` 帧 |
| 基础半径 / 厚度 | `54 -> 390` / `34` |
| 二段延迟 | `34` 帧 |
| 音刃预警 | `20` 帧 |
| 音刃命中体 / 速度 / 寿命 | `238 x 34` / `7.4px/帧` / `120` 帧 |

低/高频声波有不同色相、扩散速度和专属启动音；延迟实例只在真正激活时发声。声波绘制按每帧可见 bbox 补偿到圆形碰撞外缘。音刃的序列延迟与固定 `20` 帧可见预警分开：较晚音刃先保持隐藏，到最后 `20` 帧才播放前两张蓄势素材；中段循环显示实际飞行伤害，最后 `12` 个生命周期帧只显示无伤、静止消散。

### Awakened Duet And Reprisal

双调按阶段累积：P1 为一低一高两圈；P2 加一枚锁定玩家高度的音刃；P3/P4 再加第三个低频大圈和另一高度音刃。其后进入固定停拍协议：

| 窗口 | 时长 | 规则 |
| --- | ---: | --- |
| 停拍警告 | `30` 帧 | 持续刷新动作序号，允许收刀且不追罚此前已承诺动作 |
| 反震激活 | 最多 `42` 帧 | 只处罚在激活后新开始的普攻、落击、技能或终式 |
| 安全反击 | 完整 `54` 帧 | 完整停手或受反震后都进入同一无接触伤害窗口 |

若激活期内出现违规新起手，反震立即结算并结束激活判定；若起手暂带无敌，则当前节拍和恢复计时保持不动，直到反震伤害可结算。随后剩余恢复统一进入标准 `54` 帧反击窗，不残留额外激活空档。完整停手则在激活期结束时播放破响提示并进入同样完整的 `54` 帧窗口。整个恢复阶段都关闭身体接触伤害。

P3/P4 的每次组合招都拥有一个脚本支援槽；失败或被 debug 自动生成开关阻止只消费当前槽，等完整节拍循环回到下一次组合再尝试，不逐帧重试。基础 P3 的每个槽使用 director 的 Boss 召唤池；蚀醒槽在强化专员与基础池间交替，P3 从蚀醒 `binder` 开始、P4 从蚀醒 `warden` 开始，且全部服从 Boss 召唤成本、数量与同类 cap。

Boss 死亡后：

- 玩家得分增加 `220`。
- 技能能量增加 `60`。
- 大招能量增加 `40`。
- 补足恰好一级所需 XP，记录装备效果并排队 Boss 装备选择。
- `state.bossKills += 1`。
- `state.boss = null`。
- 清除 Boss 来源召唤物，并把 enemy director 推进到下一幕；不使用固定 `45s` 重生计时。
- 枯铃额外在结算当帧清空声波与音刃，播放专属死亡音，并在统一 `60` 帧冻结中显示断铃和悬停声波消散。
