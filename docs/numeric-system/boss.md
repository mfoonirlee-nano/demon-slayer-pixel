# Boss 数值

> 实现状态：已实现。本文记录当前源码中已经生效的 Boss 数值和行为。

## Purpose

记录当前 Boss 出场、阶段、AI 行为、召唤、投射物、专属技能和血量曲线。完整目标设计见 [boss-archetypes.md](boss-archetypes.md)。

## Current State

当前已接入基础 Boss 注册表和 `bossKills` 状态。v1 可玩顺序只启用蛛弦、枯铃，之后循环；完整 13 幕 Boss 系统暂不进入运行时。Boss 死亡奖励和重生计时统一由 `defeatBoss()` 处理。

美术与设定文案见 [../art/bosses/spider-string.md](../art/bosses/spider-string.md) 和 [../art/bosses/dead-bell.md](../art/bosses/dead-bell.md)。本文只维护当前源码已经生效的 Boss 数值和行为。

## Key Formulas

出场（蛛弦基准；枯铃读取注册表覆盖的生命曲线、碰撞伤害、AI 冷却和绘制表）：

| 项 | 当前值 |
| --- | ---: |
| 初始 Boss 计时器 | `28s` |
| 最早允许时间 | `elapsed > 18s` |
| 实际首个 Boss 出场 | 通常约 `28s` |
| 生成 X | `WIDTH + 140` |
| 目标 X | `WIDTH - 170 = 790` |
| 入场速度 | `-2.6` |
| 入场后 AI 延迟 | `32` 帧 |
| 蛛弦碰撞体 | `104 x 188` |
| 蛛弦生命 | `460 + elapsed * 2.2` |
| 枯铃碰撞体 | `104 x 188` |
| 枯铃生命 | `520 + bossKills * 60 + elapsed * 1.45` |

如果 Boss 在 `28s` 生成，生命约为 `521.6`。

枯铃技能节奏：

| 阶段 | 规则 |
| --- | --- |
| 1 | 稳定释放单圈 `枯铃震`，先预警内圈，再扩散声波环 |
| 2 | 声波变为延迟二段，并向玩家所在高度穿插一枚 `裂音刃` |
| 3 | `停拍索命`：停拍提示后释放声波、上层音刃、延迟声波和下层音刃，随后进入可反击硬直 |

Boss 死亡后：

- 玩家得分增加 `220`。
- 技能能量增加 `60`。
- 大招能量增加 `40`。
- `state.bossKills += 1`。
- `state.boss = null`。
- `state.bossSpawnTimer = PLAYER_COMBAT.skillChargeResetDelay`，当前实际作为 `45s` 重生延迟使用。
