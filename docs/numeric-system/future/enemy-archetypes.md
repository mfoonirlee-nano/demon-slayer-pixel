# 未来敌人类型与生成权重

## Purpose

定义未来普通敌人 archetype、生成权重、技能随进度解锁和素材接入边界。该文档是目标设计，当前源码仍是单一敌人数值与 AI。

## Target Design

敌人设计先解决两个问题：

- 当前 6 张敌人素材只随机换外观，玩法压力没有差异。
- 未来幕数推进后，需要用敌人组合改变战斗问题，而不是只提高血量和速度。

普通敌人进入注册表：

```ts
ENEMY_ARCHETYPES
```

设计原则：

- 每种敌人只承担一个主要压力，不把高速、高血、高伤、远程都堆在同一个单位上。
- 所有高伤行为必须有可读前摇，避免只靠接触伤害制造难度。
- 第一幕保持低认知负担，玩家应能通过移动、普攻和单个技能理解核心规则。
- 第三幕以后允许混合压力，但通过生成权重和 active cap 控制同时存在数量。
- 现有正式敌人素材可以被赋予不同 archetype；新增敌人第一版等待正式素材接入，不使用临时图形占位。

第一版角色类型：

| Archetype | 素材建议 | 定位 | 行为 | 推荐出现阶段 |
| --- | --- | --- | --- | --- |
| `chaser` | `enemy_1.png` | 基础追击 | 稳定靠近玩家，低伤、低复杂度 | 第 1 幕 |
| `crawler` | `enemy_2.png` | 低矮穿插 | 较快、低血，压缩地面空间 | 第 1 幕后半 |
| `runner` | `enemy_3.png` | 快攻压力 | 短前摇后冲刺，迫使跳跃或远程处理 | 第 2 幕 |
| `duelist` | `enemy_5.png` | 近战威胁 | 中速，靠近后短距离斩击 | 第 2 幕后半 |
| `brute` | `enemy_6.png` | 高血目标 | 慢速、高血，短霸体窗压迫空间 | 第 3 幕 |
| `caster` | `enemy_4.png` | 远程施压 | 保持距离，周期性发射投射物或召唤标记 | 第 3 幕 |

现有素材改造目标：

| 当前素材 | 视觉特征 | 当前问题 | 目标改造 |
| --- | --- | --- | --- |
| `enemy_1.png` | 裸身奔跑鬼 | 和所有敌人同数值 | 作为默认 `chaser`，保留当前手感基准 |
| `enemy_2.png` | 低矮蛛形 | 外观低矮但没有玩法差异 | 作为 `crawler`，低血高速，但普攻必须稳定可命中 |
| `enemy_3.png` | 角鬼奔跑/挥臂 | 动作像冲锋但只普通追踪 | 作为 `runner`，增加前摇冲刺 |
| `enemy_4.png` | 提灯面具鬼 | 外观像远程/召唤单位 | 作为 `caster`，正式接入投射物前不进入远程生成池 |
| `enemy_5.png` | 双刃鬼 | 外观像近战精英但同质化 | 作为 `duelist`，增加近身斩击窗口 |
| `enemy_6.png` | 甲壳虫鬼 | 外观像重型单位但同质化 | 作为 `brute`，高血慢速，限制同时存在数量 |

扩展特色敌人池：

这些敌人不强行使用现有 6 张素材，建议等正式素材、前摇动画和命中特效准备好后再进入生成池。面向原画师的敌人形象说明见 [../../art/enemies/README.md](../../art/enemies/README.md)。

| Archetype | 定位 | 行为核心 | 推荐出现阶段 | 设计价值 |
| --- | --- | --- | --- | --- |
| `leaper` | 跳跃突袭 | 蓄力后抛物线跳向玩家落点 | 第 2 幕后半 | 迫使玩家处理平台和地面落点 |
| `burrower` | 潜行包抄 | 短暂消失，地面标记后从玩家附近钻出 | 第 3 幕 | 打破单向风筝和边缘站位 |
| `splitter` | 分裂压迫 | 死亡后分裂为两个低血残影 | 第 3 幕 | 制造目标优先级和清场价值 |
| `binder` | 控场干扰 | 前摇后生成短时束缚/减速区域 | 第 3 幕后半 | 迫使玩家离开安全位置 |
| `warden` | 支援核心 | 给附近敌人提供小幅加速或减伤光环 | 第 4 幕+ | 让玩家优先处理后排支援 |

## Key Formulas

基础成长：

```ts
enemyHp = round((baseHp + bossKills * hpPerBossKill) * threatScalar + elapsed * hpScaleByElapsed)
enemyDamage = min(damageCap, baseDamage + bossKills * damagePerBossKill + elapsed * damageScaleByElapsed)
```

生成节奏：

```ts
enemySpawnInterval = clamp(1.15 - bossKills * 0.08 - elapsed * 0.0015, 0.42, 1.15)
enemySpawnBudget = Math.min(10 + bossKills * 2, 24)
enemyActiveCost = sum(enemy.archetype.spawnCost)
```

用 `spawnBudget` 替代单纯数量上限。这样 `brute` 和 `caster` 可以占更高预算，避免后期同时刷出过多高压单位。

第一版数值草案：

| Archetype | HP | 伤害 | 速度 | 转向力 | 预算 | 击杀分 | 技能能量 | 大招能量 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `chaser` | `16 + k*2` | `3 + k*0.35` | `0.72 + rand(1.08)` | `0.030` | `1` | `10` | `10` | `8/3` |
| `crawler` | `10 + k*1.4` | `3 + k*0.25` | `1.05 + rand(0.95)` | `0.040` | `1` | `9` | `8` | `2` |
| `runner` | `12 + k*1.5` | `3 + k*0.35` | `1.25 + rand(0.85)` | `0.040` | `1` | `11` | `9` | `2.4` |
| `duelist` | `22 + k*2.6` | `5 + k*0.55` | `0.84 + rand(0.72)` | `0.034` | `2` | `14` | `12` | `3.2` |
| `brute` | `38 + k*5.5` | `8 + k*0.8` | `0.42 + rand(0.45)` | `0.020` | `3` | `22` | `16` | `4.5` |

## Behavior Design

### `chaser`

基础追击单位，保留当前敌人的学习价值。

| 项 | 目标 |
| --- | --- |
| 主要压力 | 逼迫玩家移动和普攻 |
| 行为 | 持续向玩家靠近 |
| 反制 | 普攻 1-2 次、任意技能、大招清场 |
| 注意 | 不要在第一幕过早堆满数量 |

### `crawler`

低血高速穿插单位，用来打破只看站立敌人的节奏。

| 项 | 目标 |
| --- | --- |
| 主要压力 | 地面空间和跳跃落点 |
| 行为 | 较快贴地追踪，转向灵活 |
| 反制 | 下落攻击、壹之型直线清理、普攻 |
| 注意 | 碰撞体高度不能低到普攻打不到 |

### `runner`

快攻单位，核心是“可预判的突然靠近”。

| 项 | 目标 |
| --- | --- |
| 主要压力 | 反应和站位 |
| 行为 | 距离玩家一定范围时停顿 `14-18` 帧，然后冲刺 `18-24` 帧 |
| 反制 | 提前跳跃、壹之型、叁之型反击 |
| 注意 | 冲刺后必须有恢复帧，不能连续粘人 |

### `duelist`

近战精英单位，提供比 `chaser` 更明确的近身危险。

| 项 | 目标 |
| --- | --- |
| 主要压力 | 近距离处理顺序 |
| 行为 | 接近后短前摇斩击，斩击盒比接触盒更危险 |
| 反制 | 贰之型群体压制、叁之型反击、拉开距离 |
| 注意 | 斩击伤害高于接触伤害，但必须有前摇 |

### `brute`

高血重型单位，用于制造空间阻塞，而不是靠速度追杀。

| 项 | 目标 |
| --- | --- |
| 主要压力 | 持续占位和目标优先级 |
| 行为 | 慢速追踪，短霸体窗，偶尔重踏 |
| 反制 | 贰之型、下落攻击、大招 |
| 注意 | 同时存在数量必须低；霸体不能免疫大招 |

### `caster`

远程单位，用来迫使玩家离开安全站位。

| 项 | 目标 |
| --- | --- |
| 主要压力 | 远程弹幕和平台路线干扰 |
| 行为 | 保持 `220-280px` 距离，前摇后发射低速投射物 |
| 反制 | 壹之型远程清线、叁之型防守反击、快速接近 |
| 注意 | 投射物同时存在数建议每个 `caster` 最多 `2` 个 |

### `leaper`

跳跃突袭单位，专门惩罚玩家长期站在平台边缘或只向一个方向风筝。

| 项 | 目标 |
| --- | --- |
| 主要压力 | 平台落点和垂直空间 |
| 行为 | 进入范围后停顿 `18-24` 帧，锁定玩家当前位置附近，抛物线跳跃并落地冲击 |
| 反制 | 看前摇离开落点、下落攻击反打、壹之型在起跳前击杀 |
| 注意 | 落点必须有地面标记；空中不能无限修正目标 |

### `burrower`

潜行包抄单位，用来打破玩家贴边站位和单方向清线。

| 项 | 目标 |
| --- | --- |
| 主要压力 | 身后威胁和站位变化 |
| 行为 | 蓄力后潜入地面 `36-48` 帧，玩家附近出现标记，随后钻出攻击 |
| 反制 | 离开标记区域、叁之型防守、钻出后的恢复帧普攻 |
| 注意 | 潜行期间不应完全无反馈；钻出点不能直接贴玩家中心 |

### `splitter`

分裂单位，用来让玩家判断“先清小怪还是先打本体”。

| 项 | 目标 |
| --- | --- |
| 主要压力 | 清场顺序和技能价值 |
| 行为 | 本体死亡后生成两个低血 `splitling`，分裂体短暂散开后追踪 |
| 反制 | 贰之型、大招、下落攻击，或先把周围敌人清掉再击杀本体 |
| 注意 | 只能分裂一次；分裂体不能再次掉落完整奖励 |

### `binder`

控场干扰单位，不靠高伤害，而是制造玩家不想站的位置。

| 项 | 目标 |
| --- | --- |
| 主要压力 | 安全区压缩和平台路线干扰 |
| 行为 | 前摇后在玩家脚下或前进方向生成 `2-3s` 减速区域 |
| 反制 | 提前移动、壹之型远程击杀、叁之型抵挡后续压力 |
| 注意 | 束缚区域只减速或短暂锁跳，不应直接造成高额伤害 |

### `warden`

支援核心单位，用低直接威胁换取高目标优先级。

| 项 | 目标 |
| --- | --- |
| 主要压力 | 后排优先级和混怪处理 |
| 行为 | 给半径 `180px` 内敌人提供 `+12%` 移速或 `-15%` 受伤倍率光环 |
| 反制 | 壹之型远程点杀、绕过前排、用大招清掉整波 |
| 注意 | 同场最多 `1` 个；光环不影响 Boss，避免 Boss 战不可控 |

## Skill Counter Matrix

| 玩家手段 | 擅长处理 | 不擅长处理 |
| --- | --- | --- |
| 普通攻击 | `chaser`、落单 `crawler`、钻出后的 `burrower` | 多个 `runner`、远处 `caster` / `binder` |
| 下落攻击 | `crawler`、聚团敌人、`brute`、`splitter` 分裂体 | 分散远程单位、空中 `leaper` |
| 壹之型 | `runner`、`caster`、`binder`、`warden`、直线清场 | 身后敌人、贴脸包围 |
| 贰之型 | `duelist`、`brute`、`splitter`、混怪 | 极远距离目标、已潜行的 `burrower` |
| 叁之型 | `runner`、`duelist`、投射物压力、`burrower` 钻出 | 高血单位的主动击杀 |
| 大招 | 危机清场、重型单位、`warden` 光环波次 | 常规小波次不应强迫使用 |

## Implementation Notes

- 本文档只定义目标设计；当前实现仍以 `current/enemies.md` 为准。
- 第一阶段可以先建立 `sheetId -> archetypeId` 映射，让现有 6 张正式素材获得不同数值。
- `caster` 的远程行为必须等投射物来源、命中规则和反制方式一起实现后再进入生成池。
- 击杀奖励应从 archetype 读取，不再由所有敌人共享同一套固定奖励。
- `brute`、`caster`、`duelist` 需要 active cap 或 spawn budget，避免组合不可解。
- 特色敌人先通过“替换普通生成结果”的方式接入，不直接增加总刷怪密度。
- `leaper`、`burrower`、`binder` 必须有清晰落点或区域预警。
- `splitter` 的分裂体不能继续分裂，也不能给完整击杀奖励。
- `warden` 光环不影响 Boss，且同场最多一个。
- 所有新增行为先以前摇、攻击、恢复三个阶段描述清楚，再写代码。
