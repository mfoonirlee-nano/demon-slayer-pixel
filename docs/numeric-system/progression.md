# 经验与局内成长

> 实现状态：部分实现。当前源码已接入经验、角色等级、普通技能等级、大招强化等级、升级三选一、最大生命成长和技能能量上限成长；未接入的目标技能池仍以后续实现为准。

## Purpose

定义单局内经验、角色等级、基础属性成长、普通技能习得/升级、大招强化和升级三选一规则。

本系统只提供单局内成长：每局开始时经验、角色等级、普通技能习得状态、普通技能等级和大招强化等级重置，死亡或重开后不保留任何战力。

## Design Goals

- 不引入局外永久成长。
- 角色等级不设硬上限，但经验需求持续提高。
- 每次升级都稳定提高基础攻击、最大生命和技能能量上限，保证升级永远有基础收益。
- 普通技能和大招提供本局构筑方向，而不是永久养成。
- 普通技能目标池为 9 个，但未接入素材、HUD 或技能逻辑的技能不能进入升级候选。
- 玩家初始习得 2 个普通技能，后续通过升级三选一习得新技能或提升已有技能。
- 每个普通技能最高 Lv3，大招 `终式·月潮无间` 最高 Lv3。
- 大招不占普通技能槽，不进入普通技能池。
- 升级选择暂停战斗，选择完成后继续当前局。

## Runtime State

建议新增运行时状态：

```ts
runXp: number;
runLevel: number;

// 当前已习得的普通技能。未习得技能不在此表中，或等级记为 0。
skillLevels: Partial<Record<SkillId, 1 | 2 | 3>>;

// 当前装备到 1/2/3 槽的普通技能，最多 3 个。
equippedSkillIds: SkillId[];

// 0 表示本局尚未获得月潮强化；1-3 表示大招强化等级。
ultimateLevel: 0 | 1 | 2 | 3;

pendingUpgradeChoices: UpgradeChoice[];
```

推荐初始值：

```ts
runXp = 0;
runLevel = 1;

skillLevels = {
  skill1: 1, // 水龙破
  skill2: 1, // 打潮刃
};

equippedSkillIds = ["skill1", "skill2"];
ultimateLevel = 0;
pendingUpgradeChoices = [];
```

初始第 3 个普通技能槽为空。后续习得新技能时，如果存在空槽，自动装备；如果 3 个槽已满，新技能进入已习得技能池，玩家可在升级选择界面或暂停界面调整装备。

## Progression Loop

1. 击杀敌人或 Boss 时获得 XP。
2. 如果 `runXp >= xpToNextLevel(runLevel)`，扣除当前等级需求并提升 `runLevel`。
3. 升级时按等级公式刷新 `baseAttack`、`maxHp` 和 `skillEnergyMax`。
4. 升级时根据新旧最大生命差额恢复少量生命，并按新旧技能能量上限比例缩放当前技能能量。
5. 如果存在可用技能/大招成长项，生成最多 3 个升级选项，写入 `pendingUpgradeChoices`。
6. 存在待选升级奖励时暂停战斗和实体更新，等待玩家选择。
7. 玩家选择 1 个奖励后立即生效，清空当前选择。
8. 如果剩余 `runXp` 仍满足下一等级需求，继续弹出下一次升级。

连续升级处理应一次只展示一组三选一，避免多个升级奖励同时堆叠在 UI 上。战斗暂停期间不继续推进 `elapsed`、刷怪、Boss AI、平台移动、投射物、碰撞或奖励拾取。

## Attribute Growth

角色等级不设硬上限。为了让长局中基础属性持续有价值但不过快膨胀，攻击和生命使用“线性成长 + 平方根前期补正”的公式。

### 基础攻击

```ts
baseAttack(level) = Math.floor(
  baseAttack0
  + atkLinear * (level - 1)
  + atkCurve * Math.sqrt(level - 1)
);
```

推荐参数：

```ts
baseAttack0 = 16;
atkLinear = 1.2;
atkCurve = 1.6;
```

最终公式：

```ts
baseAttack(level) = Math.floor(16 + 1.2 * (level - 1) + 1.6 * Math.sqrt(level - 1));
```

示例值：

| 等级 | 基础攻击 |
| ---: | ---: |
| Lv1 | 16 |
| Lv2 | 18 |
| Lv3 | 20 |
| Lv4 | 22 |
| Lv5 | 23 |
| Lv10 | 31 |
| Lv20 | 45 |
| Lv30 | 59 |
| Lv50 | 82 |

最终总攻击仍可沿用当前战斗口径：

```ts
totalAttack = baseAttack + attackBonus;
```

等级成长提高 `baseAttack`，水晶、宝箱或装备类奖励继续影响 `attackBonus`。两者分工不要混淆。

### 最大生命

```ts
maxHp(level) = Math.floor(
  baseHp
  + hpLinear * (level - 1)
  + hpCurve * Math.sqrt(level - 1)
);
```

推荐参数：

```ts
baseHp = 100;
hpLinear = 10;
hpCurve = 8;
```

最终公式：

```ts
maxHp(level) = Math.floor(100 + 10 * (level - 1) + 8 * Math.sqrt(level - 1));
```

示例值：

| 等级 | 最大生命 |
| ---: | ---: |
| Lv1 | 100 |
| Lv2 | 118 |
| Lv3 | 131 |
| Lv4 | 143 |
| Lv5 | 156 |
| Lv10 | 214 |
| Lv20 | 324 |
| Lv30 | 433 |
| Lv50 | 646 |

### 技能能量上限

```ts
skillEnergyMax(level) = 90 + 10 * (level - 1);
maxSkillCharges = Math.floor(skillEnergyMax / 30);
```

技能释放成本保持 `30`。技能能量上限每级增加 `10`，因此可存技能次数每 3 级增加 1 次：

| 等级 | 技能能量上限 | 可存技能次数 |
| ---: | ---: | ---: |
| Lv1 | 90 | 3 |
| Lv4 | 120 | 4 |
| Lv7 | 150 | 5 |
| Lv10 | 180 | 6 |

升级时当前技能能量按比例缩放，避免上限提升后填充比例突然下降：

```ts
skillEnergy = Math.round(oldSkillEnergy / oldSkillEnergyMax * newSkillEnergyMax);
```

### 升级回血

```ts
healOnLevelUp = Math.max(10, Math.floor((newMaxHp - oldMaxHp) * 0.8));
hp = Math.min(newMaxHp, hp + healOnLevelUp);
```

升级回血只提供喘息，不直接回满血，避免升级变成稳定续命机制。

## XP Formula

因为角色等级无上限，升级需求必须持续提高。

```ts
xpToNextLevel(level) = Math.floor(
  baseXp
  + xpLinear * level
  + xpCurve * level ** 1.45
);
```

推荐参数：

```ts
baseXp = 50;
xpLinear = 22;
xpCurve = 13;
```

最终公式：

```ts
xpToNextLevel(level) = Math.floor(50 + 22 * level + 13 * level ** 1.45);
```

示例值：

| 当前等级 | 升下一级 XP |
| ---: | ---: |

| Lv2 → Lv3 | 129 |
| Lv3 → Lv4 | 177 |
| Lv4 → Lv5 | 228 |
| Lv5 → Lv6 | 281 |
| Lv10 → Lv11 | 637 |
| Lv15 → Lv16 | 1026 |
| Lv20 → Lv21 | 1455 |
| Lv30 → Lv31 | 2421 |
| Lv50 → Lv51 | 4752 |

## Normal Skill Level Rules

普通技能等级是单局内成长，不是局外养成。每个技能独立记录等级，最高 Lv3。

| 等级 | 定位 | 成长方向 |
| --- | --- | --- |
| Lv1 | 基础形态 | 技能拥有完整功能，满足该技能的核心定位 |
| Lv2 | 稳定强化 | 小幅提高伤害、命中反馈或关键效果稳定性 |
| Lv3 | 专精形态 | 强化该技能最核心的战术价值，但不改变技能类型 |

通用边界：

- 直线/往返技能可以提高伤害、飞行距离、路径宽度和命中反馈，但不能变成全屏清场或自动追踪。
- 贴身/纵向技能可以提高伤害、覆盖宽度、命中高度和恢复手感，但不能长期控场或替代防守技能。
- 防反技能可以提高反击伤害、可抵挡次数和反击范围，但不能提供长期无敌。
- 位移技能可以提高位移距离、收刀伤害和落点反馈，但不能穿越所有 Boss 技能。
- 控场/破甲技能可以提高持续时间、效果强度和 Boss 缩放，但不能无限叠加或锁死 Boss。

## Ultimate: 终式·月潮无间

大招不是普通技能，不占普通技能槽。满大招能量后释放 `终式·月潮无间`，进入有限持续时间的月潮强化状态。

`ultimateLevel = 0` 表示本局尚未获得月潮强化；`ultimateLevel = 1..3` 表示通过升级三选一获得的强化等级。

| 等级 | 玩法定位 | 成长方向 |
| ---: | --- | --- |
| Lv0 | 未强化 | 可以保留当前基础释放机制，但没有月潮成长效果。 |
| Lv1 | 基础月潮状态 | 小幅提升移动、跳跃、普攻节奏和伤害；普攻偶发残影水刃。 |
| Lv2 | 稳定强化状态 | 持续时间增加，残影水刃更稳定，移动水线更连续。 |
| Lv3 | 终阶爆发状态 | 残影斩追加伤害和命中反馈更强，但不扩大成遮挡层。 |

后续实现字段先按趋势定义，不在本文锁死具体数值：

- `duration` 随等级增加。
- `moveSpeedMultiplier` 随等级增加。
- `jumpMultiplier` 或空中控制随等级增加。
- `attackSpeedMultiplier` 随等级增加。
- `damageMultiplier` 随等级增加。
- `afterimageSlashDamage` 随等级增加。
- `afterimageTriggerRate` 随等级增加。

限制：

- 不提供长期无敌；最多只允许开启动作有短暂抗打断或减伤。
- 普攻残影和移动水线必须短寿命、低透明度。
- 大招期间普通技能只增加月潮边缘视觉，不改变技能语义。
- 大招期间不能让直线、扇形、防反、位移、控场和破甲全部变成同一种大范围爆发。

## Upgrade Choice Rules

每次升级生成最多 3 个成长选项。成长选项来自：

1. 未习得普通技能。
2. 已习得且未满 Lv3 的普通技能。
3. 未满 Lv3 的大招强化。

选择结果：

| 选项类型 | 选择后效果 |
| --- | --- |
| 未习得普通技能 | 习得该技能，等级为 Lv1。 |
| 已习得普通技能 | 该技能等级 +1。 |
| 大招强化 | `ultimateLevel + 1`。 |

候选池硬规则：

- 已满 Lv3 的普通技能不再进入候选。
- 已满 Lv3 的大招不再进入候选。
- 未接入素材、HUD 或技能逻辑的普通技能不进入候选。
- 同一次升级中不重复出现同一个技能。
- 候选不足 3 个时，有几个显示几个。
- 如果所有已接入普通技能和大招都满级，本次升级不弹选择，只获得攻击和生命成长。

推荐权重：

| 选项类型 | 权重 |
| --- | ---: |
| 未习得普通技能 | 3.0 |
| 已习得普通技能升级 | 1.3 |
| 大招强化 | 1.1 |

保底规则：

- 如果连续 3 次升级都没有出现未习得技能，下一次升级必定至少出现 1 个未习得技能。
- 如果玩家到 Lv5 仍未见过大招强化，下一次升级必定出现大招强化。
- 保底只保证“出现”，不强制玩家选择。

## Input and UI

HUD 要求：

- 常驻显示当前 `runLevel`。
- 常驻显示当前 XP 和下一级 XP 需求。
- 显示当前基础攻击、攻击加成和总攻击时应区分来源。
- 显示当前生命和最大生命。
- 常驻 HUD 只显示当前技能小图标，不展示 3 个普通技能槽。
- 当前技能图标显示技能等级：I / II / III。
- 未装备但已习得技能可在暂停界面或升级界面中查看。
- 大招充能显示在角色 HUD 左侧圆框内；大招等级在暂停页显示：0 / I / II / III。

升级选择 overlay：

- 弹出时暂停战斗。
- 最多展示 3 个选项。
- 选项区分“习得新技能”“技能精进”“终式精进”。
- 选择后立即恢复战斗。
- 如果本次升级没有可用技能/大招成长项，不弹 overlay，只显示等级提升和属性成长提示。

## Final Rules Summary

1. 不加入局外成长。
2. 角色等级只在单局内生效。
3. 角色等级不设上限。
4. 每局开始玩家为 Lv1。
5. 每次升级自动提升基础攻击和最大生命。
6. 攻击使用 `baseAttack(level)` 公式。
7. 最大生命使用 `maxHp(level)` 公式。
8. 升级时当前生命获得小额恢复。
9. 玩家开局习得 2 个普通技能：水龙破、打潮刃。
10. 目标普通技能池共 9 个。
11. 同时最多装备 3 个普通技能。
12. 每个普通技能最高 Lv3。
13. 大招 `终式·月潮无间` 最高 Lv3。
14. 大招不占普通技能槽。
15. 每次升级弹出最多 3 个成长选项。
16. 成长选项来自：未习得普通技能、已习得普通技能升级、大招升级。
17. 选择未习得技能后，习得该技能 Lv1。
18. 选择已习得技能后，该技能等级 +1。
19. 选择大招后，`ultimateLevel +1`。
20. 已满 Lv3 的普通技能和大招不再进入候选。
21. 未接入素材、HUD 或技能定义的技能不进入候选。
22. 候选不足 3 个时，有几个显示几个。
23. 所有技能和大招满级后，升级只获得攻击和生命成长，不再弹选择。
24. 死亡或重开后，等级、经验、技能习得、技能等级、大招等级全部重置。
