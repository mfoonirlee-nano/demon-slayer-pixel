# 装备池设计

> 从 [equipment.md](./equipment.md) 拆出，用于记录 6 个流派、18 件装备和各品质效果。

本文件是第一版品质实现的效果准稿。普通、精良、觉醒三档效果都要实现；具体数值、冷却和倍率可以在实现时微调，但不能改变每件装备的定位。

每件装备除下文原有机制外，还按品质百分比提高对应槽位主属性；同槽装备的三档比例存在小幅差异，完整数值见 [equipment.md 的主属性百分比表](./equipment.md#primary-stat-percentages)。百分比与机制同时生效，只使用当前品质的比例，不叠加低品质比例。

## Implementation Flags

`requiresUltimate` 表示当前品质的主要收益依赖大招能量、大招命中、大招保留或大招期间状态。玩家尚未习得大招时，该品质候选不进入掉落池，也不降级补同 ID 低品质。

| 装备 ID | 需要 `requiresUltimate` 的品质 | 说明 |
| --- | --- | --- |
| `flow_blade` | 觉醒 | 觉醒效果给大招能量。 |
| `flow_garb` | 无 | 只影响释放技能后的机动和减伤。 |
| `flow_talisman` | 觉醒 | 觉醒效果额外给大招能量。 |
| `burst_blade` | 觉醒 | 觉醒效果依赖大招命中低血 Boss。 |
| `burst_garb` | 无 | Boss 保命和技能能量，不依赖大招。 |
| `burst_talisman` | 普通、精良、觉醒 | 整件装备定位是 Boss 战大招循环。 |
| `shadowstep_blade` | 觉醒 | 觉醒效果给大招能量。 |
| `shadowstep_garb` | 无 | 只影响移动容错。 |
| `shadowstep_talisman` | 觉醒 | 觉醒效果在 Boss 附近给大招能量。 |
| `hunt_blade` | 无 | 强化普攻会生成覆盖新增攻击距离的可见水刃效果。 |
| `hunt_garb` | 无 | 只影响击杀后的机动和受伤减免。 |
| `hunt_talisman` | 普通、精良、觉醒 | 每个品质的击杀收益都包含大招能量。 |
| `risk_blade` | 无 | 只影响低血伤害窗口。 |
| `risk_garb` | 无 | 只影响低血或 Boss 战保命窗口。 |
| `risk_talisman` | 觉醒 | 觉醒效果包含部分大招能量。 |
| `tempo_blade` | 无 | 只影响普攻频率和伤害惩罚。 |
| `tempo_garb` | 无 | 只影响受伤后的节奏恢复。 |
| `tempo_talisman` | 无 | 大招能量获取降低是代价，不是掉落依赖；未习得大招时只生效技能消耗部分。 |

## Equipment Pool

### 1. 流水系 `flow`

流水系强调普攻与技能之间的转换，让玩家在普攻积攒节奏后释放强化技能。

#### 流水共鸣

| 已装备流水件数 | 效果 |
| ---: | --- |
| 2 | 保留通用的触发门槛降低，并持续恢复技能能量，每秒 `2` 点。 |
| 3 | 保留 2 件效果；流水核心效果触发时额外获得技能能量，并持续恢复生命，每秒 `1` 点。 |

#### 流水刃 `flow_blade`

槽位：`blade`

定位：普攻积攒，强化下一次技能。

| 品质 | 效果 |
| --- | --- |
| 普通 | 普攻命中 4 次后，下一次技能获得「涌流」：技能伤害提高。释放技能后清空层数。 |
| 精良 | 普攻命中 3 次后触发「涌流」；强化技能命中敌人时返还少量技能能量。 |
| 觉醒 | 普攻命中 3 次后触发「涌流」；强化技能命中 Boss 时额外获得大招能量。 |

设计意图：鼓励玩家在技能之间穿插普攻，而不是有技能就立刻释放。

#### 涟波衣 `flow_garb`

槽位：`garb`

定位：释放技能后的移动容错。

| 品质 | 效果 |
| --- | --- |
| 普通 | 释放技能后，短时间内移动速度提高。 |
| 精良 | 释放技能后，短时间内移动速度提高，并获得轻微受伤减免。 |
| 觉醒 | 释放技能后获得移动速度和轻微减伤；如果强化技能命中 2 个以上目标，持续时间延长。 |

设计意图：让技能不仅是输出按钮，也能帮助玩家穿越危险区域。

#### 潮声符 `flow_talisman`

槽位：`talisman`

定位：技能命中返还。

| 品质 | 效果 |
| --- | --- |
| 普通 | 技能命中 2 个以上敌人时，返还技能能量。 |
| 精良 | 技能命中 2 个以上敌人时返还更多技能能量；命中 Boss 也计作一次有效命中。 |
| 觉醒 | 技能命中 3 个以上敌人或命中 Boss 时返还技能能量，并额外获得少量大招能量。 |

设计意图：鼓励玩家选择更好的释放位置，而不是空放技能。

### 2. 破势系 `burst`

破势系强调 Boss 战窗口、低血斩杀和大招爆发。

#### 破势共鸣

| 已装备破势件数 | 效果 |
| ---: | --- |
| 2 | 燃魂符基础触发冷却从 `90` 帧缩短至 `60` 帧，约 `1` 秒；破月刃对 Boss 的触发血线从 `35%` 提高至 `50%`。 |
| 3 | 保留 2 件效果；燃魂符核心触发时额外获得 `2` 点技能能量，精良或觉醒的技能命中额外触发也会再获得 `2` 点。 |

#### 破月刃 `burst_blade`

槽位：`blade`

定位：Boss 斩杀。

| 品质 | 效果 |
| --- | --- |
| 普通 | Boss 生命低于一定比例时，对 Boss 伤害提高。 |
| 精良 | Boss 生命低于一定比例时，对 Boss 伤害提高；首次进入斩杀线时，下一次普攻变为强化斩击。 |
| 觉醒 | Boss 生命低于一定比例时伤害提高；大招命中低血 Boss 时追加一次斩击。 |

设计意图：让 Boss 后半段出现明显收割感。

#### 断月衣 `burst_garb`

槽位：`garb`

定位：Boss 战保命。

| 品质 | 效果 |
| --- | --- |
| 普通 | 每场 Boss 战第一次受到致命伤害时，保留 1 点生命并获得短暂无敌。 |
| 精良 | 致命保护触发后，同时获得短暂移动速度提高。 |
| 觉醒 | 致命保护触发后，清除受击硬直，获得短暂无敌，并获得一格技能能量。 |

设计意图：只保护 Boss 战关键失误，不提供常驻无脑坦度。

#### 燃魂符 `burst_talisman`

槽位：`talisman`

定位：Boss 战大招循环。

| 品质 | 效果 |
| --- | --- |
| 普通 | 对 Boss 造成伤害时，额外获得少量大招能量，该效果有短冷却。 |
| 精良 | 对 Boss 造成伤害时获得大招能量；技能命中 Boss 时额外触发一次。 |
| 觉醒 | 对 Boss 造成伤害时获得大招能量；击杀 Boss 后保留部分大招能量进入下一幕。 |

设计意图：让 Boss 战本身成为大招资源来源，而不是只靠清小怪积攒。

### 3. 影步系 `shadowstep`

影步系替代原“守势”方向。它不鼓励站桩防御，而是通过移动、穿插、贴近危险区域来获得收益。

#### 影步共鸣

| 影步装备数量 | 效果 |
| ---: | --- |
| 2 | 获得 `15%` 闪避几率，使角色更不容易被击中。 |
| 3 | 保留 2 件效果；触发「掠影」时额外获得 `10` 点技能能量。 |

#### 流影刃 `shadowstep_blade`

槽位：`blade`

定位：移动后强化普攻。

| 品质 | 效果 |
| --- | --- |
| 普通 | 连续移动一段距离后，下一次普通攻击变为「影斩」，攻击范围略微扩大。 |
| 精良 | 连续移动一段距离后触发「影斩」；影斩范围扩大，并对小怪造成额外伤害。 |
| 觉醒 | 影斩命中敌人后，短时间内再次移动可更快积攒下一次影斩；影斩命中 Boss 时获得少量大招能量。 |

设计意图：鼓励玩家拉扯、换边、跳入怪群再斩出，而不是站桩输出。

#### 踏影衣 `shadowstep_garb`

槽位：`garb`

定位：移动中的轻量容错。

| 品质 | 效果 |
| --- | --- |
| 普通 | 连续移动时，受到小怪接触伤害降低；停止移动后效果快速消失。 |
| 精良 | 连续移动时受到小怪接触伤害降低，并略微降低受伤击退。 |
| 觉醒 | 连续移动时获得接触伤害减免和击退减轻；受伤后如果仍在移动，短时间内获得移动速度提高。 |

设计意图：让玩家靠移动获得安全感，而不是靠站住变硬。

#### 掠影符 `shadowstep_talisman`

槽位：`talisman`

定位：靠位移获得资源。

| 品质 | 效果 |
| --- | --- |
| 普通 | 从敌人附近经过后，获得少量技能能量，该效果有短冷却。 |
| 精良 | 从敌人附近经过后获得技能能量；附近敌人数量较多时额外获得少量技能能量。 |
| 觉醒 | 从敌人附近经过后获得技能能量；附近敌人数量较多时额外获得技能能量；在 Boss 附近停留短时间后，额外获得少量大招能量。 |

设计意图：让玩家用走位换资源，形成“进场—穿梭—收益—脱离”的循环。

### 4. 狩猎系 `hunt`

狩猎系强调清怪、连杀和地图压制，把小怪压力转化为滚动收益。

#### 狩猎共鸣

| 已装备狩猎件数 | 效果 |
| ---: | --- |
| 2 | 狩牙刃触发门槛从 `2` 次击杀降至 `1` 次；逐猎衣从 `3` 次降至 `2` 次；连珠符冷却从 `4` 秒降至 `3` 秒。 |
| 3 | 狩牙刃强化常态生效；逐猎衣触发门槛从 `3` 次击杀降至 `1` 次；连珠符冷却从 `4` 秒降至 `2` 秒。 |

#### 狩牙刃 `hunt_blade`

槽位：`blade`

定位：连杀强化普攻。

| 品质 | 效果 |
| --- | --- |
| 普通 | `4` 秒内连续击杀 `2` 个小怪后，下一次普攻范围扩大，并投射覆盖新增攻击距离的可见水刃。 |
| 精良 | `4` 秒内连续击杀 `2` 个小怪后，下一次普攻范围扩大、伤害提高，并投射可见水刃。 |
| 觉醒 | `4` 秒内连续击杀 `2` 个小怪后，`5` 秒内的普攻持续获得范围与伤害强化，并投射可见水刃。 |

设计意图：让清怪高手越打越顺；水刃只负责呈现强化攻击新增的距离，实际伤害仍由同一次普攻判定。

#### 逐猎衣 `hunt_garb`

槽位：`garb`

定位：击杀后的机动性。

| 品质 | 效果 |
| --- | --- |
| 普通 | `4` 秒内连续击杀 `3` 个小怪后，短时间内移动速度提高。 |
| 精良 | `4` 秒内连续击杀 `3` 个小怪后提高移动速度；后续击杀会刷新持续时间。 |
| 觉醒 | `4` 秒内连续击杀 `3` 个小怪后提高移动速度，并获得下一次受伤减免；后续击杀可刷新加速并重新准备防护。 |

设计意图：让玩家利用击杀窗口穿越地图或脱离包围。

#### 连珠符 `hunt_talisman`

槽位：`talisman`

定位：击杀回能。

| 品质 | 效果 |
| --- | --- |
| 普通 | 击杀小怪时恢复 `10` 点技能能量和 `10` 点大招能量，冷却 `4` 秒。 |
| 精良 | 击杀小怪时恢复 `20` 点技能能量和 `20` 点大招能量，冷却 `4` 秒。 |
| 觉醒 | 击杀小怪时恢复 `30` 点技能能量和 `30` 点大招能量，冷却 `4` 秒。 |

设计意图：把小怪潮变成稳定资源来源；冷却期间的击杀不排队、不刷新冷却，Boss 击杀也不会触发或重置该效果。

### 5. 残心系 `risk`

残心系强调低血、高风险和反杀窗口。该流派必须有明确阈值和冷却，避免成为无条件高收益。

#### 残心共鸣

| 已装备残心件数 | 效果 |
| ---: | --- |
| 2 | 暂无套装效果。 |
| 3 | 返魂符触发时额外获得 `2` 点技能能量。 |

#### 残心刃 `risk_blade`

槽位：`blade`

定位：低血增伤。

| 品质 | 效果 |
| --- | --- |
| 普通 | 生命低于一定比例时，普攻伤害提高。 |
| 精良 | 生命低于一定比例时，普攻和技能伤害提高。 |
| 觉醒 | 生命低于一定比例时伤害提高；首次进入低血状态后，下一次技能获得额外伤害。 |

设计意图：让低血成为反击机会，而不是常驻伤害加成。

#### 赤纹衣 `risk_garb`

槽位：`garb`

定位：低血容错。

| 品质 | 效果 |
| --- | --- |
| 普通 | 生命低于一定比例时，受到伤害降低。 |
| 精良 | 生命低于一定比例时受到伤害降低，并增加受伤无敌时间。 |
| 觉醒 | 每场 Boss 战首次进入低血时，清除受击硬直并获得短暂无敌。 |

设计意图：给高风险打法一个可读的保命窗口，但不能抵消所有风险。

#### 返魂符 `risk_talisman`

槽位：`talisman`

定位：濒死资源爆发。

| 品质 | 效果 |
| --- | --- |
| 普通 | 每幕首次生命低于一定比例时，获得技能能量。 |
| 精良 | 每幕首次生命低于一定比例时，获得更多技能能量。 |
| 觉醒 | 每幕首次生命低于一定比例时，补满至少一格技能能量，并获得部分大招能量。 |

设计意图：低血时打开一次反击窗口，而不是持续无限回能。

### 6. 节奏系 `tempo`

节奏系强调更频繁地打出动作，但高频收益必须伴随代价或上限。

#### 节奏共鸣

| 已装备节奏件数 | 效果 |
| ---: | --- |
| 2 | 暂无套装效果。 |
| 3 | 暂无套装效果。 |

#### 疾奏刃 `tempo_blade`

槽位：`blade`

定位：普攻频率。

| 品质 | 效果 |
| --- | --- |
| 普通 | 普攻命中冷却降低，但单次普攻伤害略低。 |
| 精良 | 普攻命中冷却进一步降低，单次伤害惩罚降低。 |
| 觉醒 | 普攻命中冷却降低；连续命中同一目标后，下一次普攻不受伤害惩罚。 |

设计意图：让玩家选择更快的近战节奏，而不是无脑提高总伤害。

#### 迅风衣 `tempo_garb`

槽位：`garb`

定位：受伤后快速回到战斗。

| 品质 | 效果 |
| --- | --- |
| 普通 | 受伤后的击退略微降低。 |
| 精良 | 受伤后的击退降低，受伤后短时间移动速度提高。 |
| 觉醒 | 受伤后击退降低并提高移动速度；如果短时间内没有再次受伤，获得少量技能能量。 |

设计意图：减少被连续压制的挫败感，但不直接免伤。

#### 鸣拍符 `tempo_talisman`

槽位：`talisman`

定位：技能费用和大招频率取舍。

| 品质 | 效果 |
| --- | --- |
| 普通 | 技能消耗降低，但大招能量获取略微降低。 |
| 精良 | 技能消耗降低更多，大招能量获取惩罚降低。 |
| 觉醒 | 技能消耗降低；连续释放不同技能时，下一次技能额外返还部分能量。 |

设计意图：给喜欢高频技能的玩家明确选择，同时通过大招收益惩罚控制总强度。
