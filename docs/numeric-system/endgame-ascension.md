# 通关后进阶难度（血月试炼）

> 实现状态：目标设计，未实现。本文定义 13 幕主线通关后的横向进阶难度阶梯；当前源码没有通关状态、进阶层或词条系统。依赖 13 幕主线（见 [../game-design/act-structure.md](../game-design/act-structure.md)）先成立。

## Purpose

给「约 10 小时差异化体验」补上首次通关后的重玩动力。第 13 幕击败万相血月即单局通关，但若通关后只剩重复同一条 13 幕，长期动力不足。血月试炼提供一条**可叠加的进阶难度阶梯**（类 Hades 热度 / Slay the Spire 升级），每层叠加可读的负面词条。

核心约束（与设计支柱一致，见 [../game-design/game-overview.md](../game-design/game-overview.md) Non-Goals）：

- **横向解锁，不给局外永久战力**：进阶层只解锁「更难的挑战」，不给任何永久属性、永久攻击、永久血量。每局仍从基础能力开始、死亡清空。
- **可读**：每层词条必须能在开局界面看清「这层难在哪」，不做隐藏数值膨胀。
- **不靠纯数值膨胀**：优先用机制词条（敌人更快、Boss 多一阶段、觉醒段提前、喘息减少）制造差异，而非只给全体 +X% 血量。

## State

```ts
// 仅记录"已解锁到第几层"和"当前选择第几层"，不存任何战力数值
ascensionUnlocked: number;   // 已通关解锁的最高进阶层，初始 0
ascensionSelected: number;   // 本局选择挑战的进阶层，0 = 标准 13 幕
```

- 首次通关第 13 幕：`ascensionUnlocked` 由 `0` → `1`。
- 之后每在第 `n` 层通关：`ascensionUnlocked = max(ascensionUnlocked, n + 1)`。
- 开局可选 `0 .. ascensionUnlocked` 任意层（允许回退练习）。
- 进阶层仅是开局配置，不写入任何永久角色属性；这两个字段是唯一允许跨局保留的状态，且只表示「解锁进度」。

## Ascension Layers

每层在前一层基础上**新增**一个词条（叠加，不替换）。建议前几层：

| 层 | 新增词条 | 类型 | 可读提示 |
| ---: | --- | --- | --- |
| 1 | 敌人移动/冲刺速度 `+8%` | 机制+数值 | 「群体更快」 |
| 2 | 觉醒段提前：第 5 幕起即用觉醒形态 | 机制 | 「觉醒墙提前」 |
| 3 | 资源减少：水晶/宝箱奖励 `-15%` | 数值 | 「补给更紧」 |
| 4 | 喘息片段权重 `-30%`（`breather`/`safeBridge`） | 机制 | 「更少喘息」 |
| 5 | 所有 Boss 多一阶段（含基础 Boss） | 机制 | 「Boss 更难收尾」 |
| 6 | 敌人同屏预算 `+15%` | 数值 | 「敌潮更密」 |
| 7 | 觉醒招冷却下限再降 | 机制 | 「觉醒招更频繁」 |
| 8 | 终幕万相血月额外召唤上限 `4 → 6` | 数值 | 「终幕更乱」 |

> 层数与具体词条为指导值，须按 [../game-design/balance-acceptance.md](../game-design/balance-acceptance.md) 试玩微调。上限层数第一版建议封顶在能保持「可读且可解」的范围内（约 8-12 层），不做无限叠加，避免回到「靠数值膨胀拉时长」。

## 与 threatScalar 的关系

进阶词条**不改写** [act-and-threat.md](act-and-threat.md) 的基础 `threatScalar` 公式，而是作为独立乘数/开关叠加在其之上，便于单独开关核对：

```ts
effectiveThreat = threatScalar * ascensionThreatMul(ascensionSelected)
// 机制类词条（提前觉醒、多一阶段、减喘息）走各自系统的开关，不进 threatScalar
```

这样标准 13 幕（`ascensionSelected = 0`）的曲线与进阶层完全可分离验证。

## Acceptance

- 每层词条在开局界面可读，玩家进局前知道「这层难在哪」。
- 进阶层不引入任何局外永久战力；关闭进阶（选第 0 层）时体验与标准 13 幕完全一致。
- 高层仍「难但可解」：每层都应有熟练玩家的通关路径，不出现纯数值不可解。
- 通关率随层数平滑下降，不出现某一层断崖式归零。

## Implementation Notes

- 先做好 13 幕主线与通关结算，再接进阶层；进阶是 P5，依赖主线 P4 成立。
- 解锁进度是唯一跨局持久化字段，必须和「局内构筑、死亡清空」严格分开，避免被误解为局外养成。
- 词条优先用机制开关（复用 `actBand`、觉醒叠加、平台权重、奖励倍率系统），减少新数值面。
- 每个词条都要有开局可读文案；没有文案的词条不进池。
