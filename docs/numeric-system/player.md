# 玩家数值

> 实现状态：已实现。本文记录当前源码中已经生效的玩家战斗数值。

## Purpose

记录玩家基础属性、普通攻击、下落攻击、技能、大招、受伤与无敌的当前生效数值。

## Current State

玩家当前包含局内等级成长：升级提高等级基础攻击、最大生命和技能能量上限。运行时 `baseAttack`、`maxHp` 和 `skillEnergyMax` 物化保存“等级基础值 + 当前装备加成”：刃器提高攻击力、衣装提高最大生命、饰符提高技能能量上限。攻击水晶和宝箱仍可以提高 `attackBonus`，治疗奖励可以恢复生命；大招上限当前不随等级提升。

## Key Formulas

基础属性：

| 项 | 当前值 | 说明 |
| --- | ---: | --- |
| 初始 X | `148` | 角色出生横坐标 |
| 初始 Y | `GROUND_Y - 94 = 366` | 由地面偏移计算 |
| 碰撞体 | `44 x 94` | `w=44`、`h=94` |
| 移速 | `4` | 左右移动速度 |
| 跳跃速度 | `14` | 跳跃时 `vy = -jump` |
| 初始朝向 | `1` | 向右 |
| 最大生命 | `100` 起 | 等级基础值按 `maxHp(level)` 成长，再乘衣装 `+8%` 至 `+33%` |
| 等级基础攻击 | `16` 起 | 按 `baseAttack(level)` 成长，再乘刃器 `+10%` 至 `+41%` |
| 攻击加成上限 | `24` | 攻击水晶和宝箱最多提供 `+24`；刃器百分比不放大这部分加成 |
| 技能能量上限 | `90` 起 | 等级基础值每级 `+10`，再乘饰符 `+9%` 至 `+38%`；每 `30` 点 1 格 |
| 技能格数上限 | `3` 起 | `floor(skillEnergyMax / 30)` |
| 大招能量上限 | `100` | 满后可释放大招 |

装备属性只取当前装备的当前品质，并按当前等级裸属性计算后四舍五入。换装或降品导致最大生命、技能能量上限降低时，当前生命和技能能量分别夹取到新上限；死亡、重开或返回开始界面清空装备后，装备提供的属性随之移除。

技能释放：

- 技能释放消耗 `30` 技能能量。
- 技能格数同步公式为 `floor(skillEnergy / 30)`，上限为 `floor(skillEnergyMax / 30)`。
- 释放瞬间会对玩家前方半径范围内目标结算一次范围伤害。

释放瞬间范围伤害：

| 技能 | 小怪基础伤害 | 小怪距离缩放 | Boss 基础伤害 | 半径 |
| --- | ---: | ---: | ---: | ---: |
| 潮龙·破阵 | `34` | `42` | `56` | `30` |
| 弦月·潮刃 | `37` | `45` | `62` | `30` |
| 镜潮·护返 | `40` | `48` | `68` | `30` |

小怪伤害：

```ts
(enemyBase + ratio * enemyScale) * (1 + attackBonus * 0.025)
```

Boss 伤害：

```ts
bossBase * ratio
```

Boss 判定半径额外增加 `40`，最低伤害比例为 `0.2`。当前释放瞬间的 Boss 伤害不读取攻击加成。
