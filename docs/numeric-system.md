# 数值系统说明

> 对应代码：`src/constants/combat.ts`、`src/constants/assets.ts`、`src/constants/platform.ts`、`src/constants/runtime.ts`、`src/entities/player.ts`、`src/entities/enemy.ts`、`src/entities/boss.ts`、`src/entities/platform.ts`、`src/entities/particle.ts`

本文档整理当前源码中实际生效的玩法数值。`dist/`、素材生成脚本和纯视觉参数不作为玩法数值来源。

## 单位约定

- 运行时刷怪、Boss 出场、平台生成间隔使用秒。
- 普通攻击、技能动画、命中冷却、Boss AI 冷却多使用游戏帧。
- 玩家最终攻击力 = `baseAttack + attackBonus`。
- `elapsed` 表示当前局已进行时间，单位为秒。

## 技能系统

技能释放消耗 `30` 点技能能量。释放后会产生一次角色前方范围判定，并根据技能类型可能继续生成额外特效。

### 释放瞬间范围伤害

| 技能 | 小怪基础伤害 | 小怪距离缩放 | Boss 基础伤害 | 半径 |
| --- | ---: | ---: | ---: | ---: |
| 壹之型 | `34` | `42` | `56` | `30` |
| 贰之型 | `37` | `45` | `62` | `30` |
| 叁之型 | `40` | `48` | `68` | `30` |

小怪伤害公式：

```ts
(enemyBase + ratio * enemyScale) * (1 + attackBonus * 0.025)
```

Boss 伤害公式：

```ts
bossBase * ratio
```

其中 `ratio` 由目标距离决定。Boss 判定半径额外增加 `40`，且最低比例为 `0.2`。当前这段 Boss 伤害不吃攻击加成。

### 技能额外特效

| 技能 | 额外效果 | 伤害 | 关键数值 |
| --- | --- | --- | --- |
| 壹之型 | 向前飞行水龙 | `攻击力 x 1.2` | 速度 `8`，命中冷却 `20` 帧 |
| 贰之型 | 向前飞行剑气 | `攻击力 x 1.5` | 速度 `6`，最大飞行 `140`，命中冷却 `20` 帧 |
| 叁之型 | 防护水幕反击 | `攻击力 x 2` | 最多抵挡并反击 `3` 次 |

来源：`SKILL1_EFFECT_CONFIG`、`SKILL2_EFFECT_CONFIG`、`SKILL3_EFFECT_CONFIG`、`updateSkill1Effects()`、`updateSkill2Effects()`、`hurtPlayer()`。

## 普通敌人

普通敌人生成由 `spawnEnemy()` 控制。无 Boss 时按运行时刷怪间隔生成；Boss 存在时常规刷怪暂停，但 Boss 仍可召唤小怪。

### 刷新规则

| 项 | 当前值 |
| --- | --- |
| 最大同时存在数 | `12` |
| 初始刷怪间隔 | `1.2s` |
| 间隔衰减 | `elapsed * 0.012` |
| 最小刷怪间隔 | `0.38s` |
| 左右生成概率 | `50% / 50%` |
| 右侧生成 X | `WIDTH + 20` |
| 左侧生成 X | `-40` |

刷怪间隔公式：

```ts
max(0.38, 1.2 - elapsed * 0.012)
```

约 `68.3s` 后达到最小间隔。

### 敌人数值

| 项 | 当前公式或值 |
| --- | --- |
| 生命 | `16 + elapsed * 0.3` |
| 接触伤害 | `min(20, 3 + elapsed * 0.1)` |
| 初始速度 | `0.72 + random(0..1.08) + elapsed / 60` |
| 最大绝对速度 | `3.2` |
| 追踪转向力 | `0.03` |
| 离屏销毁边距 | `120` |

接触伤害约 `170s` 后达到上限 `20`。

敌人碰撞体不是直接使用 `ENEMY_CONFIG.w/h`，而是按选中的敌人贴图尺寸、`ENEMY_DRAW_SCALE`、`collisionScaleX=0.42`、`collisionScaleY=0.78` 计算。

来源：`ENEMY_CONFIG`、`enemyCollisionSize()`、`spawnEnemy()`、`updateEnemies()`。

## 平台与地图生成

平台和奖励由 `spawnNextMapSegment()` 按片段生成，而不是单个平台完全随机生成。

### 平台速度

平台向左移动，速度公式：

```ts
-(1.4 + random(0..0.9) + elapsed * 0.02)
```

### 平台层级

| 层级 | Y 范围 |
| --- | --- |
| `low` | `366-367` |
| `mid` | `274-275` |
| `high` | `182-183` |
| `top` | `90-91` |

层级转移偏向相邻层，避免平台生成到角色不可达的高度。

### 片段类型

| 类型 | 作用 |
| --- | --- |
| `breather` | 宽平台，降低压力 |
| `safeBridge` | 常规单平台 |
| `stairUp` | 逐步上升 |
| `stairDown` | 逐步下降 |
| `zigzag` | 三个平台上下折返 |
| `gapJump` | 链式跳跃平台 |
| `hoverPair` | 两个错相位悬浮平台 |
| `rewardRisk` | 安全主路加高风险奖励平台 |

难度在 `120s` 内从早期过渡到后期。高风险片段权重随难度上升，但 `tension` 过高时会增加喘息片段权重。

### 平台生成间隔

当前平台间隔使用目标像素间距和预期平台速度计算：

```ts
difficulty = clamp(elapsed / 120, 0, 1)
targetGap = lerp(280, 205, difficulty)
expectedPixelsPerSecond = expectedPlatformSpeed() * 60
interval = targetGap / expectedPixelsPerSecond * (1 + random * jitter)
```

其中 `jitter` 从 `0.35` 过渡到 `0.16`。最终间隔限制在 `0.62s` 到 `3.2s`。Boss 存在时额外增加 `0.25s`。

来源：`MAP_GENERATION_CONFIG`、`platformVx()`、`nextMapSpawnInterval()`。

## HUD 与暂停面板显示

HUD 通过 `getStateSnapshot()` 暴露以下核心数值：

- 玩家生命、最大生命。
- 玩家分数。
- 基础攻击、攻击加成、总攻击。
- 技能能量、技能格数、当前技能。
- 大招能量、是否就绪。
- Boss 当前生命、最大生命、阶段。

暂停面板当前只展示技能额外特效的伤害公式：

- 壹之型：`角色攻击力 x 1.2`
- 贰之型：`角色攻击力 x 1.5`
- 叁之型：`角色攻击力 x 2`，最多 `3` 次

它没有展示释放瞬间范围伤害公式。

## 当前调参注意事项

- 数值来源分散：基础常量在 `src/constants/*`，真实公式在 `src/entities/*`。
- `PLAYER_COMBAT.skillChargeResetDelay = 45` 被用于 Boss 击杀后的重生计时；运行时按秒递减，所以实际含义是 `45s`，变量名容易误解为帧。
- `RUNTIME_CONFIG.platformSpawnBaseInterval` 和 `platformSpawnRandomInterval` 当前没有被平台生成逻辑使用。
- `CHEST_CONFIG.spawnEvery` 和 `spawnVariance` 当前没有被奖励逻辑使用。
- `ENEMY_CONFIG.yOffsetFromGround`、`w`、`h` 当前没有被敌人生成逻辑直接使用。
- `BOSS_CONFIG.drawOffsetX/drawOffsetY`、`BOSS_SKILL1_CONFIG.drawOffsetX/drawOffsetY` 当前没有被绘制逻辑使用。
