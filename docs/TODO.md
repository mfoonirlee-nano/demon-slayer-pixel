- 整理角色状态与快照字段，统一生命、攻击、技能资源的状态来源。

### 战斗、玩家技能和大招

1. 统一文档口径：多份设计文档仍把已经落地的系统写成“目标设计 / 未实现”，需要按源码现状同步。
2. 发布前质量门禁：补一份固定验收记录，覆盖 `typecheck`、`lint`、`build` 和人工试玩结果。
3. UI/反馈打磨：Boss intro、死亡原因、移动端信息密度和 overlay 输入规则还未闭环。
