# 敌人三层差异矩阵

> 实现状态：设计文档。本文以 `src/systems/enemyDirectorConfig.ts` 的 `ENEMY_ARCHETYPES` 与 `PROFILE_CONFIGS` 为实现定位依据，描述每个 `EnemyId` 在战斗问题、可读语言和组合职责上的差异。它不新增运行时代码，也不表示所有组合已经按幕生成接入。

## Purpose

普通敌人不能只靠血量、速度和伤害拉开差异。每个 `EnemyId` 必须回答三层问题：

1. **战斗问题**：玩家面对它必须改变什么操作。
2. **可读语言**：玩家如何在小尺寸、移动中从轮廓、颜色、音效、前摇和危险区形状读出它。
3. **组合职责**：它和哪些敌人搭配时制造何种压力。

实现定位规则：

- `ENEMY_ARCHETYPES` 定义稳定 `EnemyId`、`tags`、`complexityTier`、`spawnCost`、`baseWeight`、`maxActive` 和基础数值。
- `PROFILE_CONFIGS` 定义导演组合意图：`requiredTags` 是当期必须出现的压力，`preferredTags` 是补强压力。
- 组合职责优先使用 tag 语言描述，例如 `fast`、`vertical`、`ranged`、`heavy`、`ambush`、`swarm`、`control`、`support`，避免把设计写死成固定波次。
- 基础三件套 `chaser` / `crawler` / `runner` 是教学与填充压力；后期组合中应降权或退场，避免基础怪淹没高阶机制。

## Profile Reading Guide

| ProfileId | Required tags | Preferred tags | 组合意图 |
| --- | --- | --- | --- |
| `basic_intro` | `baseline`, `low`, `fast` | — | 用基础追击、低位穿插和短前摇冲刺建立横版生存的移动、跳跃、普攻三件事。 |
| `technique_intro` | `melee_burst`, `ranged` | `baseline`, `fast` | 用近战爆发和远程牵制要求玩家读前摇、分优先级和用技能解围。 |
| `vertical_intro` | `vertical` | `ranged`, `melee_burst`, `fast` | 引入纵向/空中压力，让平台、跳跃和落点判断变成核心。 |
| `heavy_wall` | `heavy` | `baseline`, `melee_burst`, `ranged` | 用重型单位制造正面墙，再用追击、斩击或远程迫使玩家绕行。 |
| `ambush_swarm` | `ambush`, `swarm` | `fast`, `vertical` | 用潜伏与分裂制造后排/脚下混乱，再用快攻或纵向单位压缩反应时间。 |
| `control_support` | `control`, `support` | `baseline`, `ranged` | 用控场和光环支援改变击杀顺序，基础/远程单位负责把玩家赶进危险区。 |
| `mixed_pressure` | — | `fast`, `vertical`, `melee_burst`, `ranged` | 中段混合压力池，检验玩家是否能同时处理速度、纵向、近身与远程。 |
| `fast_mix` | `fast` | `baseline`, `melee_burst`, `ambush` | 觉醒段速度主题：快攻逼位移，近战/潜伏惩罚仓促落点。 |
| `vertical_pressure` | `vertical` | `ranged`, `fast` | 觉醒段纵向主题：空中与落点压力叠加投射物或冲刺。 |
| `chaos_mixed` | — | `vertical`, `ambush`, `ranged`, `heavy`, `control` | 高阶混合池，重点不是数量，而是多方向读招同时成立。 |
| `final` | — | `vertical`, `ambush`, `ranged`, `heavy`, `control`, `support` | 终幕池排除基础三件套，以非基础敌人组成高辨识压力拼图。 |

## Enemy Matrix

| EnemyId | Tags / Tier / Budget定位 | 战斗问题：玩家必须改变什么操作 | 可读语言：轮廓、颜色、音效、前摇、危险区形状 | 组合职责：搭配谁制造何种压力 |
| --- | --- | --- | --- | --- |
| `chaser` | `baseline` / T1 / 低成本、按预算 | 不能原地站桩普攻；玩家要边退边清、利用平台或跳跃重置横向距离。它是默认移动税，不应单独成为致命机制。 | 轮廓保持最普通的直立追妖，不携带武器、翅膀、盾或法器。颜色用低饱和暗肉/灰紫作为基础敌色；脚步声短促连续。前摇几乎只来自接近动画，危险区是贴身小矩形/接触范围。 | 在 `basic_intro` 中和 `crawler`、`runner` 组成基础三件套；在 `heavy_wall` 中绕过 `brute` 的正面墙追赶玩家；在 `control_support` 中把玩家推向 `binder` 咒圈或 `warden` 光环强化区。 |
| `crawler` | `low`, `melee` / T1 / 低成本、最多 5 | 玩家必须向下读脚边，不能只看胸口高度；普攻时机要覆盖低位，跳跃落地前要确认脚下安全。 | 轮廓低伏、宽而贴地，但高度不能低到误导玩家以为打不到。颜色偏土褐/暗紫，爪部有小亮点。音效用刮地声。前摇是压低蓄力、身体后缩；危险区是贴地短扇形或窄横条。 | 在 `basic_intro` 中补足低位压力，惩罚只用跳跃躲 `runner` 的玩家；配 `glider` 时形成上下夹击；配 `binder` 时让玩家在咒圈边缘的地面移动更难。 |
| `runner` | `fast` / T1 / 低成本、最多 3 | 玩家必须读短前摇并用跳、后撤、技能打断或横向错位处理；不能等它贴脸后才反应。 | 轮廓前倾、角/肩线指向冲刺方向。颜色可以有更亮的橙红冲刺边缘。音效是短促吸气或蹄踏加速。前摇是停顿下压、残影聚拢；危险区是细长水平冲刺带。 | 在 `basic_intro` 里教学快攻；在 `fast_mix` 中作为速度主题核心，配 `duelist` 惩罚贪刀，配 `burrower` 惩罚急停，配 `leaper` / `glider` 压缩落点选择。 |
| `duelist` | `melee_burst` / T2 / 中低成本、最多 3 | 玩家不能只按距离判断安全，必须等斩击前摇结束或抓恢复反打；近身时要选择防反、位移或打断。 | 轮廓由双刃和张开的攻击姿态主导。颜色可用冷白刀光与暗红身体区分。音效是拔刃/金属摩擦。前摇是双刃后收或交叉；危险区是近身扇形/短弧形斩击。 | 在 `technique_intro` 中和 `caster` 构成“近身窗口 + 远程牵制”；在 `heavy_wall` 中守住 `brute` 两侧；在 `mixed_pressure` 中专门惩罚玩家为了躲投射物而贴近敌群。 |
| `caster` | `ranged` / T2 / 中成本、最多 2 | 玩家必须改变站位与击杀优先级，不能无限风筝；需要在追击小怪时顺手切后排或用远程/位移处理施法者。 | 轮廓以提灯/法器为最亮识别点。颜色用幽绿、暗紫或琥珀灯芯，避免大面积接近玩家水蓝技能。音效是灯焰蓄能和咒语尾音。前摇是举灯定身；危险区是慢速幽火弹道、圆形落点或直线预警。 | 在 `technique_intro` 中和 `duelist` 分割注意力；配 `brute` 时藏在墙后制造后排目标；配 `vertical_pressure` 的 `glider` / `leaper` 让玩家跳跃路线也被弹道覆盖。 |
| `leaper` | `vertical`, `burst` / T2 / 中成本、最多 2 | 玩家必须观察落点预警，不能把跳跃当作万能躲避；落地前后要保留一次横向位移或技能解围。 | 轮廓是长腿、压低蓄跳和高弧线。颜色用腿部亮纹标识弹跳。音效是拉筋般的蓄力声后接落地重击。前摇是蹲伏锁定；危险区是落点圆形/椭圆形，必要时带短暂冲击波环。 | 在 `vertical_intro` 中承担第一类纵向压力；配 `runner` 形成“水平冲刺 + 落点爆发”；配 `caster` 迫使玩家在躲弹道时仍要看脚下；配 `binder` 把可用落点压缩到咒圈外。 |
| `glider` | `vertical`, `aerial` / T2 / 中成本、最多 2 | 玩家必须处理低空目标与平台边缘，不能只清地面；需要用对空技能、等待俯冲后恢复，或在平台间移动打断它的角度。 | 轮廓由翼膜、低空悬停和收翼俯冲区分。颜色用冷灰翼面和少量紫色眼光。音效是扑翼低频、俯冲时尖啸。前摇是悬停定向、收翼；危险区是斜向俯冲带或平台边缘楔形区域。 | 在 `vertical_intro` / `vertical_pressure` 中和 `leaper` 分担空中与落点压力；配 `crawler` 做上下夹击；配 `caster` 让空中路线被弹道封锁；配 `warden` 时成为光环内难以快速击杀的空中支点。 |
| `splitter` | `swarm` / T3 / 高成本、最多 2 | 玩家必须规划清场顺序，不能无脑把它打进分裂导致场面失控；需要先留技能、聚怪，或在安全窗口一次处理分裂体。 | 轮廓要在活着时就有中线裂缝或双核身体。颜色用不稳定的紫红裂光。音效是壳裂、回声叠音。前摇是身体开裂、影子外溢；危险区不是单次大范围，而是分裂点周围多个小单位的扩散扇区。 | 在 `ambush_swarm` 中和 `burrower` 一起制造后排/脚下混乱；配 `runner` 会把玩家的快速位移路线塞满小体积敌人；配 `binder` 时分裂体占住咒圈边缘，限制绕行。 |
| `brute` | `heavy` / T3 / 高成本、最多 2 | 玩家必须改变目标选择和攻击方向，不能只从正面硬砍；需要绕背、破盾、等盾击恢复或用破甲/爆发技能开路。 | 轮廓高大、宽肩、前置盾牌占主要面积；破盾后轮廓必须明显变窄或露出核心。颜色用暗铁、骨白盾缘和低饱和红眼。音效是重脚步、盾面闷响。前摇是举盾压进或盾击后撤；危险区是正面宽矩形盾击/短弧横扫。 | 在 `heavy_wall` 中作为墙，配 `caster` 保护后排，配 `duelist` 保护侧翼，配 `chaser` 把玩家从安全距离赶向盾墙；在 `chaos_mixed` 中少量出现即可重塑地形感。 |
| `burrower` | `ambush` / T3 / 高成本、最多 1 | 玩家必须追踪地面轨迹和背后风险，不能只盯屏幕中心；停步输出前要确认潜行标记，听到钻出提示要横移。 | 轮廓平时有铲爪/土壳，潜行时保留地面隆起轨迹，不能凭空消失。颜色用土黄、暗褐和少量赤眼。音效是泥土摩擦、钻出前低频震动。前摇是地面裂纹聚焦；危险区是从玩家脚下或背后的圆形钻出点。 | 在 `ambush_swarm` 中和 `splitter` 形成“不可忽视脚下 + 清场顺序”压力；配 `runner` 惩罚慌张横移；配 `caster` 让玩家无法稳定站桩处理远程；配 `control_support` 时把玩家逼回咒圈。 |
| `binder` | `control` / T4 / 很高成本、最多 1 | 玩家必须尊重地面区域，不能把安全只理解为远离敌人；需要提前离开咒圈、打断施法或用技能清出通路。 | 轮廓是长袍、符纸、手势或法杖，身体不应像 `caster` 一样以提灯为核心。颜色用暗紫符文、地面红黑咒线。音效是持续吟唱与锁链/纸符声。前摇是举手画阵；危险区是清晰圆形、环形或分段地面咒圈。 | 在 `control_support` 中和 `warden` 一起改变击杀优先级；配 `chaser` / `crawler` 把玩家赶进或钉在咒圈边；配 `leaper` 压缩可用落点；配 `caster` 形成“不能站这里，也不能慢慢走”的区域封锁。 |
| `warden` | `support` / T4 / 最高成本、最多 1 | 玩家必须改变击杀优先级，优先切支援核心；否则普通敌人的血量、速度或威胁窗口被间接放大。 | 轮廓要像移动阵眼/旗手/祭司，光环来源明确但体型仍是小怪。颜色用稳定金紫或暗红环，不覆盖全屏。音效是低频脉冲或钟鸣循环。前摇是插旗/结印开启光环；危险区是以它为中心的圆形光环边界，不是直接伤害大圈。 | 在 `control_support` 中和 `binder` 形成“先杀谁”的判断题；配 `brute` 让墙更难快速拆；配 `glider` 让空中单位成为高价值但难触达目标；配 `caster` 保护远程火力点。 |


## Concrete Change Direction

这一节把上面的设计语言落到后续实现任务。每行都说明：当前配置已经表达了什么、下一步应该怎么改，以及验收时玩家应该感受到什么。

| EnemyId | 当前配置定位 | 下一步具体改动方向 | 验收口径 |
| --- | --- | --- | --- |
| `chaser` | `baseline`，T1，`spawnCost: 1`，`baseWeight: 1.4`，`maxActive: budget`。它现在是最常出现的填充单位。 | 把行为方向收敛为“横向追击 / 横穿 / 重入场”，不要再给它额外前摇技能；后期 profile 中给基础怪降权，终幕从常规池剔除。 | 玩家看到 `chaser` 时只需要做基础走位和普攻清理，不会把它误读成快攻、远程或控场单位。 |
| `crawler` | `low` + `melee`，T1，低血低成本，`maxActive: 5`，用高 `randomSpeed` 制造脚边变化。 | 优先调普攻可命中高度、前扑恢复硬直和贴地危险区显示；避免因为低矮轮廓导致“打不到但会被蹭伤”。 | 玩家需要低头看脚边，但用基础普攻或短跳落地斩可以稳定处理。 |
| `runner` | `fast`，T1，`spawnCost: 1.2`，`maxActive: 3`，是基础快攻槽。 | 明确冲刺前摇、冲刺水平带和同时冲刺上限；在 `fast_mix` 中可以作为 required 核心，但不要和过多 `leaper` 同时抢落点。 | 玩家能在冲刺前 0.x 秒读到“马上横冲”，失败原因是没反应而不是看不见。 |
| `duelist` | `melee_burst`，T2，较高伤害和中等预算，承担近身爆发。 | 调整为“靠近后有清晰斩击窗口”的单位：前摇、命中帧、恢复帧都要能被防反/位移利用；不要让它像第二个 `runner` 一样纯靠速度。 | 玩家贴脸贪刀会被斩，但等恢复反打能获得明确收益。 |
| `caster` | `ranged`，T2，低速、最多 2，承担后排牵制。 | 先限制投射物密度，再补施法前摇、弹道颜色和后排识别；和 `brute` 同场时优先验证“墙后施法”是否公平。 | 玩家必须决定先切后排还是先清近身，屏幕上不会出现不可读弹幕。 |
| `leaper` | `vertical` + `burst`，T2，最多 2，承担落点爆发。 | 固化落点预警形状和锁定规则：起跳后落点不应无限追踪玩家；落地后给可反打恢复。 | 玩家被命中时能说清楚“我站在落点里”，而不是感觉敌人空中改向追杀。 |
| `glider` | `vertical` + `aerial`，T2，最多 2，承担低空俯冲。 | 把悬停、定向、收翼、俯冲、恢复拆成可读阶段；补对空处理窗口，避免一直停在普通攻击够不到的位置。 | 玩家需要抬头处理空中目标，但等待俯冲后能稳定反击。 |
| `splitter` | `swarm`，T3，`spawnCost: 2`，最多 2，承担清场顺序压力。 | 分裂前必须有裂缝/膨胀读法；分裂体不给完整奖励、不继续分裂；导演上避免和大量基础怪一起刷成纯数量潮。 | 玩家会先规划技能或聚怪再击杀它，而不是因为刷分或误触导致屏幕失控。 |
| `brute` | `heavy`，T3，高血高伤，`spawnCost: 2.2`，最多 2。 | 把正面盾、破盾状态、绕背收益和盾击危险区做清楚；它的速度保持低，不补远程或高速能力。 | 玩家把它当作地形墙/优先级问题，而不是普通大血量追击怪。 |
| `burrower` | `ambush`，T3，`maxActive: 1`，承担潜伏包抄。 | 地面轨迹必须常驻可见；钻出点要提前预警；同场唯一，且不要在 `binder` 咒圈内无提示钻出。 | 玩家可以通过看地面/听音效提前横移，失误来自忽略轨迹。 |
| `binder` | `control`，T4，`spawnCost: 2.6`，`maxActive: 1`，承担地面控场。 | 咒圈需要明确边界、倒计时/收束读法和逃离窗口；不要同时给高伤远程弹幕，避免职责重叠 `caster`。 | 玩家先判断“离开圈还是打断施法”，场面压力来自空间被切割。 |
| `warden` | `support`，T4，最高预算，`maxActive: 1`，承担支援核心。 | 光环来源、半径、受益敌人和优先击杀价值必须可见；支援效果宁可单一强识别，不要堆多种隐藏 buff。 | 玩家看到光环就会改变目标顺序，优先切 `warden` 或把敌群拉出光环。 |

## Profile-to-Implementation Direction

| ProfileId | 具体改动方向 | 不要做 |
| --- | --- | --- |
| `basic_intro` | 保持 `chaser` / `crawler` / `runner` 的三件套教学纯度：横向追击、脚边低位、短前摇冲刺各占一个操作问题。 | 不要提前混入远程、控场或支援，避免第一幕教学目标发散。 |
| `technique_intro` | 优先验证 `duelist` + `caster` 的近远夹击：一个逼近身读斩击，一个逼后排处理。 | 不要把 `runner` 权重拉太高，否则玩家只感到速度压力，看不到技术读招主题。 |
| `vertical_intro` | 让 `leaper` 或 `glider` 至少出现一种，preferred 的 `ranged` / `melee_burst` / `fast` 只做辅助。 | 不要同时塞满所有纵向单位；主题是介绍纵向，不是立即做觉醒段混合压力。 |
| `heavy_wall` | 用 `brute` 做正面墙，再从 `baseline`、`melee_burst`、`ranged` 中选一个补压。 | 不要同时配齐 `caster` + `duelist` + 大量 `chaser`，否则墙后目标过多。 |
| `ambush_swarm` | `burrower` 同场唯一负责脚下/背后，`splitter` 负责清场顺序；`fast` 或 `vertical` 只能作为少量追击补刀。 | 不要把分裂体奖励做满，也不要让潜伏单位无轨迹刷新。 |
| `control_support` | `binder` 切地面，`warden` 改目标顺序；基础/远程单位只负责把玩家推向错误位置。 | 不要给 `binder` 和 `warden` 隐藏效果；控场/支援必须一眼能找到来源。 |
| `mixed_pressure` | 从 `fast`、`vertical`、`melee_burst`、`ranged` 中抽 2-3 个主题，验证玩家多任务读招。 | 不要把所有 preferred tags 一次塞满，同屏压力应由预算而不是种类堆叠控制。 |
| `fast_mix` | 以 `runner` 为速度主语，`duelist` / `burrower` 只惩罚仓促位移后的落点。 | 不要再加入大量 `leaper`，否则水平速度主题会被纵向落点主题覆盖。 |
| `vertical_pressure` | 以 `leaper` / `glider` 为主，`caster` 或 `runner` 只封一部分路线。 | 不要让空中敌人长期停在不可攻击高度。 |
| `chaos_mixed` | 高阶混合只选一条主压力和一条副压力，例如 `ambush + ranged` 或 `heavy + control`。 | 不要把它理解为“所有高阶单位都能一起刷”。 |
| `final` | 排除基础三件套后，用非基础敌人的 `vertical`、`ambush`、`ranged`、`heavy`、`control`、`support` 组成轮换小题。 | 不要让终幕变成单纯加血加速，也不要用基础怪数量填满预算。 |

## Implementation Notes

- 同场高阶单位数量由 `spawnCost` 与 `maxActive` 控制。`binder`、`warden`、`burrower` 应保持同场唯一；`brute`、`splitter`、`caster`、`leaper`、`glider` 应避免在早期幕同时堆满。
- `baseWeight` 只决定倾向，不替代组合职责。若某个 profile 要强调机制，应先通过 required/preferred tag 选池，再由预算控制数量。
- 危险区形状必须服务操作答案：水平带对应跳/错位，圆形落点对应离开落点，扇形对应等恢复或绕背，光环对应优先击杀核心。
- 音效应避免所有敌人都使用同一种“妖怪叫声”。低位、冲刺、施法、重型、潜伏、控场、支援分别需要不同瞬态或循环提示。
- 终幕 `final` 的敌人池应排除基础三件套后再组合高阶压力；否则 `chaser` / `crawler` / `runner` 的数量会稀释 `vertical`、`ambush`、`control`、`support` 的辨识度。
