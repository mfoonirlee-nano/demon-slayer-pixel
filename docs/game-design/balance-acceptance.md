# 平衡测试与验收指标

> 实现状态：设计文档。本文定义试玩验收口径；当前项目尚未接入自动 telemetry。

## Test Principle

平衡验收不以“感觉更难”为目标，而以可复盘指标判断单局循环是否成立。每次大调参后至少跑 5 局手动记录：首 Boss 时间、首 Boss 击杀结果、技能释放频率、死亡原因、升级/装备节奏和平台失误。

## Baseline vs Target

| 指标 | 当前基线 | 目标设计 |
| --- | --- | --- |
| 首 Boss 出场 | 通常约 28s，最早要求 `elapsed > 18s` | 第 1 幕约 35-45s，给玩家先学习基础循环 |
| Boss 重生 | Boss 死后约 45s | 随 `bossKills` 缩短到 32s、28s、24s 下限 |
| 难度来源 | 主要随 `elapsed` 线性增长 | `elapsed + bossKills + act config` 混合驱动 |
| 普通敌人池 | 多个 enemy archetype 已实现，但随机生成未按幕组织 | 每幕显式敌人池，后期约 8 种常规敌人轮换 |
| 成长 | 攻击/治疗水晶与宝箱，技能/大招能量 | XP 小幅成长 + Boss 装备构筑变化 |
| 失败复盘 | 只显示生存时间 | 显示主要死亡原因和一条可执行提示 |

## Core Timing Targets

| 项 | 验收目标 | 失败信号 |
| --- | --- | --- |
| 首次升级 | XP 接入后，普通玩家应在 45-75s 内第一次升级 | 90s 仍未升级，或 30s 内连续升级 |
| 首次技能释放 | 玩家积极击杀时 20-35s 内获得一次技能释放机会 | 技能长期空窗，或开局过快满格 |
| 首次大招 | 90-150s 内出现第一次合理大招机会 | 大招太频繁变成常规技能，或一局几乎不用 |
| 首 Boss 击杀 | 熟悉玩家第 1 幕击杀率 55%-75% | 大多数玩家第一次见面即死，或几乎无风险 |
| 单局长度 | 普通玩家 3-8 分钟形成完整体验 | 1 分钟内频繁暴毙，或 10 分钟后无新变化 |

## Combat Acceptance

| 模块 | 通过标准 |
| --- | --- |
| 普攻 | 普通敌人进入攻击范围时，玩家能稳定判断是否命中；不要求像素级贴脸 |
| 下落攻击 | 命中范围可读，落地反击有收益，但不能无脑替代普攻 |
| 技能 | 至少一种技能能清场，一种技能能处理 Boss/精英，一种技能能提高容错 |
| 大招 | 能解决敌潮或 Boss 阶段压力，但释放时机仍需要选择 |
| 受伤 | 连续受伤多由站位或读招失败造成，不由不可见碰撞造成 |

## Enemy Pressure Acceptance

| 幕 | 目标体验 | 通过标准 |
| --- | --- | --- |
| 第 1 幕 | 教学压力 | 死亡多来自站位和普攻节奏，不来自远程/控场堆叠 |
| 第 2 幕 | 速度压力 | 玩家明显需要处理 runner/duelist 的前摇和冲刺/斩击窗口 |
| 第 3 幕 | 空间压迫 | brute/caster 让玩家改变路线和目标优先级 |
| 第 4 幕+ | 综合轮换 | 压力来源会变化，不是同一敌人和同一 Boss 重复加血 |

## Boss Acceptance

| 项 | 通过标准 |
| --- | --- |
| 入场 | Boss 出场前后有清晰提示，不和高风险平台连续叠加 |
| 阶段 | 66% 和 33% 阈值后的行为差异能被玩家感知 |
| 前摇 | 高伤技能在动画、音效或停顿上可读 |
| 召唤 | 召唤物给压力但不绕过普通敌人的同屏限制 |
| 击杀 | 击杀后奖励明显，战斗有短暂喘息，下一幕变化可感知 |

## Platform and Reward Acceptance

| 项 | 通过标准 |
| --- | --- |
| 可达性 | 连续 5 个片段内不出现明显不可达主路线 |
| 喘息 | 高压片段后能看到 `breather` 或 `safeBridge` 这类恢复节奏 |
| 奖励风险 | 高风险平台奖励更有吸引力，但不是生存必需 |
| Boss 同屏 | Boss 战期间平台压力降低，不和 Boss 技能形成不可解组合 |

## Acceptance Gate

目标设计第一阶段通过条件：

- 第 1 幕首 Boss 前没有明显不可解死亡。
- Boss 击杀能稳定推进第 2 幕且只结算一次。
- 第 2 幕的敌人和平台压力与第 1 幕有可感知差异。
- 升级三选一和装备三选一不会同时显示。
- 死亡后玩家能从界面上知道主要失败原因。
