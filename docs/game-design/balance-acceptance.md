# 平衡测试与验收指标

> 实现状态：设计文档。本文定义试玩验收口径；当前项目尚未接入自动 telemetry。

## Test Principle

平衡验收不以“感觉更难”为目标，而以可复盘指标判断单局循环是否成立。每次大调参后至少跑 5 局手动记录：首 Boss 时间、首 Boss 击杀结果、技能释放频率、死亡原因、升级/装备节奏和平台失误。

## Baseline vs Target

| 指标 | 当前基线 | 目标设计 |
| --- | --- | --- |
| 首 Boss 出场 | 通常约 28s，最早要求 `elapsed > 18s` | 第 1 幕约 35-45s，给玩家先学习基础循环 |
| Boss 重生 | Boss 死后约 45s | 随 `bossKills` 缩短到 32s、28s、24s 下限 |
| 难度来源 | 主要随 `elapsed` 线性增长 | `elapsed + bossKills + act config` 混合驱动 |
| 普通敌人池 | 多个 enemy archetype 已实现，但随机生成未按幕组织 | 每幕显式敌人池，后期约 8 种常规敌人轮换 |
| 成长 | 攻击/治疗水晶与宝箱，技能/大招能量 | XP 小幅成长 + Boss 装备构筑变化 |
| 失败复盘 | 只显示生存时间 | 显示主要死亡原因和一条可执行提示 |

## Core Timing Targets

| 项 | 验收目标 | 失败信号 |
| --- | --- | --- |
| 首次升级 | 第 1 幕 Boss 入场前应提供至少一次升级所需的普通敌人 XP；积极清怪的玩家应在 Boss 前完成首次升级 | 满清首幕供给仍无法升级，或 30s 内连续升级 |
| 首次技能释放 | 玩家积极击杀时 20-35s 内获得一次技能释放机会 | 技能长期空窗，或开局过快满格 |
| 首次大招 | 90-150s 内出现第一次合理大招机会 | 大招太频繁变成常规技能，或一局几乎不用 |
| 首 Boss 击杀 | 熟悉玩家第 1 幕击杀率 55%-75% | 大多数玩家第一次见面即死，或几乎无风险 |
| 单局长度 | 早期单局 3-8 分钟形成完整体验；熟练玩家完整清版（1→13）约 18-22 分钟 | 1 分钟内频繁暴毙，或长局后期只剩同一 Boss 重复加血而无新机制 |

## Combat Acceptance

| 模块 | 通过标准 |
| --- | --- |
| 普攻 | 普通敌人进入攻击范围时，玩家能稳定判断是否命中；不要求像素级贴脸 |
| 下落攻击 | 命中范围可读，落地反击有收益，但不能无脑替代普攻 |
| 技能 | 至少一种技能能清场，一种技能能处理 Boss/精英，一种技能能提高容错 |
| 大招 | `终式·月潮无间` 在有限持续时间内提升追击和普攻爆发；等级提升速度、持续时间和伤害，但不提供长期无敌、无限清场或遮挡 Boss 前摇 |
| 受伤 | 连续受伤多由站位或读招失败造成，不由不可见碰撞造成 |

## Enemy Pressure Acceptance

| 幕 | 目标体验 | 通过标准 |
| --- | --- | --- |
| 第 1 幕 | 教学压力 | 死亡多来自站位和普攻节奏，不来自远程/控场堆叠 |
| 第 2 幕 | 速度压力 | 玩家明显需要处理 runner/duelist 的前摇和冲刺/斩击窗口 |
| 第 3 幕 | 空间压迫 | brute/caster 让玩家改变路线和目标优先级 |
| 第 4-6 幕 | 逐幕新机制 | 每幕解锁的新敌人带来可识别的新压力，第 6 幕 12 敌人解锁完毕 |
| 第 7-12 幕（蚀醒） | 逐幕换主导 profile | 蚀醒幕杂兵组合每幕不同，靠强化召唤池 + profile 切换，不引入新敌人素材 |
| 第 13 幕（终幕） | 终盘限定池 | 万相血月战平台/杂兵压力降低，额外召唤 ≤ 4，不与换相技叠成不可解 |

## 13 幕逐幕击杀率验收

熟练玩家逐幕目标击杀率（与权威幕表 [act-structure.md](act-structure.md) 一致；任何修改先改幕表再同步本文）：

| 幕 | Boss | 目标击杀率 | 失败信号 |
| ---: | --- | ---: | --- |
| 1 | 蛛弦 | 60-75% | 首遇即死率过高，或几乎零风险 |
| 2 | 雾骨 | 55-70% | — |
| 3 | 镜魇 | 50-65% | — |
| 4 | 牙岚 | 50-65% | — |
| 5 | 灯烬 | 45-60% | — |
| 6 | 枯铃 | 40-55% | intro 段末仍无压力上升 |
| 7 | 蛛弦·蚀醒 | 35-50% | 蚀醒首遇被秒杀（断崖），或与基础形态无差异 |
| 8 | 雾骨·蚀醒 | 30-45% | — |
| 9 | 镜魇·蚀醒 | 30-45% | — |
| 10 | 牙岚·蚀醒 | 25-40% | — |
| 11 | 灯烬·蚀醒 | 25-40% | — |
| 12 | 枯铃·蚀醒 | 20-35% | — |
| 13 | 万相血月 | 15-30% | 通关率为 0（不可解），或熟练玩家轻松通关（无终盘感） |

**蚀醒难度墙判据（第 7-12 幕，"难但可解"）**：

- 蚀醒招都有可读预警（线 / 点 / 停顿 / 声），玩家失败后能说出「下次该怎么躲」。
- 蚀醒首遇（第 7 幕）允许高死亡率，但不能是无预警秒杀；玩家应能在 2-3 次尝试内学会主要应对。
- 强度比核对：在第 1 / 6 / 7 / 12 / 13 幕各算一组玩家强度（baseAttack + `attackBonusCap` + 装备品质带 + 对应 `runLevel`）对 `threatScalar`（见 [../numeric-system/act-and-threat.md](../numeric-system/act-and-threat.md)）的比值，确认蚀醒幕是「陡但不断崖」、终幕是「巅峰但可解」。

**通关率目标**：

| 玩家分层 | 单局到达最高幕 | 13 幕通关率 |
| --- | --- | --- |
| 新手（前 2 小时） | 多数止于 3-6 幕 | ~0% |
| 进阶（content 见齐后） | 多数止于 7-12 幕（蚀醒墙） | 偶尔通关 |
| 熟练（数十局后） | 稳定到达蚀醒段 | 稳定但非每局通关 |

## Boss Acceptance

| 项 | 通过标准 |
| --- | --- |
| 入场 | Boss 出场前后有清晰提示，不和高风险平台连续叠加 |
| 阶段 | 基础 Boss 在 66%/33%、蚀醒 Boss 在 75%/50%/25%、终幕在 80/60/40/20% 阈值后行为差异能被感知 |
| 前摇 | 高伤技能在动画、音效或停顿上可读；蚀醒招也必须有预警 |
| 召唤 | 召唤物给压力但不绕过普通敌人的同屏限制；终幕额外召唤 ≤ 4 |
| 蚀醒形态 | 蚀醒 Boss = 基础 + 一招蚀醒妖术 + 多一阶段，玩家能感知它是「学过的形态的强化版」，而非纯加血 |
| 终幕换相 | 万相血月各阶段借招能被认出来源（蛛网/骨雾/镜影/冲刺火线/本体），构成 12 幕机制总复习 |
| 击杀 | 击杀后奖励明显，战斗有短暂喘息，下一幕变化可感知；击败终幕出胜利结算 |

## Platform and Reward Acceptance

| 项 | 通过标准 |
| --- | --- |
| 可达性 | 连续 5 个片段内不出现明显不可达主路线 |
| 喘息 | 高压片段后能看到 `breather` 或 `safeBridge` 这类恢复节奏 |
| 奖励风险 | 高风险平台奖励更有吸引力，但不是生存必需 |
| Boss 同屏 | Boss 战期间平台压力降低，不和 Boss 技能形成不可解组合 |

## Acceptance Gate

目标设计第一阶段（intro 段闭环）通过条件：

- 第 1 幕首 Boss 前没有明显不可解死亡。
- Boss 击杀能稳定推进第 2 幕且只结算一次。
- 第 2 幕的敌人和平台压力与第 1 幕有可感知差异。
- 升级三选一和装备三选一不会同时显示。
- 死亡后玩家能从界面上知道主要失败原因。

13 幕全量通过条件（内容齐备后）：

- 1-6 幕逐幕击杀率落在上表区间，每幕新机制可识别，第 6 幕 12 敌人解锁完毕。
- 7-12 蚀醒幕构成「难但可解」的难度墙：蚀醒首遇不被无预警秒杀，强度比无断崖。
- 第 13 幕万相血月可被熟练玩家通关（通关率 > 0），但非每局通关；击败出胜利结算。
- 一次完整 1→13 清版用时约 18-22 分钟。
- 进阶难度（血月试炼）为横向解锁，不给局外永久战力（见 [../numeric-system/endgame-ascension.md](../numeric-system/endgame-ascension.md)）。
