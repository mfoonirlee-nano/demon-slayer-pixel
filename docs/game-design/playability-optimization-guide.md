# 《月潮夜行》完整可玩性优化指南

> 2026-10-24｜研究与设计建议，尚未采纳为开发规格，未实现新增玩法。
> 依据：当前工作区源码、现有测试与设计契约，以及《死亡细胞》《合金弹头》《哈迪斯 I》《永远的伊苏》相关一手资料。本次未运行游戏；体验问题是待验证假设，文中的目标值不是实测结果。

本文回答：游戏应往什么方向提升；角色、技能、装备、敌人、Boss、地图、成长和重玩怎样共同起作用；有哪些具体候选设计；如何判断哪些值得继续。本文不安排立即编码，也不把前次讨论的“借敌成势”当成已经确定的核心。

详细参考事实、版本差别与证据边界见[参考游戏研究](reference-game-research.md)。当前权威规则仍见[游戏总纲](game-overview.md)、[幕结构](act-structure.md)、[技能契约](player-skills.md)和[装备组合契约](equipment-combos.md)。若采纳本文中改变规则的建议，再同步对应契约。

## 1. 先看最终希望玩家体验到什么

建议把《月潮夜行》发展为：**一场有明确终点的月夜冒险，玩家通过自己的操作与本局获得的剑式、装备，逐渐形成打法；沿途的敌群、地形和事件不断要求他调整打法。**

理想的一局可以这样描述：开局学会用剑和跳跃应付敌人；获得回刃后开始围绕往返路线战斗；选到流水刃后尝试换招衔接；下一段出现盾墙与高台，于是选择绕背或登高；面对 Boss 时发现自己的打法有短板，下一次奖励决定补足防守还是强化爆发；最后知道这一局为什么成功或失败。

优化的五个目标：

1. **操作有掌握感**：玩家能说清自己怎样进步，而不只看到伤害变大。
2. **构筑有身份**：不同装备组合带来不同的移动、出手和资源使用习惯。
3. **遭遇有变化**：场地、敌人组合与目标共同改变每一段战斗。
4. **旅程有起伏**：紧张、施展、发现、恢复和首领考验交替出现。
5. **重开有期待**：玩家既想尝试另一套打法，也知道下一次要练什么。

这五项彼此依赖。新武器没有适合的敌人，会显得无用；有趣的装备太晚才能成形，玩家难以体验；精心设计的 Boss 若读招被特效淹没，学习便无法发生。

## 2. 三条发展方向及推荐取舍

| 方向 | 主要乐趣 | 需要改变什么 | 适配判断 |
| --- | --- | --- | --- |
| 深化单局动作生存 | 手上更熟、每局打法不同、连续战斗有变化 | 打磨基础动作、构筑、遭遇与奖励之间的联系 | **推荐作为主方向**，保留目前核心与13幕骨架 |
| 转为关卡式动作冒险 | 大地图探索、钥匙能力、区域分支与世界发现 | 相机、地图持久化、关卡边界、流程时长与叙事都要重新规划 | 可作另一产品方向，暂不混入本指南的基础假设 |
| 强化自动清场与数值构筑 | 快速成群击杀、组合爆发、低操作负担 | 减少动作承诺，增加自动攻击与同屏数量 | 可用于特殊模式或短暂高潮，不宜覆盖当前读招与剑术定位 |

推荐方向吸收四部参考游戏的不同长处：死亡细胞提供操作条件与路线选择；哈迪斯提供构筑规划与重开反馈；合金弹头提供场景节奏与临时战斗变化；早期伊苏提供简洁操作、弱点发现与冒险的连续感。取舍以本项目的横版空间、触屏操作、像素可读性和单局成长为准。

保留的边界：局内战斗成长、原创月潮剑术、可读夜妖、有限主线、三技能槽、三装备槽。大型分支世界、庞大基地养成、永久属性、海量独立资源与无限叠加状态不进入基础方案。

## 3. 从四部游戏中实际学到什么

### 3.1 死亡细胞：给玩家一个可以主动完成的战斗条件

官方历史更新中的武器会要求玩家争取正面、先控制再攻击、用连段末击完成击杀；传奇装备也曾从主要叠加伤害改为提供专属词缀。开发方还减少过泛滥的联动词缀，因为每件物品都满足太多组合时，规划便失去意义。[Update 19](https://deadcells.com/patchnotes/19)、[Update 23](https://deadcells.com/patchnotes/23)、[Update 30](https://deadcells.com/patchnotes/30)

**设计分析**：玩家获得的应是“我接下来想做什么”。收益有条件、有机会成本，操作才能围绕它组织。对本项目的转化，是让一套构筑拥有清楚的出手顺序与站位要求，同时保留替代组件。

另一个启发是容错。主设计师解释过离台起跳与接近平台时的落点修正，让玩家把注意力放在战斗判断上。[开发者访谈逐字稿](https://arstechnica.com/video/watch/dead-cells-how-to-avoid-falling-to-your-death-war-stories/?c=series) 本项目应检查输入是否表达了玩家意图；这不意味着所有动作都可以随时取消。

### 3.2 哈迪斯 I：基础动作、改招、组合与奖励选择形成一条链

官方补丁中，拳套可通过锤子改成更慢的三连击，或获得蓄力远程特殊攻击；部分组合改变投射方向、资源上限或普攻与特殊攻击的先后关系。重掷和图鉴前置提示则帮助玩家追求构筑目标。[Blood Price](https://www.supergiantgames.com/blog/hades-the-blood-price-update-patch-notes/)、[Nighty Night](https://www.supergiantgames.com/blog/hades-the-nighty-night-update-patch-notes/)、[正式版更新](https://www.supergiantgames.com/blog/hades-updates/)

**设计分析**：基础动作决定“我擅长怎么打”，局内变化决定“这局具体怎么打”，奖励控制让玩家有机会靠自己的决定完成它。对本项目，应先明确角色、技能与装备分别负责哪一层，避免新增三个系统却都只提供加伤。

哈迪斯的永久属性与大量叙事内容不直接迁移。可以借鉴“让游戏回应刚发生的经历”，用简短战斗复盘、妖闻和再遇台词支持下一局。

### 3.3 合金弹头：通过战斗情境变化维持兴奋

SNK 对3代的介绍明确包含不同武器、载具、救援、隐藏内容与路线分岔；6代进一步引入明确的角色性能差异与武器储存。它们属于不同作品，不能视为每一代共有。[3代官方介绍](https://game.snk-corp.co.jp/event/virtual-console/metalslug3/index_metalslug3_j.html)、[6代官方发布说明](https://game.snk-corp.co.jp/press/single.php?num=32)

**设计分析**：变化可以来自战场目标和使用工具的条件。玩家刚才在跑动清敌，下一段守住狭窄位置，再下一段利用短暂强力工具突破。对本项目，适合的是追击、登高、断阵、救援和少量临时武器事件；是否需要可驾驶载具应单独评估。

### 3.4 永远的伊苏：简单操作也能承载弱点与空间学习

本指南以《伊苏 Eternal／II Eternal》为主要对象，以《I・II 完全版／Chronicles》补充同一早期设计脉络。《起源》《VIII》单独标记，闪避减速与 Flash Guard 不属于 Eternal 的机制。

Falcom 的 Eternal 官方攻略要求玩家辨认蝙蝠 Boss 真正合体的信号与假动作；最终 Boss 攻略强调读移动轨迹，并避免太早破坏中央立足空间。II Eternal 的部分场景还通过变身交谈解决问题。[蝙蝠 Boss](https://www.falcom.co.jp/qanda/hints/ys/common01.html)、[最终 Boss](https://www.falcom.co.jp/qanda/hints/ys/common05.html)、[变身交谈](https://www.falcom.co.jp/qanda/hints/ys2/common03.html)

**设计分析**：重要的是玩家发现了规律，随后能更从容地执行。对本项目，可以让 Boss 的动作、地形和短场景共同表达规则。早期伊苏中的指定装备或魔法硬门槛，不适合直接放进随机三槽构筑；所有主线敌人都要保留基础动作可完成的解法。

## 5. 用四种时间尺度组织可玩性

| 时间尺度 | 玩家在决定什么 | 系统应提供什么 |
| --- | --- | --- |
| 每次交手 | 现在打、跳、躲、护返还是留技能 | 可靠动作、清晰敌招、可利用的恢复窗口 |
| 一段遭遇 | 先处理谁、站在哪里、何时引灵 | 有主题的敌群、合理空间、资源与风险 |
| 一幕至一局 | 深化还是转型、走哪条路、为Boss留什么 | 奖励方向、构筑说明、事件与清楚阶段目标 |
| 多次重开 | 想练哪一招、尝试哪一类打法、挑战什么限制 | 复盘、练习、横向内容和可选挑战 |

设计一个新内容时，要指出它主要改善哪一行，并检查它有没有破坏其他行。例如强力自动清场饰符可以提供爆发乐趣，但若同时抹去站位、目标优先级与技能管理，它会降低前三行的选择。

## 6. 基础战斗与手感：先让现有动作值得反复使用

### 6.1 为每个动作写明职责

| 动作 | 建议稳定承担的职责 | 应保留的弱点 |
| --- | --- | --- |
| 普攻 | 低成本处理、补刀、资源循环的基础 | 距离与出手位置有限，不能兼任所有解围手段 |
| 跳跃 | 换层、绕背、躲过低位攻击、选择落点 | 空中也需要观察威胁，落点有承诺 |
| 落击 | 快速下压、处理聚集敌人、从高位兑现优势 | 落点明确且有恢复，不能安全覆盖一切 |
| 护返 | 预判威胁并获得反击机会 | 前摇与有限防护，不能依靠连按无限续护 |
| 潮闪 | 迅速改变位置、穿过局部压力 | 资源成本、方向与落点风险 |
| 大招 | 把已积累资源变成短暂主动压制 | 爆发结束后仍要处理资源与危险 |

### 6.2 优先审视输入与动作衔接

当前按键直接触发跳跃，动作起手在忙碌时会拒绝部分输入。建议先测量“玩家明明按了却没有动作”的具体情境，再决定是否引入短输入缓冲、离台起跳宽限或更清楚的拒绝反馈。不能把未测得的输入延迟写成既有缺陷。

动作取消采用明确边界：允许哪些恢复阶段接跳跃或防守，哪些承诺阶段必须完成。既不能让反应迟钝吞掉输入，也不能让重招没有风险。具体时间以动画、真实判定和不同输入设备共同校准。

精准操作奖励可以放在已有护返或特定剑式中。先比较两条方向：所有角色拥有独立闪避键，或继续由走位、跳跃和已装备技能承担防守。推荐先深化后者；若试玩证实所有构筑都因缺乏基础脱困而受限，再讨论独立闪避，并重新定义潮闪的价值。

### 6.3 让强弱反馈有层级

普通命中、打断、破盾、反击、击杀、大招爆发应有不同但短促的反馈。打击停顿只用于少数重要动作；持续多段命中不能不停冻结世界。受伤应清楚表达伤害来源和短暂无敌结束，屏幕震动、闪屏强度需要可调。

## 7. 角色与武器：先明确身份，再决定制作规模

需要区分三层：**角色决定基础动作和移动习惯；技能决定当前携带的战术工具；装备决定这些动作在本局怎样获得额外价值。** 现有刃器是装备槽，不自动等于一套新的武器动作。

可以比较“同一主角的三种战法”和“多名独立角色”。前者复用世界身份，适合验证操作差异；后者在轮廓、武器、声音与情感上更鲜明，但每人都需要完整的动作、受伤、技能和可读性工作。两者是制作选择，本指南不预先宣布新增角色数量。

以下是三种可供比较的角色方向，名称暂定：

| 方向 | 基础动作与完整循环 | 玩家擅长什么 | 明确短板 |
| --- | --- | --- | --- |
| 潮刃者：流动剑术 | 贴近试探→剑式换位或铺垫→普攻／回刃兑现→移动重整 | 在中近距离切换攻防，利用往返路径 | 需要管理站位，不能稳定远距离站桩 |
| 灯渡客：布置与回收 | 放置一盏有限驻留的灯→在自己与灯之间选择攻击起点→移动改变射线→回收后重新布置 | 预判敌群路线、制造交叉攻击 | 启动慢，敌人逼近或地形改变时要放弃布置 |
| 断潮行者：重击与破阵 | 移动找窗口→短蓄力重击→选择继续压制或收势→重新取得距离 | 正面破势、精确抓恢复窗口 | 空挥和贪刀代价高，对分散目标效率低 |

这些身份必须在没有稀有装备时就能感受到。角色起始资源和规则应允许完整通关；局外解锁提供并列选择。独立角色是否共享九剑式，需要再评审动作表现与身份冲突，不能简单换皮复用全部动作。

角色差异验收：同一场敌群战斗中，三者的理想站位、第一目标、最想拿的奖励和最怕的局面应明显不同。若只是攻击快慢，身份还不充分。

## 8. 技能：从九种功能变成可理解的三槽选择

### 8.1 三槽应允许多种分工

可选结构包括“主攻＋防守＋处理短板”“铺垫＋兑现＋位移”“远近双攻＋资源稳定”。三槽不应强制每局都塞入同一个防守技能。若某个Lv3被动过强，玩家只为被动占槽却很少施放，应检查被动与主动的价值分配。

| 现有技能 | 当前可形成的战术价值 | 建议深化的方向 |
| --- | --- | --- |
| 潮龙 | 中距离直线、穿排 | 用敌列与射线位置体现价值，避免单纯加宽至覆盖全屏 |
| 弦月 | 近身覆盖、解围 | 强化贴近与安全距离的取舍，统一普攻剑气生效说明 |
| 护返 | 预判防守与反击 | 比较宽容多次防护与精准单次强反击，保留各自代价 |
| 潮闪 | 穿线换位 | 让落点和朝向影响后续攻击，不依靠额外无敌时间吸引选择 |
| 回涡 | 聚拢轻敌、制造范围窗口 | 让吸入方向与地形有意义；Boss仍保留独立解法 |
| 破甲 | 提前准备精英／Boss输出 | 让玩家看懂窗口并安排爆发，避免成为所有构筑唯一必带 |
| 雨线 | 对空、多线处理 | 增加清晰的目标高度与覆盖选择，评估随机追加是否有足够反馈 |
| 回刃 | 留刃、换位、锁线回收 | 深化敌列和移动路线的配合，已有完整二段优先保持清晰 |
| 升浪 | 纵向处理与落点防守 | 利用高低敌人、平台边缘、落击衔接体现价值 |

### 8.2 分支升级作为候选，不额外堆一套成长面板

现有Lv1—3负责获得完整功能与精进。若引入改招，应优先放进已有升级选择或少量特定事件；每招至多先设计一对有代价的分支，保留原形态。以下是示例，均需修改对应技能契约后才能采用：

| 分支示例 | 改变的决定 | 代价 |
| --- | --- | --- |
| 潮龙：贯流／折浪 | 贯流适合穿排；折浪在一次指定碰撞后折向处理另一层敌人 | 折浪失去部分直线穿透，反射次数有上限 |
| 护返：守潮／留光 | 守潮连续防护；留光收一枚明确可收的敌弹后主动归还 | 留光收弹后防护结束，对近战只保留基础单次反击 |
| 雨线：散雨／据高 | 散雨覆盖宽；据高从高位命中后稳定追加集中打击 | 高位条件与较窄覆盖，取消同分支随机追加 |
| 升浪：守位／落潮 | 守位适合原地对空；落潮在成功落击后的窗口接招 | 需要承诺落点并等恢复结束，额外收益重新占用伤害预算 |

同一技能的两条路要有适用场景，不能一条在伤害、范围、安全性和成本上全部优于另一条。也不把九招都改成同样的“先完成条件，再领额外伤害”。

大招继续作为本局的高潮能力。可比较更强短爆发和更长低强度两种配置，但先保持移动与普攻强化的既有身份；不同时叠入每招专属大招改版。

## 9. 装备与构筑：让每件装备有明确职责

### 9.1 延续三槽，减少重叠

建议刃器主要定义攻击收益条件，衣装调整移动／生存的取舍，饰符连接或改写某条规则。现有六系作为内容组织方式保留，混搭仍须成立。品质可以增加稳定性和收益，但核心玩法应在较低品质就能体验。

评审一件装备时，填写五句：它让我想做什么；在什么场景最有价值；我为它放弃什么；没有指定搭档时是否仍有用途；世界内怎样看见它生效。只有“伤害提高”难以支撑一件关键装备的身份。

### 9.2 先深化现有组合，再比较新增规则

| 构筑方向 | 当前可用核心 | 战斗循环 | 应有的弱项与替代 |
| --- | --- | --- | --- |
| 聚潮控场 | 流水刃、鸣拍符、回涡等已有组合 | 覆盖铺标→把敌人留在有效区域→换招集中兑现 | 分散远程目标与高移动Boss；可用远程工具补足 |
| 移位破势 | 破月刃、踏影衣、破甲／回涡等 | 移动准备→创造控制或破甲条件→在固定位置爆裂 | 爆裂会落空；对Boss依靠破甲，不靠无限控制 |
| 连杀传印 | 流水刃、连珠符、回刃等 | 铺标→选择补刀对象→向下一目标传播→异招兑现 | 单体场面收益不同；回刃仍独立提供路线价值 |
| 稳态衔接 | 流水刃或破月刃、涟波衣 | 用更宽窗口完成衔接→利用短防护重新站位 | 放弃踏影主动聚怪能力，爆发上限与机动有所取舍 |

以上是已有能力的设计用途，不能标成新增流派已验证成功。应先观察玩家是否理解并主动使用，再判断缺的是说明、奖励供给、适合的遭遇，还是规则本身。

新增装备示例用于拓展比较，并非一次加入全部：

| 候选 | 规则变化 | 机会成本与限制 |
| --- | --- | --- |
| 坠镜符 | 配合留光，把归还弹改为抛物线落地爆破 | 失去直线穿排；前置未成立时不投放为空白奖励 |
| 燕归衣 | 落击命中后可选择一次横向反跃 | 选择反跃放弃落地范围冲击；不能无限踩踏、不能默认踩Boss |
| 空潮刃 | 在明确技能空窗中，用稳定普攻命中缓慢恢复一次施法机会 | 占用刃器槽、牺牲技能爆发；限制单次动作收益，不能空挥或打道具刷能 |
| 守灯衣 | 引灵完成时在原位置留下短时防护灯，玩家可选择继续守位或离开 | 不能移动携带，不能连续叠灯；不得通过满血虚假治疗触发 |
| 断弦符 | 把某一类延迟范围反应改为窄线传播 | 集中攻击成排敌人，放弃环身覆盖；明确哪些反应可改写 |

构筑应具备起步、成形、深化三个阶段。一件关键组件给出新做法，两件使循环更稳定，第三件提供取舍或新场景。避免三件齐全前所有组件都失效；已有依赖型饰符需要通过候选提示和供给规则处理。

派生伤害、反射、击退与控制必须有触发上限。任何组合都要检查：能否无限回能、无限控Boss、递归生成反应、靠换装刷新收益，或靠高频小伤害绕过原有次数限制。

## 10. 普通敌人与遭遇：把已有十二类组织成不同问题

### 10.1 先明确每个敌人的教学作用

| 现有敌人 | 希望玩家学会的判断 | 推荐的组合用途 |
| --- | --- | --- |
| chaser | 控制接敌距离与普攻节奏 | 提供可处理的前排数量 |
| crawler | 看脚边与低位路径 | 与高位威胁形成上下观察 |
| runner | 看前摇，避开已承诺的冲刺线 | 迫使玩家离开固定炮台位置 |
| duelist | 诱招后利用恢复 | 检验贪刀与近距离节奏 |
| brute | 绕背、破盾或暂时绕行 | 形成正面战线与后排保护 |
| caster | 处理远程射线与优先级 | 推动玩家换层或接近后排 |
| binder | 提前离开控制区域 | 与少量近战组合，避免多重失控 |
| leaper | 识别落点与落地窗口 | 让平台停留有风险 |
| glider | 管理头顶与斜向接近 | 让对空工具有明确用途 |
| burrower | 观察地面预兆并保留撤离路线 | 打破单向清怪习惯 |
| splitter | 计划击杀顺序和落点 | 让范围能力与资源安排有价值 |
| warden | 识别支援来源并决定是否突破前排 | 制造有限目标优先级压力 |

这是职责分析，不意味着这些敌人缺乏现有行为。新增敌人必须提出表中没有的主要问题；换色、加血、增加攻击段数不足以证明必要性。

### 10.2 用遭遇模板组织压力

| 遭遇模板 | 组成和空间 | 玩家可采用的不同办法 |
| --- | --- | --- |
| 盾后灯火 | brute＋caster，保留上下通路 | 绕背、登高点杀、破甲突破或先退开拉散 |
| 上下交错 | crawler＋glider，宽地面与一座低台 | 先对空争取地面空间，或先清地面再跳 |
| 追击与落点 | runner＋leaper，错开起手 | 引冲刺后变向，或提前离开预计落点 |
| 支援结阵 | warden＋少量基础前排 | 突破支援，或利用远程与平台解决前排阻挡 |
| 分裂回收 | splitter＋有限远程威胁 | 控制击杀位置，留范围技能处理分裂体 |

同一模板在平地、窄桥和双层平台上会有不同压力。导演应逐渐考虑“这个场地还能留下哪些安全移动”，并建立不允许组合及起手错峰规则。数量预算只能限制规模，不能单独保证可解。

首次出现的机制先低压展示，再加入一个搭档，最后用于混合考验。随机化在已经验证可解的模板内变化，且不能依据玩家刚选的装备偷偷生成专门克制它的组合。

### 10.3 新敌人作为候选库

鸣潮铳鬼的慢弹可被击回，提供“留敌利用”；执索钓尸的钩索可以误抓同伴，提供“诱导位移”；负碑鬼能暂时承载玩家，提供“借敌换层”。这些分别涉及弹体归属、牵引与移动承载，成本依次提高。它们可以丰富某些遭遇，但不承担整份指南的全部方向。

精英优先保留熟悉本体，再增加一种可读空间规则。每种精英能力都要审核能搭配哪些敌人，避免护盾、封路、追踪和高速接近叠加成无解场面。

## 11. Boss：让每一只考一种主能力，蚀醒改变一道题

| Boss | 当前机制基础 | 建议突出的核心考验 | 蚀醒设计评审重点 |
| --- | --- | --- | --- |
| 蛛弦 | 追猎、蛛网与召唤 | 在追击中辨认通路，利用停手窗口 | 柱阵改变路线选择，保留可识别通道 |
| 雾骨 | 薄雾、骨刺、锁向追击 | 先记危险位置，再移动进入恢复窗口 | 遮蔽保留预警；记忆题与即时闪避题不能完全重叠 |
| 镜魇 | 镜影、反射与真身突进 | 判断真身、控制出招时机 | 真假变化仍有可靠信号，不把猜测当技巧 |
| 牙岚 | 高速冲刺和连击 | 观察连段是否结束，决定何时追击 | 增加连续决策，同时明确最终收招 |
| 灯烬 | 召唤、火线与灰烬压力 | 在支援目标、地面安全区和本体间分配注意 | 移动火线需留下可抵达安全区，召唤预算服务主考题 |
| 枯铃 | 单双节拍、停拍与反震 | 识别何时应停止攻击，再完整兑现反击 | 双调增加判断，不靠更多视觉噪音制造难度 |
| 万相血月 | 五相接力与借招 | 调用已学规则，维持长战资源规划 | 避免多个主危险源同时要求互斥动作 |

主线Boss每个阶段至少应回答：危险信号是什么；玩家能用什么基础动作避开；什么时候能安全进攻；失败后能学到什么。技能与装备可以缩短解题过程或创造新窗口，但不应成为唯一通关钥匙。

设计恢复窗口时，不只看持续时间，还要看玩家躲完后是否来得及走回攻击距离。长时间等待无敌阶段会压低主动性；可以提供换位、清理场地或准备技能的事情，但不要强迫所有玩家不停做杂务。

已有Boss优先完善这些考题。多部位夜舟、可破坏场地、追逐型首领可作为未来扩展候选，先评估相机、移动平台、角色可达性与素材成本，再决定是否替换某段现有内容。

## 12. 地图、事件与十三幕节奏

### 12.1 一幕内部要有不同作用的片段

建议的一幕结构是：进入与看清环境→低压展示→组合压力→可选路线／事件→整理资源→Boss考验→奖励与喘息。无需每幕机械重复全部步骤，关键是同类高压片段之间有变化。

现有导演已有喘息、低血处理、Boss前奏和时间兜底。新增事件必须进入同一时间与压力预算，不能因为玩家选择探索就继续叠加完整敌潮。Boss门槛中的波次数是投放推进，不应在指南中误写成“必须清光每波”。

### 12.2 让高低路线对不同构筑有价值

高台可以获得射线优势，也可能被对空敌人逼离；地面有更直接的近战与拾取路径，但更容易被冲刺封线。宝藏负责诱因，战术位置负责持续价值。主路线应由基础跳跃可达，二段跳与位移提供捷径或额外余地。

两条发展办法需要区分：同屏上下分路可沿用当前片段结构；选择不同区域与Boss的大分支会牵动整个流程。推荐先把第一种做成丰富的设计库，第二种保留为未来独立决策。

### 12.3 六类事件候选

| 事件 | 玩家在做什么选择 | 获得的变化 | 成本判断 |
| --- | --- | --- | --- |
| 月下试刀 | 接受一次额外危险组合，或走安全路线 | 选择特定剑式的精进方向 | 中，主要依赖遭遇与奖励 |
| 失灯旅人 | 在敌潮中保护一段可见路径，或先保障自己 | 本局后续一次补给／路线情报 | 中，需要可靠的事件退出与失败结果 |
| 斩旗改道 | 根据构筑选下一幕的敌群与奖励倾向 | 玩家主动影响路线 | 中，需保留教学顺序和敌群多样性 |
| 夺妖灯 | 冒险接近装置取得一次术式，或拆毁换补给 | 下一战获得一次临时战术工具 | 中高，携带、使用和清理规则要完整 |
| 潮退隐径 | 在短暂打开的下层路径取物，或保持高位安全 | 强调发现与时间判断 | 中高，必须验证基础可达性和返回路线 |
| 无舵夜舟 | 登上移动战场，选择拆部件或保留可利用器械 | 一段大型场景高潮 | 高，暂作愿景，不默认加入主线 |

事件奖励优先使用现有技能、装备、残灵和临时战术效果。暂不增加金币、锻造石、好感度等多套资源。失败应有清晰且有限的代价，避免一次未读懂的事件直接毁掉整局。

### 12.4 十三幕承担不同的学习阶段

| 阶段 | 体验目标 | 内容安排原则 |
| --- | --- | --- |
| 1—3幕 | 会操作，形成第一种偏好 | 新机制逐项展示；让一次关键选择尽早改变玩法 |
| 4—6幕 | 构筑成形，学会调整 | 给予相近价值的路线和转型机会；组合考题逐步增加 |
| 7—9幕 | 熟悉规则出现新变化 | 蚀醒重组已学能力，避免全靠更快更多 |
| 10—12幕 | 识别短板并管理资源 | 保留补足缺口的选择，考验长战与风险判断 |
| 13幕 | 运用这一局形成的能力完成终点 | 规则综合、清楚阶段、明确胜利反馈 |

现有18—22分钟是完整通关的设计目标。是否容纳13次Boss与全部奖励停顿，需要先记录真实时长。若学习和停顿明显拥挤，应先调整每段密度、奖励频率和喘息，再讨论幕数；不能凭文件中的目标时长断言节奏已经合适。

## 13. 成长、奖励与资源：让计划和随机同时存在

### 13.1 奖励应帮助玩家做三种决定

深化当前打法、补足当前短板、尝试另一条路线。现有技能抽取已保留精进与发现，装备候选已有槽位与升品处理；后续重点是它们能否把相关奖励送到玩家能使用的阶段。

可比较三种干预随机的方法：一次有限重选、路线预告奖励类别、带明确代价的定向精进。推荐优先路线预告与更清楚的组合说明，再验证是否仍需要重选。若增加重选，额度在本局内取得或提供固定平等额度，不能依靠永久刷取获得优势。

关键组件获取前不要大量投放只对它生效的附属物。候选不足时允许较少选项或有用补给，不能用失效卡填满三张。转型应显示将失去的规则，已有库存与暂停换装能力可以继续服务试验新组合。

### 13.2 区分四种资源的职责

| 资源 | 职责 | 需要警惕的循环 |
| --- | --- | --- |
| 生命 | 承担错误与冒险成本 | 治疗过量使读招失去意义；过少则阻止尝试 |
| 残灵 | 把击杀与接触拾取转换为稍后治疗 | 满仓后所有选择无意义；某种敌群导致供给骤降 |
| 技能能量 | 决定使用强工具的时机与组合长度 | 困境中永远无法恢复，或某种反应无限回能 |
| 大招能量 | 积累一次明确高潮 | 总是囤到死，或长期保持强化状态 |

引灵当前是可与移动并行的延时治疗。若要改成减速、站定或受击打断，应作为单独方案比较，不能为了模仿其他游戏直接改变；它会影响所有敌群、移动端操作与低血体验。

评估Boss单体场景中的能量获取是否支持所有合理构筑。若确有资源断流，可比较稳定普攻供给、特定装备回能、阶段恢复窗口等办法，明确代价与上限；不能只靠持续召小怪来给所有Boss补资源。

### 13.3 减少无意义的奖励停顿

记录升级、Boss装备、灵匣、暂停换装各占多少时间。相邻待领奖励可以保持清楚顺序与连续展示；只有内容允许时才讨论合并，不能让玩家同时判断多套系统。玩家看完卡面应知道“选择后下一场准备怎样打”。

## 14. 重玩、横向解锁与失败反馈

重玩应至少提供三种动机：想把已学动作做得更好；想试另一个组合；想看到另一种遭遇或挑战。

| 候选功能 | 价值 | 与单局定位的关系 |
| --- | --- | --- |
| 已见Boss／敌人练习 | 缩短从失败到理解的距离 | 练习不发主线资源、不推进主线成绩 |
| 构筑与规则图鉴 | 告诉玩家已有组件怎样配合、缺什么前置 | 记录知识，战力仍从每局基础开始 |
| 简短死亡复盘 | 显示主要伤害来源、当时危险与一条建议 | 依据实际事件，避免凭标签猜死因 |
| 本局回顾 | 展示关键选择、用得最多的动作与到达阶段 | 帮助玩家理解自己的打法，不把统计堆满屏 |
| 横向角色／技法解锁 | 新的操作身份与实验方向 | 必须保持同等起点；解锁顺序不能暗含越来越强 |
| 血月试炼 | 主动组合行为、空间或资源限制 | 现有后续规划的深化，逐项可读且可组合验证 |
| 固定种子挑战 | 比较同样机会下的路线与构筑选择 | 先做本地重试，不需要在线经济或排行榜系统 |

永久解锁新装备可能稀释掉落池，也可能提供更强组合，即使没有直接加属性也会影响战力。若采用内容解锁，应提供合理的候选池控制或等强替代，并单独评价新玩家与全解锁玩家的体验。

叙事可使用本局沿途短句、旅人反应、Boss再遇变化和妖闻。持久叙事是否表示主角记得死亡，需要世界设定先确定；不自动照搬哈迪斯的重生逻辑，也不扩展为复杂对话树。

## 15. 视觉、声音、教学与触屏体验

视觉优先级建议是：即将造成伤害的信号、玩家与可落脚处、重要状态与交互、命中效果、环境装饰。敌人的身体动作与危险范围要相互解释，特殊机制同时使用形状和动作，避免只靠颜色。

每种新规则采用“看见一次→安全尝试→获得反馈→遇到组合”的教学过程。界面提供短说明，世界提供可观察的结果。图鉴负责完整规则，奖励卡面只讲本次改变和代价。

触屏需要独立验证：切技能再施放是否容易误触；反应型操作是否必须同时按太多按钮；手指是否遮挡落点；长按与二段操作是否清楚。候选改招优先使用已有按键和明确动作状态，禁止把桌面键位组合直接当成移动端已可用。

音效要区分起手、命中、破盾与危险升级。BGM可按探索、常规战、Boss与奖励时刻改变强度，沿用[原创音乐方向](../music-direction.md)，让声音帮助理解段落。音效密集时保留危险提示，避免所有反馈都提高音量。

辅助设置可以包括震动／闪屏强度、粒子密度、轮廓、危险提示音量和独立难度选项。辅助与挑战规则分别说明；不把降低视觉负担视为降低技巧要求。

## 16. 一局示例：这些系统怎样一起工作

以下是未来目标体验示例，使用已有系统加少量候选设计，不表示当前游戏已经如此运行。

开局，玩家用潮龙处理远处敌人、用弦月清理近身，学会在敌人出手后接近。第一次成长选择回刃，便开始把刀留在敌群另一侧，再跳上低台收回。一次装备奖励出现流水刃，玩家决定用回刃铺标、潮龙兑现。

进入中段，盾后灯火遭遇让正面射线受阻。玩家可以用回刃绕背，也可以走高台点杀施法者。这时灵匣提供补足生存与强化传播两种选择：残灵充足的玩家可能选连珠符，生命偏低的玩家可能先求稳。

下一处斩旗事件预告两类敌群。偏穿排的构筑选择较集中的追猎路线，准备利用连杀；另一局的空中打法可能愿意走对空压力更高但回报不同的路线。路径适配提供倾向，不应给某套构筑绝对安全的答案。

到了单体Boss，传印收益减少，回刃的往返与站位仍有价值。玩家认识到自己需要单体工具，于是在后续奖励中补破甲，或继续依靠熟练操作换取更强清群能力。死亡时，复盘指出主要失误是连段未结束就追击；练习允许他直接观察该Boss的收招信号。

同一条主线因此同时包含动作学习、构筑形成、路线判断、短板处理与下一局目标。新敌人和特殊场景负责提供更多变化，不需要每一场都加入新机制。

## 17. 怎样判断优化是否有效

首先建立当前版本基线，再比较候选方案。新手、熟练者、键盘和触屏分开记录；小样本用于发现问题，不能声称证明留存或全体平衡。

| 目标 | 观察与记录 | 失败信号 |
| --- | --- | --- |
| 操作可靠 | 输入到动作的响应、被拒绝输入的原因、失误录像 | 玩家无法解释为何按键没发生动作 |
| 构筑有身份 | 相同遭遇中的站位、目标顺序、施法顺序和资源习惯 | 换装备后操作几乎完全相同 |
| 奖励有选择 | 选择理由、转型次数、关键组件首次出现与成形阶段 | 固定选最高品质，或多数奖励无法使用 |
| 敌群可解 | 首次机制理解、受伤来源、可行撤离路径 | 必须依赖某个随机技能才能避开伤害 |
| Boss可学习 | 多次尝试中某类错误是否减少，恢复窗口是否可利用 | 失败被理解为随机，或只能靠更高属性跨过 |
| 路线有意义 | 不同构筑的路线选择、放弃原因、实际风险回报 | 任意构筑永远选择同一路线 |
| 节奏有起伏 | 实际战斗、等待、选奖励、恢复、Boss占时 | 长期满压、长时间无事可做或频繁打断 |
| 重开有目标 | 玩家能否说出下一局想尝试或改正的事情 | 只有“再刷一次看看运气” |

使用率、通关率和伤害数据需要一起解释：低使用率可能来自难获得、难理解、适用场景少；高胜率可能来自只有熟练玩家会选择。不要只按排行榜砍掉有趣构筑。

需要验证的边界包括：无限连锁与回能、永久控制、同屏危险冲突、基础路线可达性、临时物件在Boss出场／暂停／死亡／重开时的生命周期、装备替换后旧效果归属。自动化能证明规则，手感与理解仍靠人工观察。

## 18. 优先级、依赖与成本

下面是研究与设计完善顺序，表示依赖关系，不是立即开工排期。

| 层级 | 先完成的设计工作 | 为什么在这里 | 成本方向 |
| --- | --- | --- | --- |
| 基础共识 | 统一现状、定义目标体验、明确输入与生存规则、记录当前基线 | 后续内容要建立在同一种游戏判断上 | 低至中，主要是核查与设计 |
| 现有系统深化 | 九技能职责、装备规则说明、候选供给、敌群模板、Boss核心考题 | 能直接判断已有内容是否被充分利用 | 中，主要是规则、编排、界面与反馈 |
| 单局变化 | 路线回报、有限事件、技能分支、复盘与练习设计 | 让一局及多次重开形成完整链条 | 中至高，取决于新增交互 |
| 内容扩展 | 新角色动作体系、新敌人、新场景和大型遭遇 | 在明确缺口后补内容，避免重复职责 | 高，素材、动画、音效与平衡共同增长 |
| 长期挑战 | 横向解锁、血月试炼、固定种子与额外模式 | 依赖正常主线已经能被理解和掌握 | 中至高，需防止难度与成长互相混淆 |

成本判断是相对等级，未进行工程排期。完整角色、多部位Boss、可承载玩家的敌人、大分支世界，成本都显著高于奖励说明或已有敌人的新组合。

## 19. 需要守住的取舍与后续讨论点

| 取舍 | 当前推荐 | 何种证据会让建议改变 |
| --- | --- | --- |
| 单角色战法或多角色 | 先写清操作身份，再决定表现形式 | 独立角色的身份与情感收益足以覆盖素材成本 |
| 基础闪避或技能防守 | 先维持走位／跳跃／配招防守结构 | 合理构筑反复因缺少基础脱困而产生不可解局面 |
| 更多技能或现有改招 | 先完善九招的不同职责和少量分支 | 出现明确且现有工具无法表达的战术需求 |
| 全新经济或现有资源 | 先使用装备、技能、残灵和临时效果 | 新资源拥有独立且必要的选择作用 |
| 13幕或更短流程 | 暂以现有13幕为研究基线 | 实测学习负担、疲劳和奖励停顿无法通过密度调整解决 |
| 主线事件或大型分支 | 优先有限事件与同屏路线 | 探索成为主要目标，愿意重新设计关卡结构 |
| 横向解锁或全部开放 | 对新手学习与公平起点分别评估 | 解锁稀释掉落或隐性提高战力，需调整内容池 |

后续讨论应先确定目标体验与这些取舍，再从候选库挑内容。每项被采纳的设计都需要写清玩家的新决定、完整操作循环、适用场景、代价、反馈和验收方式。本指南提供整体方向与可比较方案，具体数值、角色数量和制作清单留待设计评审后确定。
