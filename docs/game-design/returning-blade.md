# 回刃·归潮：留刃牵线

> 实现状态：已接入源码；自动化验证覆盖输入、路线、命中和资源规则。尚未进行实机试玩，数值为首轮实现值。

## 玩家体验与方向选择

核心体验是把刀留在敌人身后，再通过换位拉出回斩路线。玩家需要决定何处投刀、何时结束等待，以及收刀前站在哪里。

比较过接刃连投与留刃牵线：前者强调精准接刀节奏，后者利用横版高度、平台和敌群路线。本轮选择后者，保留点按二段输入，不增加接刀按键或固定连招。

## 状态与输入

| 阶段 | 行为 | 玩家可作的决定 |
| --- | --- | --- |
| 投刃 | 18 帧施法释放；向面朝方向飞至距释放中心 176px 处，边缘限制在画布内 | 选择朝向与释放高度 |
| 留刃 | 在落点悬停，Lv1 120 帧，Lv2/Lv3 150 帧；不造成伤害 | 换位、跳跃、普攻、切换技能或提前收刀 |
| 收束 | 再次点按当前技能，锁定当时玩家中心，原地收束 6 帧 | 可以继续移动，但锁定路线不再改变 |
| 归刃 | 以 12px/帧沿锁定直线回到该点并消散 | 玩家无需留在终点接刀 |

- 去程速度为 8px/帧；去程期间也可主动收回，但不取消尚未完成的角色施法动作。
- 首次施放支付当前技能费用，默认 30；收回不扣能量，不重复触发施法装备效果。
- 同场最多一把刀；收束和归刃期间再次按键不会生成第二把或重置路线。
- 留刃最后 30 帧逐渐收紧并给出一次短提示，耗尽后自动锁定玩家当前位置回收。
- 切换当前技能不取消留刃；切回回刃后可操作。暂停、奖励和终式定格沿用玩法冻结，不推进留刃计时。
- `K` 按下边沿触发，长按重复事件不会自动收刀。触控技能按钮采用相同二段点按规则。
- 桌面当前技能框与触控技能按钮显示“收回 / 归刃”；阶段由运行时快照投影，不另维护 UI 倒计时。
- 手动收刀算一次主动攻击指令，递增攻击起手序号；自动回收不递增。二段不重新发布普通技能首次释放事件。
- 玩家死亡后不再结算此刀伤害或显示路线；重开清空刀、潮痕和交叉斩。

## 伤害与成长

| 参数 | Lv1 | Lv2 | Lv3 |
| --- | ---: | ---: | ---: |
| 小怪完整往返伤害 / 当前攻击 | 2.4 | 2.7 | 3.0 |
| Boss 完整往返伤害 / 当前攻击 | 1.6 | 1.8 | 2.0 |
| 留刃时间 | 2 秒 | 2.5 秒 | 2.5 秒 |
| 去程 / 归刃分配 | 30% / 70% | 30% / 70% | 30% / 70% |
| 双中合痕追加 / 本招完整往返基础伤害 | 无 | 无 | 35% |

最终伤害仍消费统一攻击加成、装备、裂甲等结算；以上为技能自身倍率，不代表最终实战伤害。

每个目标去程、归程各最多命中一次，普通敌人不再采用每段 2/3/4 个目标上限，Boss 也不因体型大反复受击。伤害通过连续扫掠检测覆盖移动路径，斜线包围矩形的空角不造成伤害。

Lv3 去程有效命中留下潮痕；归刃命中同一目标时，在该次伤害中追加合痕伤害，并播放独立纯视觉交叉斩。存活的非精英、非盾兵普通敌人动作与接触伤害暂停 12 帧；重型、精英和 Boss 只受伤害。合痕不传播标记、不生成新刀、不产生独立返能。

盾牌依据刀的实际来向判定：刀从背面返回可以伤及本体；盾兵若已转向归刃，盾依然有效。技能不赋予无条件穿盾，也不触发潮龙装备被动的随机击退，以保持路线与目标位置可预测。

Lv2 的长按微调保留为后续可选探索，本轮采用已选定的延长悬停方案，不增加按住/松开语义。

## 配合与弱点

- 回涡：把敌群聚到预览潮线上，再决定是否立即回收。
- 平台：空中投刃、落地收刀能形成斜向攻击；反过来可以从地面刀位收向高处。
- 盾兵：把刀送到背后，观察其朝向再收回。
- Boss：等待其穿入路线或结束位移再收刀；收益不依赖击杀小怪。

准备时间、错误高度和目标离开路线都会导致损失。该技能不提供无敌、护盾、玩家拉拽或持续悬停伤害；被贴身围困时仍应考虑其他解围技能。
