## Skill Content

完整角色技能设定见 [player-skills.md](player-skills.md)。本节只保留内容扩展优先级摘要。

当前三招和大招已经满足第一版战斗闭环；目标形态下，大招从一次性范围爆发改为限时强化状态。普通技能继续走技能池配置，大招期间只允许附加更亮的月潮边缘表现，不改写每个普通技能的核心定位。

| 技能 | 当前定位 | 后续设计需求 |
| --- | --- | --- |
| 水龙破 | 前方飞行水龙，路径伤害 | 进入 `SKILL_DEFS`，支持 Lv1-Lv3 技能等级读取伤害和路径成长；大招期间仍保持直线处理 |
| 打潮刃 | 前方水流剑气，短距离高覆盖 | 进入 `SKILL_DEFS`，明确命中框和 Lv1-Lv3 覆盖成长；大招期间仍保持贴身覆盖定位 |
| 静水返 | 防护水幕，受击反击 | 明确 Lv1-Lv3 抵挡次数、反击目标、与 Boss 技能交互；大招期间仍保持防反容错定位 |
| 终式·月潮无间 | 限时强化状态，提升移动、跳跃、普攻节奏和伤害；普攻生成短促残影水刃 | 替换旧的瞬时范围爆发定位；读取 `ultimateLevel` 决定持续时间、移动、跳跃、攻速、伤害和残影追加伤害 |

普通技能池后续可以继续扩展直线、扇形、防反、位移、控场和破甲方向，但不要因为大招重做而把所有技能同质化。先把现有三招配置化，避免 XP、装备、普通技能等级和大招等级接入时把倍率写散。

后续六个普通技能方向：位移追击、短时控场、单体破甲、对空多段、往返路线控制、纵向浪击。它们进入候选池前必须先有正式素材、HUD 图标、命中形状和升级边界。

普通技能等级规则：每个已解锁普通技能每局从 Lv1 开始，最高 Lv3；升级三选一可以提供指定技能的“技能精进”奖励，已达 Lv3 的技能不再进入候选。

终式目标规则：

- 释放满能量大招后进入短时间爆发状态，不再依赖单帧大范围伤害清屏。
- `ultimateLevel` 上限为 `3`，由局内升级三选一的“大招强化”奖励提升，死亡或重开后清空。
- Lv1 是基础月潮状态，获得小幅移动、跳跃、攻速和伤害提升。
- Lv2 增加持续时间，残影水刃更稳定，移动和跳跃提升更明显。
- Lv3 是终阶爆发，残影斩命中反馈和追加伤害更强，但仍保留有限持续时间。
- 大招期间不是无敌状态；最多只给短暂开启动作抗打断或减伤。
- 强化重点放在追击和普攻爆发窗口，残影不能长期遮挡 Boss 前摇、敌人读招或地面危险区。

## Music and Audio Content

音乐方向已经有完整 prompt，但 runtime 当前只有简单 tone SFX。接入顺序建议：

1. Start Screen、Act 1、Spider String 三首先验证音色。
2. 补 Boss intro sting、victory（终幕通关）、game over、low health warning。
3. 再生成 intro 段（1-6 幕）其余 Boss 主题，然后是 awakened 段（7-12 幕）觉醒变奏与终幕万相血月主题。
4. 觉醒段建议复用基础幕主题的变奏（变速 / 加层 / 调式变化），呼应「觉醒形态复用基础精灵」的成本策略。
5. 所有 BGM 导入前先确认 loop seam，无爆音和断点。

音频实现前不要把 prompt 文档当作已接入素材。

## First Buildable Milestone

最小可交付目标不是一次性做完所有内容，而是先完成“Boss 击杀推进第 2 幕”的闭环：

1. 当前 Boss 击杀统一入口。
2. 增加 `bossKills` 和 `act` helper。
3. 平台、敌人和 Boss 重生读取 `act`，但先不接新素材。
4. HUD 显示当前幕。
5. 击败 `蛛弦` 后进入第 2 幕，敌人权重和平台权重发生可感知变化。

这个里程碑通过后，再接 XP 和装备 overlay。
