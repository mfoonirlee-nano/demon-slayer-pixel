# 装备与技能组合

> 实现状态：规则、命中接线与选择预览已接入；全量 162 个测试文件、1,199 项测试通过，类型检查与 lint 通过。未启动游戏试玩，手感与收益平衡仍需人工验证。

## 玩家要做的决定

构筑的价值来自同一招在不同装备下承担不同职责。玩家在三技能槽、刃器、衣装、饰符的限制内，决定谁负责铺标、谁负责兑现、怎样把目标留在爆发范围里，以及为了资源循环放弃哪种伤害形态。

原来的通用「两种技能命中后，普攻／落击领奖」不承担本轮目标：所有构筑都得到同一套后续动作，装备选择没有改变衔接规则。本轮将反应放回具体装备与技能命中之间。

## 方向取舍

比较过两种方案：

1. **逐招专属进化**：每件装备分别改写九招的弹道、动作和段数。单招身份强，但容易形成一张固定配方表；新增技能时要再补整套专属规则。
2. **共享目标状态与反应**：装备提供潮印、控制衔接、潮眼、传印和形态改写，技能利用已有的弹道、移动、聚怪、破甲与往返轨迹产生不同结果。

选择第二种。玩家可以先发现一条可复用的规则，再把它放到另一招上尝试。具体改变落在世界位置和目标状态上，保留技能自身的战斗问题。

## 六件装备的新增组合职责

这些规则从普通品质就可用；原有主属性、品质机制和同系套装仍然保留。品质数值来源见 [装备系统](../numeric-system/equipment.md)，反应参数唯一来源为 [equipmentReactions.ts](../../src/constants/equipmentReactions.ts)。

| 装备 | 新增规则 | 操作与限制 |
| --- | --- | --- |
| 流水刃 | 技能有效命中留下潮印；不同技能命中消耗潮印，沿玩家当前朝向扫潮 | 同招不刷新、不兑现自己的标记；每次施法最多一次反应。站位与转身决定扫潮方向 |
| 破月刃 | 技能命中受控或破甲目标，留下延迟范围爆裂 | 回涡、升浪命中普通敌人当次即可触发；Boss 通过破甲触发，不会被普通控制锁住 |
| 踏影衣 | 移动蓄势后，下次技能命中留下短暂牵引潮眼 | 潮眼自身不造成伤害。要用下一招利用聚拢与控制窗口 |
| 涟波衣 | 延长潮印与控制衔接窗口；成功反应后短暂减伤 | 控制衔接窗口是破势资格，不延长 Boss 硬控。与踏影衣同槽，不能同时装备 |
| 连珠符 | 有潮印的目标死亡时，将原技能标记传给附近两个未标记目标 | 需要流水刃提供标记；保留原标记来源与剩余时间，不无限续标 |
| 鸣拍符 | 将流水刃的定向扫潮改为定点聚潮，吞并聚潮范围内的其他标记 | 需要流水刃；放弃向前穿排，换取就地聚拢与集中爆发。与连珠符同槽 |

普通伤害、被动月牙、装备反应本身不会新建技能来源，也不会递归触发第二轮伤害反应。带标记目标被普攻、反应或敌方伤害击败时，仍可结算传印；这只迁移已有标记。踏影蓄势统计角色实际横向行动，排除移动平台被动运载距离。

## 可成形的构筑

### 聚潮控场

**流水刃 + 鸣拍符 + 回涡／雨线／潮龙**。先用覆盖多目标的技能铺标，再用另一招在敌群中兑现。鸣拍符把一次朝前扫潮变成原地聚潮，吸收范围内标记；留在原位输出更容易，追逐远处敌列的收益降低。第三槽选择涟波衣可以扩大衔接容错，选择踏影衣则需要先移动准备潮眼。

### 移位破势

**破月刃 + 踏影衣 + 潮闪／回涡／破甲**。移动准备潮眼，把敌人聚到定点范围里；普通敌人可由回涡、升浪或潮眼提供控制资格，再承接破势延迟爆裂。Boss 不吃这类控制，破甲是明确的转换手段。爆裂位置固定，目标离开便会落空，因此需要把移动、控制与爆发连起来。

### 连杀传印

**流水刃 + 连珠符 + 回刃／潮龙／月弧**。沿回刃去回路径或直线弹道铺标，让普攻或其他伤害击败带标记目标，再用另一招收取附近传出的标记。传印保留原招式身份与剩余时长，因此玩家还要判断该切哪一招、先击败谁。选择连珠符会放弃鸣拍符的聚潮形态。

### 稳态衔接

**流水刃或破月刃 + 涟波衣**。延长铺垫窗口，反应后提供短暂掩护，让玩家能承受贴近敌群的兑现动作。它与踏影衣竞争同一槽位：选择更宽的衔接时间，或选择主动移动形成聚敌落点。

## 九招怎样提供不同组合条件

| 技能类别 | 原有行为在组合中的作用 |
| --- | --- |
| 潮龙、雨线 | 沿线或多束覆盖不同目标，铺开潮印；每次施法的反应上限避免多束无限爆发 |
| 月弧、护返 | 近身范围或反击命中负责兑现，要求玩家进入合适位置与时机 |
| 潮闪 | 穿过敌列铺标，同时为移动类装备创造位移；转身可以改变下一次扫潮方向 |
| 回涡、升浪 | 普通敌人的控制直接提供破势资格；聚拢影响后续范围爆裂的命中数量 |
| 破甲 | 对普通敌人与 Boss 都能提供破势资格，当次与后续技能都可利用破甲窗口 |
| 回刃 | 去程、留刃与锁线回收允许玩家在铺标后换位，再选择另一招兑现 |

全九招都通过有效技能命中参与同一规则。回刃的往返、雨线的多束、潮闪的沿途与收刀仍属于各自同一次施法，不靠拆分实体绕过上限。

## 反馈与发现

- 世界内显示目标潮印、控制／潮眼与定点反应区域；扫潮和聚潮沿用本项目已有序列帧资源，按新规则的位置和时序播放，本轮不把复用资源称作新生成素材。
- 装备奖励说明选择后**获得什么、失去什么、缺少什么依赖**。鸣拍符明确显示聚潮取代扫潮；缺少流水刃时不能显示为已激活。
- 暂停装备详情展示当前组合或换装预览；未获得的装备明确写“获得并装备后”。
- 暂停技能详情和技能奖励显示当前装备如何影响这一招。未装入技能槽的技能写“习得并装备此招后”，不声称选中升级就立即激活。
- 详情允许滚动，保留完整品质机制和套装说明；短卡面只显示简洁摘要。

## 验收与边界

自动化已覆盖九招真实伤害入口、同招不转换、异招转换、每次施法上限、标记过期、反应不递归、位置固定、控制与 Boss 破甲路径、传印来源／剩余时间、鸣拍形态替换、换装清理、死亡和重开清理；计时和实体接在既有玩法冻结分支内。移动平台不蓄势、图集峰值与判定对齐也有回归覆盖。
