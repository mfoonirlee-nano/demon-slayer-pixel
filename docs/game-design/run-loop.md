# 核心循环与单局节奏

> 实现状态：设计文档。当前运行时仍主要按时间推进难度；Boss 击杀驱动幕数属于目标设计。

## Core Loop

当前循环：

1. 从开始界面进入单局。
2. 玩家通过移动、跳跃、普攻和技能处理普通敌人与平台路线。
3. 击杀普通敌人获得分数、技能能量和大招能量。
4. 平台片段持续滚动，奖励以水晶和宝箱形式出现。
5. Boss 按计时器出场；Boss 在场时常规刷怪暂停，但 Boss 可召唤小怪。
6. 击杀 Boss 获得分数、技能能量和大招能量，之后等待下一次 Boss 计时。
7. 玩家生命归零后进入死亡界面，按 `R` 重开。

目标循环：

1. 击杀敌人获得分数、技能能量、大招能量和 XP。
2. 移动路线与平台片段迫使玩家持续调整站位。
3. XP 满后弹出升级三选一，提供小幅稳定成长。
4. Boss 出场形成阶段压力和明确击杀目标。
5. 击杀 Boss 触发装备三选一，并推进 `bossKills`。
6. `act = bossKills + 1`，下一幕改变敌人池、Boss 池、平台权重和奖励上限。
7. 第 4 幕后进入综合轮换；第 5 幕可接终盘 Boss 或无限挑战。

## Run Flow

| 阶段 | 当前实现 | 目标设计 |
| --- | --- | --- |
| 开始界面 | 已实现封面、加载状态、任意键/点击开始、本地击杀视觉进度 | 增加明确模式入口和首次教学提示，但不做复杂菜单 |
| 开局 0-30s | 普通敌人和平台按时间成长，首 Boss 通常约 28s 出场 | 第 1 幕教学压力，首 Boss 目标窗口约 35-45s |
| 首 Boss | 单例 Boss `蛛弦`，阶段、弹幕、召唤和单向技能已实现 | 首 Boss 作为机制考核，击杀后推进第 2 幕 |
| 幕间奖励 | 当前 Boss 击杀只给分数与能量 | Boss 装备三选一，短暂停顿后进入下一幕 |
| 中期 | 时间继续提高敌人、平台和 Boss 数值 | 第 2 幕速度压力，第 3 幕空间压迫 |
| 后期 | 仍是单例 Boss 重复出场 | 第 4 幕+ 综合敌人池与 Boss 池轮换 |
| 失败 | 生命归零，死亡动画，显示生存时间，按 `R` 重开 | 增加死亡原因归因和一条可执行复盘提示 |

## Act Design

| 幕 | 触发 | 核心体验 | 敌人池目标 | 平台目标 | Boss 目标 |
| --- | --- | --- | --- | --- | --- |
| 第 1 幕 | `bossKills = 0` | 教学压力，熟悉横穿、低位和冲刺 | `chaser`、`crawler`、`runner` | 宽平台、安全桥、少量跳跃链 | `蛛弦` 首轮教学压力 |
| 第 2 幕 | `bossKills = 1` | 速度压力和近身窗口 | 加入 `duelist`、后续可加 `leaper` | 增加阶梯、链式平台 | Boss 召唤池加入更快敌人 |
| 第 3 幕 | `bossKills = 2` | 空间压迫、高血目标和远程牵制 | 加入 `brute`、`caster` | 增加折返、风险奖励、悬浮 | Boss 技能组合更复杂 |
| 第 4 幕+ | `bossKills >= 3` | 综合轮换与持续挑战 | 全内容池按权重轮换 | 全片段池，保留喘息片段 | Boss 池轮换并强化 |
| 第 5 幕+ | 后续扩展 | 终盘或无限挑战 | 加入后期机制敌人 | 高压片段不连续堆叠 | 可触发终幕 Boss |

## Teaching Rhythm

第一局前 60 秒要承担隐性教学：

- 先让玩家在低压下使用 `A/D`、`W/Space` 和 `J`。
- 前几个敌人应能用普攻稳定处理，避免立刻要求技能。
- 技能能量默认从空开始，玩家通过击杀理解“击杀补充资源”。
- 第一批平台以 `breather`、`safeBridge` 和简单 `stairUp/stairDown` 为主。
- 首次 Boss 入场前应避免同屏高复杂敌人与高风险平台叠加。
- 首次死亡后只提示重开和核心失败原因，不展开长教学文案。

## Failure Experience

当前死亡体验已经有死亡动画和生存时间。目标设计需要补齐死亡原因，便于玩家理解“下次该改什么”。

推荐失败原因优先级：

| 原因 | 触发口径 |
| --- | --- |
| Boss 技能命中 | 过去 5 秒内主要伤害来自 Boss 技能或弹幕 |
| 被敌潮包围 | 过去 5 秒内受到 2 个以上普通敌人伤害 |
| 平台路线失误 | 连续较长时间无法接近奖励或被平台带离安全位置 |
| 资源空窗 | 生命低于 30% 时技能能量和大招能量都不足 |
| 控场失误 | 受到 binder 区域减速后被连击或持续伤害击败 |

死亡界面第一版只需要展示一条简短复盘文案，例如“被 Boss 前摇技能命中，下一次优先保留一次技能解围”。不要在死亡界面加入复杂统计面板。

## Endgame Shape

第 4 幕后有两种可选方向，后续实现前需要二选一：

| 方向 | 优点 | 风险 |
| --- | --- | --- |
| 无限挑战 | 更符合生存游戏，可持续扩内容 | 需要更严格的后期生成池和数值上限 |
| 终盘 Boss | 单局有明确通关目标 | 需要专属 Boss、音乐、UI 和奖励闭环 |

推荐第一版采用“第 4 幕后无限挑战，第 5 幕可选终盘 Boss 条件”的混合方案：先保证无限可玩，再把终幕 Boss 作为后续内容目标。
