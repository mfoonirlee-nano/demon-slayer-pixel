# 核心循环与单局节奏

> 实现状态：设计文档。当前运行时仍主要按时间推进难度；Boss 击杀驱动幕数属于目标设计。

## Core Loop

当前循环：

1. 从开始界面进入单局。
2. 玩家通过移动、跳跃、普攻和技能处理普通敌人与平台路线。
3. 击杀普通敌人获得分数和技能能量；习得终式后才额外获得大招能量。
4. 平台片段持续滚动，奖励以水晶和宝箱形式出现。
5. Boss 按计时器出场；Boss 在场时常规刷怪暂停，但 Boss 可召唤小怪。
6. 击杀 Boss 获得分数、技能能量、装备三选一；终式只在角色升级三选一中习得，已习得后 Boss 击杀才会获得大招能量。
7. 玩家生命归零后进入死亡界面，按 `R` 重开。

目标循环：

1. 击杀敌人获得分数、技能能量、大招能量和 XP。
2. 移动路线与平台片段迫使玩家持续调整站位。
3. XP 满后弹出升级三选一，提供小幅稳定成长。
4. Boss 出场形成阶段压力和明确击杀目标。
5. 击杀 Boss 触发装备三选一，并推进 `bossKills`。
6. `act = bossKills + 1`（上限 13），下一幕改变 Boss、敌人池、平台权重和奖励上限。
7. 第 1-6 幕逐个引入 6 个基础 Boss；第 7-12 幕 1:1 出现蚀醒形态；第 13 幕进入终极 Boss 万相血月，击败即单局通关。
8. 首次通关后解锁血月试炼进阶难度层，提供横向重玩动力，不给局外永久战力。

## Run Flow

| 阶段 | 当前实现 | 目标设计 |
| --- | --- | --- |
| 开始界面 | 已实现封面、加载状态、任意键/点击开始、本地击杀视觉进度 | 增加明确模式入口和首次教学提示，但不做复杂菜单 |
| 开局 0-30s | 普通敌人和平台按时间成长，首 Boss 通常约 28s 出场 | 第 1 幕教学压力，首 Boss 目标窗口约 35-45s |
| 首 Boss | 单例 Boss `蛛弦`，阶段、召唤和单向技能已实现 | 首 Boss 作为机制考核，击杀后推进第 2 幕 |
| 幕间奖励 | 当前 Boss 击杀给分数、技能能量、装备三选一；终式由角色升级三选一习得 | Boss 装备三选一，短暂停顿后进入下一幕 |
| 中期 | 时间继续提高敌人、平台和 Boss 数值 | 第 2-6 幕逐个引入基础 Boss，敌人池在第 6 幕解锁完毕 |
| 蚀醒段 | 仍是单例 Boss 重复出场 | 第 7-12 幕 1:1 出现蚀醒 Boss，制造刻意的难度墙 |
| 终幕 | 无 | 第 13 幕万相血月，5 阶段换相借招，击败即通关 |
| 失败 | 生命归零，死亡动画，显示生存时间，按 `R` 重开 | 增加死亡原因归因和一条可执行复盘提示 |

## Act Design

幕结构是一条 13 幕有限阶梯，分三段（`actBand`）。完整的逐幕 Boss、敌人解锁、目标时长和击杀率见权威总表 [act-structure.md](act-structure.md)；这里只给分段体验目标：

| actBand | 幕 | 触发 | 核心体验 | 敌人池目标 | Boss 目标 |
| --- | --- | --- | --- | --- | --- |
| intro | 1-6 | `bossKills 0-5` | 逐幕熟悉一种新压力，6 幕内见齐 12 种敌人 | 每幕 +1~2 种，第 6 幕解锁完毕，常规池 ≤ 8 | 6 个基础 Boss 各承担一种核心机制 |
| awakened | 7-12 | `bossKills 6-11` | 蚀醒难度墙：基础 Boss 的蚀醒形态 1:1 重现 | 不引入新敌人，靠强化召唤池 + 轮换 profile 逐幕换组合 | 6 个蚀醒 Boss：+ 新月蚀术招 + 多一阶段 |
| final | 13 | `bossKills = 12` | 终盘总复习：换相借招 | 终盘限定池，额外召唤 ≤ 4 | 万相血月，5 阶段，击败即通关 |

各幕之间用 Boss 击杀推进（`act = bossKills + 1`，上限 13），不靠拖时间。蚀醒段的难度抬升主要来自 `threatScalar` 分段加速 + 蚀醒招，见 [../numeric-system/act-and-threat.md](../numeric-system/act-and-threat.md)。

## Teaching Rhythm

第一局前 60 秒要承担隐性教学：

- 先让玩家在低压下使用 `A/D`、`W/Space` 和 `J`。
- 前几个敌人应能用普攻稳定处理，避免立刻要求技能。
- 技能能量默认从空开始，玩家通过击杀理解“击杀补充资源”。
- 第一批平台以 `breather`、`safeBridge` 和简单 `stairUp/stairDown` 为主。
- 首次 Boss 入场前应避免同屏高复杂敌人与高风险平台叠加。
- 首次死亡后只提示重开和核心失败原因，不展开长教学文案。

## Failure Experience

当前死亡体验已经有死亡动画和生存时间。目标设计需要补齐死亡原因，便于玩家理解“下次该改什么”。

推荐失败原因优先级：

| 原因 | 触发口径 |
| --- | --- |
| Boss 技能命中 | 过去 5 秒内主要伤害来自 Boss 技能或弹幕 |
| 被敌潮包围 | 过去 5 秒内受到 2 个以上普通敌人伤害 |
| 平台路线失误 | 连续较长时间无法接近奖励或被平台带离安全位置 |
| 资源空窗 | 生命低于 30% 时技能能量和大招能量都不足 |
| 控场失误 | 受到 binder 区域减速后被连击或持续伤害击败 |

死亡界面第一版只需要展示一条简短复盘文案，例如“被 Boss 前摇技能命中，下一次优先保留一次技能解围”。不要在死亡界面加入复杂统计面板。

## Endgame Shape

终盘形态采用**有明确终点的 13 幕闯关 + 通关后横向进阶难度**：

- **单局终点**：第 13 幕击败万相血月即单局通关，出胜利结算。这给单局一个清晰目标，避免「后期只剩同一 Boss 重复加血」。
- **蚀醒段难度墙**：第 7-12 幕的蚀醒 Boss 是单局的主要技巧考核，让到达第 13 幕本身成为成就。
- **通关后循环**：首次通关后解锁**血月试炼进阶难度阶梯**（类 Hades 热度）——每层叠加可读的负面词条（敌人更快 / Boss 多一阶段 / 资源减少 / 蚀醒段提前 / 喘息片段减少）。进阶层只解锁新挑战，不给局外永久战力，符合「单局构筑、死亡清空」支柱。详见 [../numeric-system/endgame-ascension.md](../numeric-system/endgame-ascension.md)。

放弃原「第 4 幕后无限挑战」方向：无限轮换后期只能靠数值膨胀，与设计支柱「内容轮换而非数值膨胀」冲突；13 幕有限阶梯 + 进阶难度能在不膨胀的前提下提供长期差异化。
