# 角色技能设定

> 实现状态：当前源码已接入 9 招普通技能、技能能量、大招能量和当前版本大招；`终式·月潮无间` 开局未习得，需要通过角色升级三选一学习。

## Purpose

定义角色的基础攻击、普通技能池、大招、升级挂钩和可读性边界。当前生效数值仍以 [../numeric-system/player.md](../numeric-system/player.md) 为准；本文只描述后续要落地的玩法设定。

本文普通技能展示名统一采用 `二字意象·二字动作` 格式；`typeTag`/技能 ID 保持英文实现锚点，不参与玩家侧展示。源码或其它文档如果仍出现旧展示名，后续接入时以本文为目标命名同步。大招作为终式，继续使用 `终式·月潮无间`。

## Design Goals

- 普攻是常规处理手段，承担基础清怪、补刀和大招强化期的主要反馈。
- 普通技能承担明确战术分工：直线、贴身、防反、位移、控场、破甲、对空、路线封锁和纵向处理；差异必须体现在命中形状、前摇承诺、站位要求和失败代价上。
- 普通技能拥有独立等级：每局初始 Lv1，最高 Lv3，通过局内升级奖励提升，死亡或重开后回到 Lv1。
- 大招是限时强化状态，不再是一次性范围爆发；强化重点放在追击、跳跃和普攻残影潮刃。
- 技能效果必须读得出形状、起手、命中和消散，不能长期遮挡 Boss 前摇、敌人身体、平台边缘或地面危险区。
- 第一版保持当前 `K` 释放技能、`L` 释放大招、`1/2/3` 切换技能的输入结构；如后续扩展技能池，默认仍只装备 3 个普通技能。

## Skill System Rules

普通技能：

- 普通技能消耗技能能量，不共享大招能量。
- 当前已实现三招作为默认技能：`潮龙·破阵`、`弦月·潮刃`、`镜潮·护返`。
- 目标技能池扩展为 9 个普通技能：当前三招 + 后续六招。
- 每个已解锁普通技能都有独立 `skillLevel`，初始 `1`，上限 `3`；后续新解锁技能进入本局时也从 Lv1 开始。
- `SKILL_DEFS` 应统一保存技能 ID、展示名称、定位、解锁条件、消耗、施法前摇、命中形状、伤害模型、等级成长字段、图标和特效资源。
- 未解锁或未接入素材的技能不能出现在 HUD、升级候选或装备词条里。

大招：

- 大招不进入普通技能池，不占普通技能槽。
- `ultimateLevel = 0` 表示尚未习得终式；未习得时不会获得大招充能，也不能释放大招。
- 角色升级时，尚未习得终式则会在三选一中提供 `习得终式`；选择后 `ultimateLevel` 变为 `1`。
- 习得后，满大招能量可释放 `终式·月潮无间`，进入有限持续时间的月潮强化状态。
- 习得后的 `ultimateLevel` 可通过局内升级三选一提升，上限 `3`，死亡或重开后清空。
- 大招期间普通技能只增加月潮边缘视觉，不改变技能语义；最明显的变化集中在移动、跳跃、普攻节奏和普攻残影潮刃。

## Base Actions

| 动作 | 定位 | 目标设定 | 边界 |
| --- | --- | --- | --- |
| 普攻 | 基础处理、补刀、强化期核心输出 | 短距离潮纹斩，命中点清晰；大招期间追加短促残影潮刃 | 不做长距离自动追踪，不替代技能清场 |
| 下落攻击 | 高风险落点反击 | 空中下坠形成小范围潮涌冲击，落地有短恢复和明确命中反馈 | 不能无脑替代普攻，不能长期滞空控场 |
| 移动/跳跃 | 站位和追击 | 常态保持当前横版手感；大招期间提高移动和跳跃能力 | 大招强化不等于无敌穿越危险区 |

## Normal Skill Cast Wind-up

施法前摇用于区分“反应技”和“承诺技”，也给敌人、Boss 与玩家读招留出公平窗口。前摇按 60fps 目标描述，后续实现可微调，但不能抹平不同技能的承诺差异。

| 前摇档位 | 目标帧段 | 适用技能 | 设计含义 |
| --- | --- | --- | --- |
| 极短 | 5-9f | `弦月·潮刃`、`流步·潮闪` | 允许紧急解围或脱离，但范围、持续或后续恢复要受限 |
| 短 | 10-15f | `潮龙·破阵`、`镜潮·护返`、`升浪·托月` | 常规战斗可稳定使用，但不能抢救已经命中的伤害 |
| 中 | 16-22f | `回涡·引潮`、`断浪·裂甲`、`回刃·归潮` | 要提前判断站位或敌群路线，换取更强控制、破甲或路线收益 |
| 长 | 22-30f | `雨线·穿针` | 高收益对空或远程压制，需要更明显的起手和失败代价 |

规则：

- 前摇期间可以播放角色施法动作和起手特效，但命中框、防反窗口、无敌帧和控制效果必须等到对应动作节点后才生效。
- 反应型技能可以前摇短，但不能同时拥有长持续、全屏覆盖和低失败代价。
- 承诺型技能可以收益更高，但前摇、站位要求或恢复时间至少保留一个明确弱点。
- 大招期间可以缩短少量恢复或增加边缘视觉，不能把所有普通技能压成同一个即时爆发节奏。

## Normal Skill Levels

普通技能等级是单局内成长，不是局外养成。每个技能独立记录等级，默认三招每局从 Lv1 开始；后续六招如果通过幕数、奖励或装备解锁，也从 Lv1 开始。

| 等级 | 定位 | 成长方向 |
| --- | --- | --- |
| Lv1 | 基础形态 | 技能拥有完整功能，满足该技能的核心定位 |
| Lv2 | 稳定强化 | 小幅提高伤害、命中反馈或关键效果稳定性 |
| Lv3 | 专精形态 | 强化该技能最核心的战术价值，但不改变技能类型 |

等级成长字段按技能类型选择，不要求所有技能都用同一组字段：

| 技能类型 | Lv2/Lv3 可成长字段 | 不可改变 |
| --- | --- | --- |
| 直线/往返 | 伤害、飞行距离、路径宽度、命中反馈 | 不能变成全屏清场或自动追踪 |
| 贴身/纵向 | 伤害、覆盖宽度、命中高度、恢复手感 | 不能长期控场或替代防守技能 |
| 防反 | 反击伤害、可抵挡次数、反击范围 | 不能长期无敌，不能让防护窗口早于潮幕成形 |
| 位移 | 位移距离、收刀伤害、落点反馈 | 不能穿越所有 Boss 技能，不能让无敌早于位移启动 |
| 控场/破甲 | 持续时间、效果强度、Boss 缩放 | 不能无限叠加或锁死 Boss |

技能等级奖励应指定一个具体技能，例如 `潮龙·破阵精进` 或 `镜潮·护返精进`。已达 Lv3 的技能不再进入技能等级候选。

## Skill Upgrade Hooks

升级三选一和装备词条只能强化技能等级、数值或局部手感，不能把技能改成另一个定位。

| 升级方向 | 可影响字段 | 边界 |
| --- | --- | --- |
| 技能精进 | 指定已解锁技能等级 `+1` | 单技能最高 Lv3，不让一个技能覆盖全部场景 |
| 范围微调 | 半径、宽度、路径长度 | 只做小幅提升，不把单点技改成全屏技 |
| 资源循环 | 技能能量获取、击杀返还、消耗减免 | 不绕过技能能量上限，不形成无限释放 |
| 状态强化 | 控场持续、破甲持续、反击次数 | 对 Boss 和精英必须有缩放或上限 |
| 解锁/换装 | 技能池候选、3 个装备槽位 | 未接入素材和 HUD 前不进入候选池 |

## Ultimate: 终式·月潮无间

`终式·月潮无间` 是角色的爆发状态，而不是普通技能。角色开局没有终式，需要在角色升级三选一中学习；学会后才开始积累大招能量并允许释放。

| 等级 | 玩法定位 | 视觉表现 |
| --- | --- | --- |
| Lv1 | 基础月潮状态，小幅提升移动、跳跃、普攻节奏和伤害 | 脚下半月潮纹，轻量青蓝轮廓，普攻偶发残影潮刃 |
| Lv2 | 强化更稳定，持续时间增加，残影潮刃更可靠 | 周身潮波更稳定，移动潮线更连续 |
| Lv3 | 终阶爆发，残影斩追加伤害和命中反馈更强 | 轮廓高光更亮，残影斩更清晰，但不扩大成遮挡层 |

状态字段后续按趋势实现，不在本文锁死具体数值：

- `duration` 随等级增加。
- `moveSpeedMultiplier` 随等级增加。
- `jumpMultiplier` 或空中控制随等级增加。
- `attackSpeedMultiplier` 随等级增加。
- `damageMultiplier` 和残影追加伤害随等级增加。

限制：

- 不提供长期无敌；最多只允许开启动作有短暂抗打断或减伤。
- 普攻残影和移动潮线必须短寿命、低透明度。
- 大招期间技能仍保持原定位，不能让直线、扇形、防反、位移、控场和破甲全部变成同一种大范围爆发。

## Readability Checklist

- 每个普通技能都要有稳定形状：线、扇形、环身、潮涡、单体斩、斜线雨、往返刃或纵向浪柱。
- 每个普通技能都要有稳定起手：玩家能通过动作读出当前技能是即时解围、预判控场、破甲前置还是路线封锁。
- 玩家、敌人、Boss 和平台危险区的优先级高于技能特效炫酷度。
- 大招强化状态不能用全屏遮挡来表现强度。
- UI 中技能名称、等级和冷却/能量状态必须能在移动端读清。
- 新增技能进入候选池前必须先完成图标、施法前摇、命中形状、基础数值和升级边界。
