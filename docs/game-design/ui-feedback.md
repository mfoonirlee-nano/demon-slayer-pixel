# UI/UX 与反馈设计清单

> 实现状态：设计文档。当前 UI 已有开始界面、HUD、暂停、死亡和移动端触控；升级、装备、Boss 入场和幕数提示属于目标设计。

## UI State Flow

| 状态 | 当前实现 | 目标补充 | 是否暂停战斗 | 输入 |
| --- | --- | --- | --- | --- |
| Start screen | 已实现封面、加载提示、任意键/点击开始 | 增加首次提示和未来模式入口 | 游戏未开始 | 任意键、点击/触屏 |
| Loading | 已有贴图加载文案 | 保持简短，不阻塞输入反馈 | 游戏未开始或 runtime 未更新 | 无需操作 |
| Gameplay HUD | 生命、技能图标/能量、大招球、Boss 血条 | 增加幕数、等级、XP；移动端保持可读 | 否 | 常规战斗输入 |
| Boss intro | 未实现独立 overlay | Boss 名称、短暂停拍、音效 sting、血条入场 | 建议暂停 0.6-1.0s | 不接受菜单输入 |
| Act prompt | 未实现 | 击杀 Boss 后显示“第 N 幕”与核心压力 | 建议暂停 0.8-1.2s | 自动关闭 |
| Upgrade choice | 未实现 | XP 升级三选一 | 是 | 鼠标/触屏点击，`1/2/3` |
| Equipment choice | 未实现 | Boss 装备三选一 | 是 | 鼠标/触屏点击，`1/2/3` |
| Pause | 已实现暂停面板和数值/技能说明 | 统一按钮布局与移动端表现 | 是 | `Esc/P` 恢复 |
| Death | 已实现死亡动画、生存时间、`R` 重开 | 增加死亡原因和一条复盘提示 | 游戏结束 | `R` 重开 |

## Overlay Rules

- 同一时间只允许一个选择 overlay：升级三选一和装备三选一必须排队。
- 选择 overlay 打开时，`elapsed`、刷怪、Boss AI、平台移动、投射物、碰撞和拾取都暂停。
- Pause 不能覆盖选择 overlay；若选择 overlay 打开，`Esc/P` 不关闭选择，只能选择奖励。
- Death 优先级最高；生命归零后清空未处理选择 overlay。
- Boss intro 和 Act prompt 是短暂停拍，不应该要求玩家点击确认。
- 移动端所有 overlay 必须支持触屏选择，不依赖键盘。

## HUD Requirements

当前 HUD 已经尽量精简。目标新增信息必须保持常驻层不拥挤：

| 信息 | 常驻要求 | 建议位置 |
| --- | --- | --- |
| 生命 | 必须常驻 | 当前状态条上轨 |
| 技能能量与当前技能 | 必须常驻 | 当前状态条下轨 + 技能图标 |
| 大招能量 | 必须常驻 | 当前大招球 |
| Boss 血条 | Boss 存在时显示 | 画面顶部中央 |
| 当前幕 | 目标设计接入后显示 | HUD 角落小标签 |
| 等级与 XP | XP 系统接入后显示 | 状态条附近的细进度，不抢主血条 |
| 装备 | 不建议全常驻 | Pause 或简短换装提示 |

## Feedback Checklist

| 事件 | 当前基础 | 目标标准 |
| --- | --- | --- |
| 普攻起手 | 有短音效 | 加轻微武器起势音，避免盖过命中音 |
| 普攻击中 | 有斩击粒子、hit burst、tone | 命中点必须贴近碰撞重叠区域 |
| 敌人死亡 | 有得分、能量、粒子，本地封面击杀计数 | 补小型消散或闪白，不遮挡平台 |
| 玩家受伤 | 有受伤音、击退、无敌闪烁 | 补明确红色屏边或角色受击层，不长期遮挡 |
| 技能释放 | 有动画、flash、粒子和 tone | 每个技能有独立起手、命中和消散层级 |
| 大招释放 | 有充能球、释放动画和范围效果 | 满能量提示更清楚，释放后有短暂强反馈 |
| 水晶拾取 | 有治疗/攻击结算和音效 | 攻击与治疗颜色、图标或粒子必须区分 |
| 宝箱拾取 | 已有奖励结算 | 补开箱反馈，价值高于普通水晶 |
| 升级 | 未实现 | 暂停、音效、三选一卡片出现，选择后立即反馈 |
| 装备获得 | 未实现 | Boss 击杀后更强的掉落反馈，卡片显示槽位和替换关系 |
| Boss 入场 | 有生成 tone 和血月背景变化 | 补标题、短暂停拍、Boss intro sting |
| Boss 阶段变化 | 通过血条阶段文字和行为变化体现 | 补阶段音效、短闪、姿态/特效密度变化 |
| Boss 击杀 | 有分数、能量、音效和清空 Boss | 补击败提示、Act prompt、装备选择入口 |
| 死亡 | 有死亡动画和生存时间 | 补死亡原因、game over sting |

## Input Requirements

| 输入 | 当前行为 | Overlay 目标行为 |
| --- | --- | --- |
| `A/D`、方向键 | 移动 | 选择 overlay 打开时忽略 |
| `W/Space` | 跳跃 | 选择 overlay 打开时忽略 |
| `J` | 普攻 | 选择 overlay 打开时忽略 |
| `K` | 技能 | 选择 overlay 打开时忽略 |
| `L` | 大招 | 选择 overlay 打开时忽略 |
| `1/2/3` | 切换技能 | 选择 overlay 打开时改为选择选项 |
| `Esc/P` | 暂停/恢复 | 选择 overlay 打开时不关闭选择 |
| `R` | 死亡后重开 | Death 状态专用 |
| 触屏按钮 | 移动端战斗输入 | 选择 overlay 打开时隐藏或禁用战斗按钮 |

## Visual Readability Rules

- Boss 血条、玩家状态条和选择卡片不能被技能特效长期遮挡。
- 敌人前摇特效不能和玩家水蓝技能大面积同色。
- 后期控场区域必须让玩家看清边界，但不遮住平台边缘。
- 移动端按钮不能覆盖 Boss 血条、升级选择或死亡提示。
- 任何新增 overlay 都要先定义暂停规则，再做视觉样式。
