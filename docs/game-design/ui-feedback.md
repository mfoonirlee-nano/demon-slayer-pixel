# UI/UX 与反馈设计清单

> 实现状态：设计文档。当前阶段只规划桌面端第一版 UI：常驻 HUD 补等级与 XP，暂停界面作为角色配置页，升级和 Boss 击杀提供奖励选择。开始、Boss 血条、死亡、移动端触控等现有 UI 暂不扩展。

## Current Scope

本轮 UI 不追求完整菜单系统，而是补齐单局成长闭环：

1. **常驻 HUD**：保留现有生命、技能能量、当前技能图标、大招球和 Boss 血条，只新增角色等级与 XP 细条。
2. **Pause 配置页**：暂停界面展示角色状态、装备栏和技能栏，并允许玩家在暂停时调整装备和已装备技能。
3. **升级奖励 UI**：角色升级时暂停战斗，弹出 3 个水蓝系成长选项。
4. **Boss 奖励 UI**：击杀 Boss 后暂停战斗，弹出 3 个金红系装备选项。

暂缓内容：移动端 UI、Boss Intro、Act Prompt、死亡复盘、局外养成、商店、装备背包详情页、拖拽操作、奖励重抽、复杂动画和新增大规模 UI 美术资源。

## UI State Flow

| 状态 | 当前实现 | 本轮目标 | 是否暂停战斗 | 输入 |
| --- | --- | --- | --- | --- |
| Start screen | 已实现封面、加载提示、任意键/点击开始 | 暂不扩展 | 游戏未开始 | 任意键、点击 |
| Gameplay HUD | 已有生命、技能图标/能量、大招球、Boss 血条 | 增加角色等级与 XP 细条 | 否 | 常规战斗输入 |
| Pause | 已实现暂停面板和数值/技能说明 | 改为角色状态、装备栏、技能栏三栏配置页 | 是 | 鼠标点击、数字键、`Esc/P` |
| Upgrade choice | 未实现 | 升级三选一成长奖励 | 是 | 鼠标点击、`1/2/3` |
| Boss equipment choice | 未实现 | Boss 击杀三选一装备奖励 | 是 | 鼠标点击、`1/2/3` |
| Death | 已实现死亡动画、生存时间、`R` 重开 | 暂不扩展 | 游戏结束 | `R` 重开 |

## Overlay Priority

同一时间只允许一个可交互 overlay。优先级从高到低：

1. **Death**：最高优先级；生命归零后清空未处理奖励选择。
2. **Boss equipment choice**：Boss 装备奖励优先于升级奖励。
3. **Upgrade choice**：升级奖励一次只展示一组三选一。
4. **Pause**：不能覆盖奖励选择；奖励选择存在时 `Esc/P` 不关闭奖励。
5. **Gameplay HUD**：常驻底层信息。

如果击杀 Boss 同时导致升级，顺序为：Boss 装备三选一 → 升级三选一 → 恢复战斗。

## Gameplay HUD

### 保留信息

| 信息 | 位置 | 说明 |
| --- | --- | --- |
| 生命 | 当前状态条上轨 | 战斗中必须常驻 |
| 技能能量 | 当前状态条下轨 | 战斗中必须常驻 |
| 大招能量 | 状态栏左侧圆框 | 显示充能进度，满能量时保持金红高亮 |
| 当前技能图标 | 大招圆框右下方小圆框 | 只显示当前 1/2/3 技能槽对应技能 |
| Boss 血条 | 画面顶部中央 | Boss 存在时显示 |

### 新增信息

只新增等级和 XP，不增加分数、时间、装备、技能说明等额外常驻信息。

```text
Lv.3  XP ███████░░░ 42 / 100
```

建议放在当前玩家状态条下方，作为细条展示：

- XP 条高度低于生命和技能条。
- 主色使用水蓝或淡青，避免抢生命和大招的视觉优先级。
- 等级文字与 XP 数值保持小字号、强描边或阴影，保证像素风可读。
- 若 XP 系统尚未接入，可先显示默认 `Lv.1  XP 0 / 100`。

## Pause Configuration Page

暂停界面不再只是说明页，而是本局构筑配置页。保持现有暂停背景资源，内容区改成三栏：

```text
角色状态 | 装备栏 | 技能栏
```

### 角色状态

角色状态栏只展示，不提供操作。

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| 等级 | `Lv.3` | 当前单局等级 |
| 经验 | `42 / 100` | 当前等级 XP 进度 |
| 生命值 | `86 / 100` | 当前 HP / 最大 HP |
| 攻击力 | `14` 或 `14 (10+4)` | 展示基础和加成 |
| 技能充能 | `70 / 100` | 当前技能资源 |
| 大招充能 | `35 / 100` | 满时用金色强调 |
| 分数 | `1240` | 保留现有暂停页分数 |

### 装备栏

装备栏展示并允许更换当前装备。装备槽位固定为：

| 槽位 ID | 中文 UI | 定位 |
| --- | --- | --- |
| `blade` | 刃器 | 输出方式：普攻、技能、Boss 爆发、特殊攻击触发 |
| `garb` | 衣装 | 生存节奏：移动容错、低血保护、受伤后恢复节奏 |
| `talisman` | 饰符 | 资源循环：技能能量、大招能量、释放频率、触发返还 |

默认展示：

```text
装备栏

刃器  流水刃
衣装  涟波衣
饰符  未装备
```

交互规则：

1. 点击一个装备槽，打开该槽位的可选装备列表。
2. 列表只显示同槽位装备，例如点击 `刃器` 只显示 `blade` 装备。
3. 点击候选或按数字键选择后，立即装备到该槽位。
4. 没有装备时显示 `未装备`，不要留空。
5. 第一版不做拖拽、不做装备分解、不做背包详情页。

候选列表示例：

```text
可选刃器
[1] 流水刃   已装备
[2] 破月刃
[3] 流影刃
```

### 技能栏

技能栏展示并允许更换 3 个技能槽。

默认展示：

```text
技能栏

[1] 潮龙·破阵   Lv.2
[2] 弦月·潮刃   Lv.1
[3] 镜潮·护返   Lv.1

当前技能：潮龙·破阵
抬刃聚潮后向前释放潮龙，造成窄长路径伤害，用于直线远程点杀。
伤害公式：角色攻击力 x 1.2
```

交互规则：

1. 点击技能槽，打开已习得技能列表。
2. 只能装备已习得技能，未习得技能不显示或置灰。
3. 一个技能不能重复装备到多个槽位。
4. 选择候选技能后，写入对应技能槽。
5. 战斗中的 `1/2/3` 仍然只负责切换当前技能槽，不打开配置列表。
6. 第一版不做拖拽排序，使用点击和数字键即可。

候选列表示例：

```text
选择技能槽 2
[1] 潮龙·破阵   Lv.2   已装备
[2] 弦月·潮刃   Lv.1   当前槽
[3] 镜潮·护返   Lv.1
[4] 流步·潮闪   Lv.1
```

## Upgrade Choice UI

升级奖励 UI 用于角色等级提升后的成长选择，视觉主色为水蓝。

触发规则：

1. 击杀敌人或 Boss 获得 XP。
2. XP 达到当前等级需求后，提升等级并生成最多 3 个升级选项。
3. 存在待选升级奖励时暂停战斗和实体更新。
4. 玩家选择 1 个奖励后立即生效。
5. 如果剩余 XP 仍满足下一等级需求，继续弹出下一组升级选项。

布局：

```text
等级提升
Lv.2 → Lv.3
选择一项强化

[1] 潮龙·破阵精进  技能 Lv+1
[2] 最大生命提升   生命 +20
[3] 技能充能强化   能量获取 +10%
```

第一版奖励类型控制在 4 类：

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| 基础属性 | 攻击力提升、最大生命提升 | 直接增强角色状态 |
| 技能强化 | 潮龙·破阵 Lv+1、弦月·潮刃 Lv+1 | 提升已习得技能等级 |
| 资源强化 | 技能能量获取提升、大招能量获取提升 | 改善释放循环 |
| 新技能 / 大招 | 解锁新技能、终式等级 +1 | 加入技能库或提升大招等级 |

新技能解锁规则：

- 选择后加入 `learnedSkillIds`。
- 如果 `equippedSkillIds` 有空槽，自动装备到空槽。
- 如果 3 个槽都已占用，只加入技能库，并提示“已习得，可在暂停界面调整技能”。

## Boss Equipment Choice UI

Boss 奖励 UI 用于击杀 Boss 后获得装备，视觉主色为金色 + 血红。

触发规则：

1. Boss 击杀后生成 3 个装备候选。
2. 打开 Boss 装备奖励 overlay 并暂停战斗。
3. 玩家选择 1 件装备。
4. 选中装备加入装备库存。
5. 若对应槽位为空，自动装备；若槽位已有装备，只加入库存并提示可在暂停界面更换。

布局：

```text
血鬼遗物
选择一件装备

[1] 流水刃
    刃器 · 普通
    普攻命中积攒水势，释放技能时提高伤害。
    已装备：无

[2] 涟波衣
    衣装 · 普通
    受伤后短暂提升移动容错。
    已装备：旧衣装名

[3] 潮声符
    饰符 · 普通
    技能命中返还少量能量。
    已装备：无
```

每张装备卡必须显示：

| 信息 | 说明 |
| --- | --- |
| 装备名 | 如 `流水刃` |
| 槽位 | `刃器 / 衣装 / 饰符` |
| 品质 | 如 `普通 / 精良 / 觉醒` |
| 核心效果 | 一句话说明，不放长文本 |
| 当前槽位装备 | 用于判断是否需要稍后在暂停页更换 |

## Input Rules

| 场景 | `1/2/3` | 鼠标点击 | `Esc/P` |
| --- | --- | --- | --- |
| 战斗中 | 切换当前技能槽 | 无 | 暂停 |
| Pause 默认态 | 选择技能槽或聚焦快捷槽 | 选择装备槽 / 技能槽 | 恢复战斗 |
| Pause 装备列表打开 | 选择装备候选 | 装备候选 | 关闭列表，不恢复战斗 |
| Pause 技能列表打开 | 选择技能候选 | 技能候选 | 关闭列表，不恢复战斗 |
| Upgrade choice | 选择奖励 | 选择奖励 | 不关闭奖励 |
| Boss equipment choice | 选择奖励 | 选择奖励 | 不关闭奖励 |
| Death | 无 | 无 | 无，使用 `R` 重开 |

打开奖励选择时，`A/D`、方向键、`W/Space`、`J`、`K`、`L` 等战斗输入全部忽略。

## Data Model Requirements

建议快照和运行时最少补齐以下字段。字段命名可按实际代码风格调整，但语义不要拆散。

```ts
type PlayerGrowthSnapshot = {
  runLevel: number;
  runXp: number;
  xpToNext: number;
  ultimateLevel: 0 | 1 | 2 | 3;
};

type SkillLoadoutSnapshot = {
  learnedSkillIds: SkillId[];
  equippedSkillIds: Array<SkillId | null>; // 固定 3 槽
  skillLevels: Partial<Record<SkillId, 1 | 2 | 3>>;
};

type EquipmentLoadoutSnapshot = {
  equipmentInventory: EquipmentItemSnapshot[];
  equippedEquipment: {
    blade?: EquipmentItemSnapshot;
    garb?: EquipmentItemSnapshot;
    talisman?: EquipmentItemSnapshot;
  };
};

type RewardOverlaySnapshot = {
  pendingUpgradeChoices: UpgradeChoiceSnapshot[] | null;
  pendingEquipmentChoices: EquipmentItemSnapshot[] | null;
};
```

奖励和配置页关系：

- 升级奖励负责提供属性、技能等级、新技能和大招成长。
- Boss 奖励负责提供装备。
- 暂停页负责最终调整本局装备和技能槽。
- 常驻 HUD 只显示当前战斗必需信息和 XP 进度。

## Visual Readability Rules

- 常驻 HUD 不展示装备详情和技能说明，避免抢战斗视野。
- 常驻 HUD 的角色状态区只保留生命条和技能条；大招充能使用左侧圆框展示。
- XP 条不得比生命条和技能条更醒目。
- 升级奖励使用水蓝体系，Boss 装备奖励使用金红体系。
- Pause 配置页允许信息密度更高，但每栏必须有清晰标题。
- 选择列表必须标记当前装备、当前技能槽和已装备技能。
- 任何奖励 overlay 打开时必须暂停实体更新，避免玩家在读卡时受伤。

## Implementation Decisions

本轮实现做一个可玩的纵切，不做完整菜单系统或完整 18 件装备池。

- React 只负责素材布局、动态文本和点击/数字键交互；XP、升级、装备、技能槽和奖励队列规则放在独立 domain/system 模块中。
- 手动暂停和奖励暂停分开建模。运行时暂停条件是 `manualPaused || hasBlockingOverlay`，奖励 overlay 打开时 `Esc/P` 不能恢复战斗。
- Boss 血条继续复用现有 `boss_hp_bar.png`。主 HUD 的组合预览、大招圆框、当前技能小圆框、生命/技能条三段式外框、暂停页、奖励面板、卡片、槽位和按钮状态使用 `assets/sprites/ui/system/` 下按用途分组的独立透明 PNG；生命条和技能条的动态填充使用 CSS 绘制以支持随等级变长。
- XP 条是例外：用 CSS 实现，并固定放在游戏窗口底部。
- 现有技能图标和 `ultimate_orb_*_sheet.png` 继续独立使用。
- `UI_SPRITES` 为每个 UI 框体单图记录 `src/w/h`，便于逐个素材微调。
- 开局习得并装备 `潮龙·破阵`、`弦月·潮刃` 和 `镜潮·护返`；后续六招通过升级三选一解锁。战斗中按 `1/2/3` 切换当前技能槽。
- 技能可在暂停页替换，不能卸下。装备可卸下，卸下后回到本局装备库存。
- 第一版 Boss 装备奖励固定提供 `流水刃`、`涟波衣`、`潮声符` 三件普通装备，不允许重复拥有；选中后自动装备到对应槽位，旧装备回到库存。
- 第一版技能等级和大招等级立刻影响伤害倍率，但不重做大招为限时强化状态。
