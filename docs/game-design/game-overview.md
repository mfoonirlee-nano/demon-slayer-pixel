# 游戏总纲

> 实现状态：产品方向与当前玩法概览。9 招普通技能、局内成长和 13 幕主线已接入；本轮升级抽取与技能衔接已接入并通过自动化验证，未做实机试玩。

## Game Positioning

《月潮夜行》当前定位为单局制 2D 横版像素动作生存游戏。玩家在夜色山林与鸟居场景中控制原创潮刃者移动、跳跃、普攻、释放月潮流剑式和大招，在不断刷新的夜妖、移动平台和阶段式 Boss 压力中尽可能生存并提高分数。

核心形态为“单局内构筑 + 横版动作生存”：

- 每局从基础能力开始。
- 击杀敌人获取分数、XP、技能能量与可收集的残灵；习得终式后还会获取大招能量。
- 平台路线和敌人组合持续制造移动压力。
- Boss 周期性出场形成阶段目标。
- 击杀 Boss 获得强奖励并推进下一幕。
- 幕数提高后敌人池、Boss 池、地图片段和装备品质带发生变化。
- 当前主线是一条 **13 幕有限闯关阶梯**：第 1-6 幕引入 6 个基础 Boss，第 7-12 幕出现蚀醒形态，第 13 幕击败终极 Boss 万相血月即单局通关。完整幕表见 [act-structure.md](act-structure.md)。

## Target Player

目标玩家偏好短时可重开、操作反馈直接、像素动作表现清晰的生存玩法。早期单局在 3 到 8 分钟内形成完整体验：开局熟悉、首 Boss 考核、第二幕构筑开始成形、第三幕后进入更高压力。随着玩家变强，一次顺利的清版（1→13 幕）约 18-22 分钟；长期约 10 小时的差异化体验来自反复挑战蚀醒难度墙、局内构筑差异和通关后进阶难度，而非单局无限拉长。

## Core Experience

核心体验是“在移动路线、敌潮和 Boss 前摇之间做快速判断”：

- 站位：玩家需要通过地面、平台和跳跃维持可攻击位置。
- 节奏：普攻负责基础处理，技能负责解围，大招提供限时强化窗口，用移动、跳跃和普攻残影潮刃追击高压目标。
- 续航：击杀后收集残灵，再选择安全的 `0.6s` 引灵窗口恢复生命；拾取本身不直接回血。
- 构筑：XP 三选一提供技能习得和精进，Boss 装备三选一与高台灵匣补充构筑方向；每局重开清空战斗成长。
- 读招：敌人和 Boss 的高伤行为必须有前摇、攻击窗口和恢复窗口。
- 反馈：命中、受伤、拾取、升级、Boss 阶段变化都要给出清楚的视觉和声音反馈。

## Design Pillars

| 支柱 | 要求 | 反例 |
| --- | --- | --- |
| 操作清晰 | 移动、跳跃、普攻、技能、大招必须有稳定输入响应和可见反馈 | 随机硬控、不可读碰撞、技能命中范围不明 |
| 压力可读 | 每种敌人只承担一个主要压力，高伤行为有前摇 | 高速、高血、远程、控场堆在同一单位 |
| 单局构筑 | 成长只在当前局内生效，死亡后清空 | 局外属性碾压、永久数值膨胀 |
| 内容轮换 | 幕数推进改变敌人、Boss、平台权重和装备品质带 | 只给同一个 Boss 加血或只缩短刷怪间隔 |
| 像素识别 | 小尺寸下仍能从轮廓读出功能 | 只靠换色区分敌人与状态 |

## Non-Goals

- 不做局外永久战斗属性成长。通关后的血月试炼进阶难度是**横向解锁**（解锁更高难度层和负面词条），不给任何永久战力数值；每局仍从基础能力开始、死亡清空。
- 不做复杂剧情分支、对话树或多结局叙事。
- 不做商业化、抽卡、每日任务或在线经济系统。
- 不用临时图形占位把未完成敌人或 Boss 强行接入常规池。
- 不让后期难度只依赖数值膨胀；蚀醒段必须靠新月蚀术招、阶段增加和敌人组合制造差异，而非只给 Boss 加血。

## Current Game Identity

当前源码已经接入：

- React 外壳承载开始界面、HUD、暂停、死亡和移动端触控。
- Canvas runtime 驱动战斗、地形、敌人、Boss、粒子和背景。
- 玩家有移动、跳跃、普攻、下落攻击、9 招普通技能和月潮大招；开局习得三招，最多装备三招，回刃包含留刃与主动回收操作。
- 12 种普通敌人各有行为，enemy director 使用本局种子、幕数、战斗 profile、波次预算和同屏 cap 安排压力。
- Boss 注册表驱动 6 个基础遭遇、6 个蚀醒遭遇和终幕万相血月；第 13 幕胜利进入通关结算。
- XP 升级暂停、Boss 装备三选一、暂停换装和每幕一次的高台灵匣已形成局内成长循环。
- 地图已经是片段式生成，包含喘息、桥、上下楼梯、折返、跳跃链、悬浮和高风险支路；地图不再投放攻击/生命奖励物。
- 普通敌人会掉落可储存的残灵，HUD 以六珠灵龛表达储量，玩家主动引灵后才恢复生命。

升级候选按本局种子抽取，让新招在早期即可出现。装备深度围绕现有技能的路径、控制和破甲建立：流水刃布印后换招兑现，鸣拍符改变兑现形态，踏影衣制造聚怪位置，破月刃把控制/破甲转成延迟破裂，连珠符传播潮印。组合与战术取舍见 [equipment-combos.md](equipment-combos.md)。这些规则替代无装备也能触发的全局连式奖励。

尚未接入的后续目标包括通关后血月试炼；主线仍需人工试玩校准逐幕压力、构筑可读性与操作反馈，目标击杀率和时长不代表已经测得的结果。
